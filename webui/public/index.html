Credentials

Kept in this browser's localStorage and sent as X-API-Key. Leave it empty when the console was started with --token: the proxy injects the token server-side and the secret never reaches the page.

Slicing

Attach a model file to submit multipart/form-data (the REST server stores it in its upload pool); leave it empty when the config already names a server-side model_path. The Output column shows the server-side result path reported by the API; click a path to copy it, hover the state of a failed job for its error message, and use Preview to read the result itself in the panel below the table. capture geometry adds ?geometry=1 to the submission so the Layer geometry panel below has something to draw. embed preview images sets gcode_thumbnails in the config of fdm only, which makes the engine project the model it just sliced into the comments at the head of its G-code.

Layer geometry

no layer geometry previewed yet

-

Drawn from /api/jobs/{id}/geometry, so the job has to have been submitted with capture geometry and must have reached a terminal state; Cancel only asks the pipeline to stop, and it does so at its next safe point. The server keeps snapshots for the last few jobs only, so an older row can report that its snapshot is gone - the panel states the server's own answer verbatim. Scroll to zoom, drag to pan; contours are drawn with a constant line width at every zoom level. Stack and Side draw at most 12 sampled layers, and only Path shows the real continuous toolpath a spiral run deposited (it needs spiral_mode in the config of fdm, tdp or waam). In those two stacked views a line between neighbouring rings is the travel a run would take, not measured data.
