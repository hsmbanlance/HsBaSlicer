Credentials

Kept in this browser's localStorage and sent as X-API-Key. Leave it empty when the console was started with --token: the proxy injects the token server-side and the secret never reaches the page.

Slicing

Attach a model file to submit multipart/form-data (the REST server stores it in its upload pool); leave it empty when the config already names a server-side model_path. The Output column shows the server-side result path reported by the API; click a path to copy it, hover the state of a failed job for its error message, and use Preview to read the result itself in the panel below the table.
