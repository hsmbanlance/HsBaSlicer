## 核心技术栈

HsBaSlicer项目采用了一系列先进的C++库和工具，以支持高精度几何计算、复杂CAD模型处理、日志记录、数据序列化、线性代数运算、脚本扩展和压缩解压功能。以下是对各核心技术的详细说明。

### CGAL：高精度几何计算与切片算法

CGAL（Computational Geometry Algorithms Library）是HsBaSlicer中用于高精度几何计算和切片算法的核心库。项目通过`meshmodel/CgalModel.hpp`和`meshmodel/CgalModel.cpp`实现了基于CGAL的三维模型处理功能，包括布尔运算（并集、交集、差集）、几何变换（平移、旋转、缩放）、边界框计算、体积计算以及三角网格生成。

在代码中，`CgalModel`类封装了CGAL的`Polyhedron_3`和`Nef_polyhedron_3`等数据结构，利用`Exact_predicates_inexact_constructions_kernel`内核确保几何计算的鲁棒性。该库支持创建基本几何体（如立方体、球体、圆柱体等），并用于执行精确的切片算法，是3D打印切片引擎的数学基础。

### OpenCASCADE（OCCT）：复杂CAD模型处理

OpenCASCADE（简称OCCT）是一个强大的开源CAD/CAE/CAM开发平台，用于处理复杂的参数化和边界表示（B-rep）模型。HsBaSlicer通过`cadmodel/OcctModel.hpp`和`cadmodel/OcctModel.cpp`集成了OCCT，以支持STEP和IGES等工业标准CAD格式的读写。

`OcctModel`类封装了OCCT的`TopoDS_Shape`数据结构，能够加载和保存STEP/IGES文件，并执行高级几何操作，如实体加厚（`ThickSolid`）。该库特别适用于处理由CAD软件生成的复杂机械零件，确保了与工业设计流程的无缝集成。OCCT的使用受限于非Android平台，如`vcpkg.json`中所示。

### Boost.Log：跨平台日志记录

Boost.Log库为HsBaSlicer提供了灵活且高效的跨平台日志记录功能。在`logger/logger.hpp`和`logger/logger.cpp`中，项目实现了一个单例模式的`LoggerSingletone`类，封装了Boost.Log的严重性级别（trace、debug、info、warning、error、fatal）和日志格式化功能。

日志系统支持配置文件（`logcfg.ini`）来动态设置日志级别和输出路径，并能同时输出到控制台和文件。在Android平台上，系统会自动切换到`__android_log_print`进行内核日志输出，确保了跨平台的一致性。该库通过`Boost::log`和`Boost::log_setup`在CMake中链接，是调试和监控应用行为的关键工具。

### Protobuf：配置与数据的序列化传输

Protocol Buffers（Protobuf）是HsBaSlicer中用于配置和数据序列化的核心技术。项目在`proto/`目录下定义了多个`.proto`文件（如`base_config.proto`、`slice_config.proto`），描述了切片配置、模型数据、路径信息等结构化数据的协议。

通过`proto/CMakeLists.txt`中的CMake脚本，这些`.proto`文件被自动编译成C++、C#、Java和Python等多种语言的源代码，实现了跨语言的数据交换。例如，`msg_base_config`消息定义了切片技术类型、输出格式和文件名等基本信息。这种序列化机制确保了配置数据在不同模块和平台间高效、可靠地传输。

### Eigen3：线性代数运算

Eigen3是一个高性能的C++模板库，用于线性代数、矩阵和向量运算。HsBaSlicer广泛使用Eigen3来处理3D几何变换，如平移、旋转和缩放。在`base/eigen_translator.hpp`和`base/eigen_translator.cpp`中，项目实现了`Eigen::Vector2f`、`Eigen::Vector3f`等类型与字符串之间的转换，以便在Boost.PropertyTree中存储和读取配置。

`Eigen::Quaternionf`被用于表示三维空间中的旋转，`Eigen::Isometry3f`和`Eigen::Affine3f`则用于执行仿射变换。这些运算在`CgalModel`和`OcctModel`的`Transform`方法中被调用，是实现精确几何操作的数学基础。

### Lua 5.4+：脚本扩展能力

Lua 5.4+为HsBaSlicer提供了强大的脚本扩展能力，允许用户自定义切片路径的生成逻辑。在`paths/layerspath.cpp`中，`LayersPath::ToString`方法通过`luaL_openlibs`加载Lua标准库，并执行用户提供的Lua脚本（如`custom_fill.lua`）来生成G代码或机器人语言。

项目通过`fileoperator/LuaAdapter.cpp`将C++对象（如`Bit7zZipper`）暴露给Lua环境，实现了双向交互。测试文件`points_path_test.cpp`中的Lua代码展示了如何遍历点路径并生成CSV格式的输出。这种设计使得非程序员用户也能通过编写简单的Lua脚本来定制切片后处理流程。

### miniz/bit7z：ZIP压缩与解压

HsBaSlicer支持多种格式的压缩与解压，主要依赖`miniz`和`bit7z`两个库。`miniz`是一个单文件的zlib替代品，用于基本的ZIP压缩，通过`fileoperator/zipper.hpp`实现。`bit7z`是一个7-Zip的C++封装，提供了更广泛的格式支持。

在`fileoperator/bit7z_zipper.hpp`中，`Bit7zZipper`类支持ZIP、7z、XZ、BZIP2、GZIP、TAR等多种格式的压缩，并能处理密码保护的归档。`ZipperFormat`枚举定义了所有支持的格式。该库通过`USE_BIT7Z`编译宏在非Android平台上启用，提供了比`miniz`更强大的功能。

## vcpkg依赖管理

vcpkg是HsBaSlicer项目的主要依赖管理工具，通过`vcpkg.json`和`vcpkg-configuration.json`文件进行声明和配置。

### vcpkg.json中的依赖项

`vcpkg.json`文件列出了项目的所有第三方依赖及其版本约束。关键依赖包括：
- `cgal`：用于几何计算
- `opencascade`：用于CAD模型处理（排除Android/iOS）
- `boost-log`：用于日志记录（排除Android）
- `protobuf`：用于数据序列化
- `eigen3`：用于线性代数
- `lua`：用于脚本扩展
- `miniz`和`bit7z`：用于压缩解压
- `sqlpp11`：用于数据库操作，根据平台选择不同特性

依赖项通过`platform`字段进行条件约束，例如`"platform": "!android & !ios"`确保某些库仅在桌面平台上使用。这使得项目能够为不同目标平台定制依赖集。

## CMake构建配置

CMake是HsBaSlicer的构建系统，通过`CMakeLists.txt`和`CMakePresets.json`文件进行配置。

### CMakePresets.json构建环境

`CMakePresets.json`定义了跨平台的构建预设，支持Windows、Linux、macOS和Android。每个预设都指定了生成器（Ninja）、二进制目录、安装目录和工具链文件（`vcpkg.cmake`）。

- **Windows**：使用`cl.exe`编译器，继承`windows-base`预设，提供x64 Debug和Release配置。
- **Linux**：使用`g++`编译器，提供Debug和Release配置。
- **macOS**：类似Linux，但系统名为`Darwin`。
- **Android**：使用`android.toolchain.cmake`，指定`arm64-android`三元组和`android-28`平台。

这些预设通过`condition`字段根据主机系统名称自动选择，简化了跨平台构建流程。

## C++20标准与Ninja构建工具

### C++20标准的使用

HsBaSlicer要求编译器支持C++20标准，这在`CMakeLists.txt`中通过`set(CMAKE_CXX_STANDARD 20)`明确指定。项目充分利用了C++20的新特性，特别是在`base/concepts.hpp`中定义了多个概念（concepts），如`CharStream`、`WCharStream`、`Enum`、`StdHash`等。

这些概念用于约束模板参数，提高了代码的类型安全性和可读性。例如，`EqualAndStdHash`概念要求类型同时支持`operator==`和`std::hash`，确保了在哈希容器中的正确使用。C++20的`std::format`也被用于字符串格式化，取代了传统的`printf`风格。

### Ninja构建工具的优势

Ninja被选为HsBaSlicer的默认构建工具，因其具有以下优势：
- **速度快**：Ninja专注于最小化构建时间，通过精确的依赖跟踪避免不必要的重新编译。
- **简洁性**：生成的构建文件（`build.ninja`）比Makefile更简洁，易于解析。
- **跨平台一致性**：在Windows、Linux和macOS上提供一致的构建体验。
- **与CMake集成良好**：CMake可以无缝生成Ninja构建文件，支持增量构建和并行编译。

在`CMakePresets.json`中，所有预设都指定`"generator": "Ninja"`，确保了构建过程的高效性。

## 开发者依赖安装指南

### 通用依赖安装步骤

1. **安装CMake**：至少3.21版本，建议通过包管理器安装。
2. **安装Git**：用于克隆vcpkg和项目仓库。
3. **安装vcpkg**：
   ```bash
   git clone https://github.com/microsoft/vcpkg.git
   ./vcpkg/bootstrap-vcpkg.sh  # Linux/macOS
   ./vcpkg/bootstrap-vcpkg.bat # Windows
   ```
4. **设置环境变量**：将`VCPKG_ROOT`指向vcpkg安装目录。

### 操作系统特定指南

#### Windows
- 安装Visual Studio 2022，包含“使用C++的桌面开发”工作负载。
- 确保`cl.exe`在PATH中。
- 使用CMake预设进行构建：
  ```bash
  cmake --preset x64-release
  cmake --build --preset x64-release
  ```

#### Linux
- 安装系统依赖：
  ```bash
  sudo apt install g++ ninja-build libx11-dev libglu1-mesa-dev libxi-dev libxmu-dev libfontconfig1-dev
  ```
- 安装vcpkg并构建项目：
  ```bash
  cmake --preset linux-release
  cmake --build --preset linux-release
  ```

#### macOS
- 安装Xcode命令行工具和Homebrew。
- 通过Homebrew安装CMake和Ninja：
  ```bash
  brew install cmake ninja
  ```
- 构建项目：
  ```bash
  cmake --preset macos-release
  cmake --build --preset macos-release
  ```

#### Android
- 安装Android NDK，并设置`ANDROID_NDK_HOME`环境变量。
- 使用`android-release`预设：
  ```bash
  cmake --preset android-release
  cmake --build --preset android-release
  ```

通过遵循此指南，开发者可以快速搭建HsBaSlicer的开发环境，并开始贡献代码。
