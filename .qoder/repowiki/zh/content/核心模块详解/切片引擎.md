## 核心组件
- 切片 API（Safe/Unsafe/Lua/Reusable Topo）
  - SafeSlice：返回闭合多边形，丢弃开放轮廓
  - UnSafeSlice：保留开放轮廓，便于材料填充类工艺或调试

  - 快速切片 SliceFast（要求拓扑完整性检查通过）
- 并行切片
  - ParallelForLayers：按层并行调度，块状提交任务，进度回调串行化
  - ThreadPool：底层线程池，支持协程执行器

## 架构总览
切片引擎的整体数据流如下：
1. 外部流水线（SLA/SLM/SLS）加载模型并计算层数
2. 构建可复用拓扑 BuildSliceTopology
3. 对每一层调用 SliceLayer（内部等价于 NormalizeUnSafePolygons(UnSafeSlice(z))）
4. 将结果 PolygonsD 交给后续填充/路径生成阶段
5. 并行调度由 ParallelForLayers 管理，确保每层写入独立输出槽位

### FullTopoModel 拓扑数据结构与层次关系
FullTopoModel 是切片专用的全拓扑重建网格模型，提供：
- Face：包含三角形顶点索引、三条边索引、法向量（可选）
- Vertex：包含三维坐标、关联的面和边列表
- Edge：包含两个顶点索引、相邻的两个面索引

构造过程：
- 从 IModel 提取三角形网格（顶点矩阵与面索引矩阵）
- 构建顶点表、边表、面表，并通过哈希映射建立边到面的邻接关系
- 可选计算逐面法向量

### 层平面与网格相交计算
- 层平面为 Z=height 的水平面
- 对每条边进行相交判断：若两端点分别在 plane 两侧或恰好在平面上，则计算交点
- 对于每个三角面，最多产生两个交点；当恰好两个交点时，在邻接图中添加一条边连接这两个交点键值

```mermaid
flowchart TD
Start(["开始"]) --> CheckZ["判断边两端点的 Z 与 height 的关系"]
CheckZ --> |同侧| NoIntersect["无交点"]
CheckZ --> |异侧或共面| ComputeT["计算 t = (height - v1.z)/(v2.z - v1.z)"]
ComputeT --> IntersectPoint["计算交点 p = v1 + t*(v2 - v1)"]
IntersectPoint --> CollectPoints["收集三角面所有交点"]
CollectPoints --> TwoPoints{"是否恰好两个交点？"}
TwoPoints --> |是| AddEdge["在邻接图中添加两点间的边"]
TwoPoints --> |否| NextFace["跳过该面"]
AddEdge --> NextFace
NextFace --> End(["结束"])
```

### 拓扑结构构建与邻接图
- 构建原始邻接图 raw_adj：以整数化的二维 Key（x,y）作为节点，记录交点之间的邻接关系

- 构建合并后的邻接图 adj：将代表元相同的点视为同一节点，去除自环

### 环路遍历与闭合检测
- 选择下一个邻居的策略：根据入边方向与出边方向的夹角最小原则选择 next
- 闭合条件：next 回到起点或已访问节点，且路径长度满足最小多边形要求（≥3 个点）
- 自相交处理：若 next 已在当前路径中，则切分出子环并标记 closed

```mermaid
flowchart TD
Start(["开始遍历"]) --> PickNext["pick_next(cur, prev, neis)"]
PickNext --> CheckStart{"next == start 或 is_same_point(next,start)？"}
CheckStart --> |是| CloseLoop["闭合环，加入结果"]
CheckStart --> |否| CheckVisited{"visited[next] 存在？"}
CheckVisited --> |是| SelfIntersect["检测到自相交，切分子环"]
CheckVisited --> |否| Move["prev=cur; cur=next"]
Move --> PickNext
CloseLoop --> End(["结束"])
SelfIntersect --> End
```

## 性能与并行优化
- 拓扑复用：BuildSliceTopology 仅构建一次，SliceLayer 多次调用，避免每层 O(总面数) 的重建开销
- 并行切片：ParallelForLayers 将层索引分配到线程池，块状提交任务，减少进度回调频率
- 线程池规模：默认硬件并发数，可通过环境变量 HSBA_PIPELINE_THREADS 强制设置（例如设为 1 进行串行对比）
- 单核/单层回退：当线程数为 1 或层数为 1 时自动回退串行路径，保证行为一致

## 精度、容差与自相交处理
- 坐标整数化：使用 integerization 将浮点坐标转为整型 Key，提升哈希与比较效率
- 容差处理：coord_eps = max(1, round(tolerance * integerization))，用于判定两点是否相同
- 点合并：网格分桶 + 并查集，合并 coord_eps 范围内的相近点，避免微小误差导致拓扑断裂
- 自相交检测：在环路遍历过程中，若 next 已在当前路径中，则切分出子环，并标记 closed=false（Open polyline）
- 闭合检测：当 next 回到起点或已访问节点，且路径长度满足最小多边形要求，则闭合环

```mermaid
flowchart TD
Tolerance["tolerance -> coord_eps"] --> Integerize["坐标整数化 Key"]
Integerize --> GridBucket["网格分桶"]
GridBucket --> MergeNearby["并查集合并相近点"]
MergeNearby --> Traverse["环路遍历"]
Traverse --> SelfIntersect{"next 在当前路径中？"}
SelfIntersect --> |是| SubLoop["切分子环，closed=false"]
SelfIntersect --> |否| Closed{"next==start 或 visited[next]？"}
Closed --> |是| Close["闭合环，closed=true"]
Closed --> |否| Continue["继续遍历"]
```

## 错误检测与修复策略
- 拓扑完整性检查：CheckTopo 验证顶点/边/面引用一致性；SliceFast 在拓扑无效时抛出异常
- 外部异常转换：GuardSlice 将 CGAL/OCCT 等第三方库异常统一转换为 IOError，避免跨边界传播
- Lua 错误处理：Lua 初始化、加载、运行错误均抛出 RuntimeError，并提供错误信息
- 开放轮廓过滤：NormalizeUnSafePolygons 过滤掉非闭合或非简单多边形，确保下游处理稳定

## 使用示例与参数调优指南
- 基本用法
  - 安全切片：调用 Slice(model, height, tolerance)，返回闭合多边形
  - 不安全切片：调用 UnSafeSlice(model, height, tolerance)，返回可能开放的轮廓
  - Lua 切片：调用 SliceLua(model, script, height)，通过脚本自定义切片逻辑

  - layer_height / first_layer_height：影响层数与首层质量

  - HSBA_PIPELINE_THREADS：控制并行线程数，设为 1 可进行串行对比测试
- 流水线集成
  - SLA/SLM/SLS 流水线在“切片阶段”调用 BuildSliceTopology 与 SliceLayer，并使用 ParallelForLayers 并行执行

## 故障排查
- 拓扑无效
  - 现象：SliceFast 抛出异常
  - 排查：检查 CheckTopo 返回值，确认顶点/边/面引用一致性
- 切片结果为空或异常
  - 现象：Polygons 为空或出现开放轮廓
  - 排查：调整 tolerance，检查 NormalizeUnSafePolygons 的过滤逻辑
- 并行性能不佳
  - 现象：多线程下速度不如串行
  - 排查：设置 HSBA_PIPELINE_THREADS=1 进行对比，检查任务粒度与线程池规模
- Lua 脚本错误
  - 现象：运行时抛出 RuntimeError
  - 排查：检查脚本语法与返回表结构，确认 V/E/F 与 height 是否正确推送

## 结论
HsBaSlicer 的切片引擎以 FullTopoModel 为核心，实现了稳健的层平面与网格相交计算、完整的拓扑重建、精确的点合并与自相交检测，并通过 BuildSliceTopology + SliceLayer 实现高效的拓扑复用。配合 ParallelForLayers 与 ThreadPool，切片流水线在多核环境下具备良好扩展性。针对精度与容差，系统提供了灵活的参数控制；针对错误与异常，提供了统一的转换与检测机制。开发者可根据具体工艺需求，选择合适的切片模式与安全级别，并结合 Lua 脚本进行定制化扩展。
