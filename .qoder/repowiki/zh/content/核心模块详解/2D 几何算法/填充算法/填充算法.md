## 详细组件分析

### 直线填充 LineFill
- 数学原理
  - 计算填充方向单位向量 u=(cosθ, sinθ)，与其垂直的法向 v=(-sinθ, cosθ)。
  - 沿法向以间距 spacing 步进，构造长条矩形带，与输入多边形求交得到若干片段。
  - 对每个片段投影到 u 方向，取最小/最大投影值作为线段端点，排序后输出为独立线段集合。
- 关键参数
  - spacing：平行线间距
  - angle_deg：填充角度（度）
  - lineThickness：用于锯齿类算法控制桥接采样步长（在 LineFill 中主要用于内部辅助）
- 适用场景
  - 需要简单、快速、可预测的直线路径
  - 对拐角过渡要求不高，或后续路径优化会处理连接性
- 复杂度
  - 设扫描行数 R，每行片段数 K，则时间复杂度约 O(R·K log K)（排序），空间复杂度 O(R·K)

```mermaid
flowchart TD
Start(["开始"]) --> ComputeDir["计算方向向量 u,v"]
ComputeDir --> ScanRows["沿法向步进生成矩形带"]
ScanRows --> Intersect["与多边形求交得到片段"]
Intersect --> Project["投影到 u 方向求 s_min/s_max"]
Project --> SortSegs["按 s_min 排序片段"]
SortSegs --> EmitLines["输出独立线段"]
EmitLines --> End(["结束"])
```

### 简单锯齿填充 SimpleZigzagFill
- 数学原理
  - 复用 LineFilling 的行片段数据。
  - 对偶数行从左到右遍历，奇数行从右到左遍历，将相邻行的有效片段中心点连接，形成连续蛇形折线。
  - 使用二分查找确定片段与多边形边界的精确进入/离开点，避免越界。
- 关键参数
  - spacing、angle_deg、lineThickness
- 适用场景
  - 需要单条连续路径以减少抬刀次数
  - 形状相对规则，连通性较好
- 复杂度
  - 构建行片段 O(R·K)，连接过程 O(R·K)，整体近似线性于片段数量

```mermaid
flowchart TD
S0["开始"] --> Rows["获取各行片段"]
Rows --> EvenRow{"偶数行?"}
EvenRow --> |是| TraverseEven["从左到右遍历片段"]
EvenRow --> |否| TraverseOdd["从右到左遍历片段"]
TraverseEven --> Connect["连接相邻行片段中心"]
TraverseOdd --> Connect
Connect --> Clamp["二分查找边界进入/离开点"]
Clamp --> Output["输出连续折线"]
Output --> E0["结束"]
```

### 高级锯齿填充 ZigzagFill
- 数学原理
  - 同样基于行片段，但引入“连通分量”思想：
    - 将相邻行的片段区间做重叠判断，使用并查集合并属于同一连通分量的片段。
    - 对每个连通分量构建一条或多条折线，必要时沿外轮廓走最短弧进行桥接，避免穿越空洞。
  - 当桥接失败时，回退到仅连接中点在多边形内的情况，否则将未连接的片段作为额外直线输出。
- 关键参数
  - spacing、angle_deg、lineThickness
- 适用场景
  - 复杂凹多边形、存在多个岛屿或孔洞
  - 需要更稳健的连接与绕障桥接
- 复杂度
  - 并查集操作近似 O(N α(N))，N 为片段总数；区间重叠比较在最坏情况下 O(R^2·K^2)，实际可通过索引优化降低

```mermaid
flowchart TD
Z0["开始"] --> BuildSegList["扁平化片段列表"]
BuildSegList --> UnionFind["并查集合并相邻行重叠片段"]
UnionFind --> Components["划分连通分量"]
Components --> BuildPolyline["逐分量构建折线"]
BuildPolyline --> BridgeCheck{"需要桥接?"}
BridgeCheck --> |是| BuildBridge["沿外轮廓最短弧桥接"]
BridgeCheck --> |否| AppendSeg["直接追加片段"]
BuildBridge --> AppendSeg
AppendSeg --> ExtraLines["收集无法连接的额外线段"]
ExtraLines --> Z1["结束"]
```

### 偏移填充 OffsetFill
- 数学原理
  - 反复对输入多边形执行向内偏移（负 delta），直到结果为空。
  - 每次偏移结果闭合为首尾重合的多边形环，作为填充路径输出。
- 关键参数
  - spacing：偏移步长
  - join_type：拐角连接类型（Square/Bevel/Round/Miter）
- 适用场景
  - 需要多层同心轮廓填充，常用于边框或薄壁增强
- 复杂度
  - 迭代次数受 MAX_FILL_ITERATIONS 限制；每次偏移复杂度取决于底层几何库

```mermaid
flowchart TD

CheckSpacing --> |是| ReturnEmpty["返回空结果"]
CheckSpacing --> |否| LoopStep["step=1..MAX"]
LoopStep --> Offset["Offset(poly, -spacing*step)"]
Offset --> EmptyCheck{"结果为空?"}
EmptyCheck --> |是| Break["跳出循环"]
EmptyCheck --> |否| ClosePath["闭合每条环"]
ClosePath --> Collect["收集结果"]
Collect --> LoopStep
Break --> O1["结束"]
```

### 复合填充 CompositeOffsetFill
- 数学原理
  - 对原始多边形分别进行外扩（outwardCount 层）和内缩（inwardCount 层）。
  - 对每一层偏移后的多边形应用内部填充（Line/SimpleZigzag/Zigzag）。
  - 将所有层的填充结果合并输出。
- 关键参数
  - spacing：内部填充间距
  - offsetStep：偏移步长
  - outwardCount/inwardCount：外扩/内缩层数
  - mode：内部填充模式
  - angle_deg：填充角度
  - join_type：偏移拐角类型
- 适用场景
  - 需要“边框 + 内部填充”的组合效果，例如外壁强化与内部支撑结合

```mermaid

OutLoop --> InLoop["内缩 inwardCount 层"]
InLoop --> Merge["合并所有层填充结果"]
Merge --> C1["结束"]
```

### 混合填充 HybridFill
- 数学原理
  - 先输出若干外扩偏移轮廓（不填充），然后逐步内缩，直到面积小于阈值或顶点数不足，停止继续内缩。
  - 对最后一步的内缩结果（可能为空）执行内部填充，并将之前输出的偏移轮廓与填充结果合并。
- 关键参数
  - spacing、offsetStep、outwardCount、inwardCount、mode、angle_deg、lineThickness、join_type
- 适用场景
  - 需要“外部轮廓 + 局部内部填充”的效果，适合薄壁与内部强度平衡

```mermaid
flowchart TD
H0["开始"] --> OutOffsets["输出 outwardCount 个外扩轮廓"]
OutOffsets --> InOffsets["逐步内缩，检查面积/顶点数"]
InOffsets --> FinalOffs["记录最后一次有效内缩结果"]
FinalOffs --> FillFinal["对最终偏移区域执行内部填充"]
FillFinal --> Combine["合并轮廓与填充结果"]
Combine --> H1["结束"]
```

## 性能与复杂度
- 通用优化建议
  - 合理设置 spacing：过密会增加片段数量与几何运算量
  - 控制 outwardCount/inwardCount：层数越多，偏移与填充次数越多
  - 选择合适的 join_type：Round/Miter 可能增加几何复杂度
- 算法特性
  - LineFill：O(R·K log K)，适合快速直线路径
  - SimpleZigzagFill：近似 O(R·K)，连接开销低
  - ZigzagFill：并查集与桥接带来额外开销，但在复杂形状下更稳健
  - OffsetFill/CompositeOffsetFill/HybridFill：受偏移次数与内部填充模式影响
- 内存管理
  - 大量片段与中间多边形应尽量避免重复拷贝
  - 使用 reserve 预分配容器减少重分配
  - Lua 自定义填充返回的表需及时释放，避免长时间持有大对象

## 故障排查
- 常见问题
  - spacing <= 0：OffsetFill 直接返回空结果
  - 非相邻行连接：SimpleZigzag/Zigzag 仅允许同层或相邻层连接，避免环路
  - 桥接失败：ZigzagFill 回退到中线检测或输出额外直线
  - Lua 脚本错误：加载或调用失败会抛出运行时异常
- 定位方法
  - 检查输入多边形是否有效（顶点数、面积符号）
  - 调整 join_type 与 lineThickness
  - 在 Lua 脚本中打印中间结果或使用测试用例对比
