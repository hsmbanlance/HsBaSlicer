## 简介

HsBaSlicer是一个3D模型切片库，提供C++接口用于加载3D模型、执行切片操作并生成二维多边形轮廓。本指南将指导新手用户从零开始构建和运行HsBaSlicer项目，涵盖环境准备、项目配置、构建过程以及API使用方法。

## 环境准备

在开始构建HsBaSlicer之前，需要准备必要的开发工具和依赖项。根据操作系统不同，安装步骤有所区别。

### Windows环境

对于Windows用户，推荐安装Visual Studio 2022或更高版本，并在安装过程中选择"使用C++的桌面开发"工作负载，确保包含CMake和vcpkg组件。同时需要安装Git用于克隆仓库。

不支持MinGW/MSYS2等编译环境。

### Linux环境

对于Linux用户，建议使用Ubuntu 20.04或Debian 10.0以上版本。需要安装以下开发包：

```bash
sudo apt install libx11-dev mesa-common-dev libglu1-mesa-dev libxi-dev libxmu-dev libxmu-headers libxrender-dev libxtst-dev autoconf-archive
```

如果需要编译MySQL相关组件，还需安装：

```bash
sudo apt install libncurses-dev libtirpc-dev
```

编译PostgreSQL相关组件需要：

```bash
sudo apt install bison flex
```

如果使用OpenCASCADE，需要安装：

```bash
sudo apt install -y libfontconfig1-dev
```

### 通用工具

无论哪个平台，都需要安装以下核心工具：

- **CMake**（≥3.12版本）：用于项目配置和构建
- **Git**：用于克隆代码仓库
- **vcpkg**：用于管理C++依赖库

编译器需要支持C++20标准。

## 项目克隆与配置

### 克隆仓库

首先使用Git克隆HsBaSlicer仓库：

```bash
git clone https://github.com/hsmbanlance/HsBaSlicer.git
cd HsBaSlicer
```

### 安装vcpkg

vcpkg是本项目依赖的包管理器。按照以下步骤安装：

```bash
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
./bootstrap-vcpkg.sh  # Linux/macOS
# 或 bootstrap-vcpkg.bat (Windows)
```

建议将vcpkg的安装路径添加到环境变量`VCPKG_ROOT`中，以便CMake预设能够自动找到它。

### 配置文件说明

- `CMakePresets.json`：定义了不同平台的构建预设
- `vcpkg.json`：声明了项目依赖的第三方库
- `vcpkg-configuration.json`：配置了vcpkg的注册表源

## 构建项目

HsBaSlicer支持通过命令行或IDE进行构建，利用CMakePresets.json中的预设简化配置过程。

### 使用CMake预设构建

项目提供了多个预设配置，适用于不同平台和构建类型：

- `x64-debug`：Windows平台调试版本
- `x64-release`：Windows平台发布版本
- `linux-debug`：Linux平台调试版本
- `linux-release`：Linux平台发布版本

#### Windows构建步骤

1. 确保已安装Visual Studio 2022和vcpkg
2. 设置环境变量`VCPKG_ROOT`指向vcpkg安装目录
3. 在项目根目录打开命令行，执行：

```bash
cmake --preset x64-debug
cmake --build --preset x64-debug
```

#### Linux构建步骤

1. 安装必要的开发包和工具链：

```bash
sudo apt install g++ gdb make ninja-build rsync zip
```

2. 构建项目：

```bash
cmake --preset linux-debug
cmake --build --preset linux-debug
```

或者使用传统方式：

```bash
mkdir build
cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build .
```

### 使用IDE构建

#### Visual Studio 2022

1. 打开HsBaSlicer文件夹
2. CMake会自动检测CMakePresets.json并配置项目
3. 在"解决方案资源管理器"中选择适当的构建配置（如x64-debug）
4. 点击"全部生成"按钮

#### 其他IDE

大多数现代IDE（如CLion、VS Code）都支持CMake Presets功能，可以直接导入项目并选择相应的预设进行构建。

## API使用示例

本节提供两种API使用方式的完整示例：传统的底层API和新的FDM管道API。

### 传统API使用示例

```cpp
#include "DllHsBaSlicer/initialize.h"
#include "meshmodel/IglModel.hpp"
#include "LibHsBaSlicer/Slice/mesh_slice.hpp"
#include "base/ModelFormat.hpp"

#include <iostream>
#include <filesystem>

int main() {
    // 1. 初始化库
    initialize();
    
    // 2. 创建模型实例
    HsBa::Slicer::IglModel model;
    
    // 3. 加载STL模型
    std::string modelPath = "example.stl";
    if (!std::filesystem::exists(modelPath)) {
        std::cerr << "模型文件不存在: " << modelPath << std::endl;
        return -1;
    }
    
    if (!model.Load(modelPath)) {
        std::cerr << "加载模型失败: " << modelPath << std::endl;
        return -1;
    }
    
    std::cout << "成功加载模型: " << modelPath << std::endl;
    
    // 4. 获取模型信息
    Eigen::Vector3f min, max;
    model.BoundingBox(min, max);
    float volume = model.Volume();
    
    std::cout << "边界框: (" << min.transpose() << ") - (" << max.transpose() << ")" << std::endl;
    std::cout << "体积: " << volume << std::endl;
    
    // 5. 设置切片参数并执行切片
    float layerHeight = 0.2f; // 层高200微米
    float maxHeight = max.z();
    
    for (float z = 0.0f; z < maxHeight; z += layerHeight) {
        // 调用切片函数获取二维多边形轮廓
        auto polygons = HsBa::Slicer::Slice(model, z);
        
        std::cout << "Z=" << z << "mm: " << polygons.size() << "个轮廓" << std::endl;
        
        // 处理每个轮廓
        for (size_t i = 0; i < polygons.size(); ++i) {
            const auto& polygon = polygons[i];
            std::cout << "  轮廓" << i << ": " << polygon.size() << "个点" << std::endl;
            
            // 输出前几个点的坐标
            for (size_t j = 0; j < std::min(polygon.size(), size_t(3)); ++j) {
                std::cout << "    (" << polygon[j].x << ", " << polygon[j].y << ")";
            }
            if (polygon.size() > 3) {
                std::cout << "...";
            }
            std::cout << std::endl;
        }
    }
    
    return 0;
}
```

### FDM管道API使用示例

```cpp
#include "fdm_pipeline.h"
#include "logger/logger.hpp"

// 进度回调函数
void OnProgress(int percent, const char* stage, void* user_data) {
    LoggerSingletone::LogInfo(std::format("[{}%] {}", percent, stage));
}

// 结果回调函数（异步）
void OnPipelineComplete(HsBaFdmPipelineResult_t result, void* user_data) {
    if (result.success) {
        LoggerSingletone::LogInfo(std::format("切片完成! 总层数: {}, 耗时: {:.2f} 秒", 
                                            result.total_layers, result.elapsed_seconds));
    } else {
        LoggerSingletone::LogInfo(std::format("切片失败: {}", 
                                           result.error_message ? result.error_message : "未知错误"));
    }
    HsBaFreePipelineResult(&result);
}

int main() {
    // 1. 创建默认配置
    HsBaFdmPipelineConfig_t cfg = HsBaCreateDefaultConfig();
    
    // 2. 设置模型
    cfg.model_name = "stanford_bunny";
    cfg.model_path = "models/stanford_bunny.stl";
    
    // 3. 配置工艺参数
    cfg.layer_height = 0.2f;           // 层高0.2mm
    cfg.first_layer_height = 0.25f;    // 首层0.25mm
    cfg.fill_spacing = 0.4;            // 填充间距0.4mm
    cfg.fill_mode = HSBA_FILL_ZIGZAG;  // 锯齿形填充
    cfg.fill_angle = 45.0;             // 填充角度45度
    cfg.wall_count = 3;                // 壁厚3圈
    cfg.top_layer_count = 5;           // 顶层5层实心
    cfg.bottom_layer_count = 4;        // 底层4层实心
    cfg.infill_density = 0.15;         // 中间层填充率15%
    
    // 4. 配置支撑参数
    cfg.enable_support = 1;            // 启用支撑
    cfg.overhang_angle = 50.0f;        // 悬垂阈值50度
    cfg.support_pattern = HSBA_SUPPORT_TREE; // 树状支撑
    
    // 5. 配置路径参数
    cfg.line_width = 0.4f;             // 线宽0.4mm
    cfg.print_speed = 60.0f;           // 打印速度60mm/s
    cfg.travel_speed = 120.0f;         // 移动速度120mm/s
    cfg.extrusion_multiplier = 1.0f;   // 挤出倍率1.0
    
    // 6. 设置输出路径
    cfg.output_path = "output/stanford_bunny.gcode";
    
    // 7. 同步运行管道
    HsBaFdmPipelineResult_t result = HsBaRunFdmPipeline(&cfg, OnProgress, nullptr);
    
    if (result.success) {
        std::cout << "切片成功! 总层数: " << result.total_layers 
                  << ", 耗时: " << result.elapsed_seconds << " 秒" << std::endl;
    } else {
        std::cout << "切片失败: " << (result.error_message ? result.error_message : "未知错误") << std::endl;
    }
    
    // 8. 释放结果内存
    HsBaFreePipelineResult(&result);
    
    return 0;
}
```

## 常见问题排查

在构建和使用HsBaSlicer时可能会遇到一些常见问题，以下是解决方案。

### vcpkg路径未设置

**问题现象**：CMake配置失败，提示找不到vcpkg.toolchain.cmake

**解决方案**：
1. 确认vcpkg已正确安装
2. 设置环境变量`VCPKG_ROOT`指向vcpkg根目录
3. 重启命令行或IDE使环境变量生效

### C++标准不匹配

**问题现象**：编译错误，提示C++20特性不支持

**解决方案**：
1. 确认编译器版本支持C++20（如MSVC 19.29+，GCC 10+，Clang 10+）
2. 检查CMakeLists.txt中C++标准设置：

```cmake
if(CMAKE_VERSION VERSION_GREATER 3.12)
  set(CMAKE_CXX_STANDARD 20)
endif()
```

### 依赖库安装失败

**问题现象**：vcpkg安装依赖库时失败

**解决方案**：
1. 确保网络连接正常
2. 更新vcpkg到最新版本：

```bash
./vcpkg update
./vcpkg upgrade
```

3. 检查vcpkg-configuration.json中的注册表配置

### Stanford Bunny模型下载失败

**问题现象**：FDM示例构建时无法下载Stanford Bunny模型

**解决方案**：
1. 检查网络连接是否正常
2. 手动下载模型文件：
   ```bash
   mkdir -p samples/FDM/models
   wget https://upload.wikimedia.org/wikipedia/commons/4/43/Stanford_Bunny.stl \
        -O samples/FDM/models/stanford_bunny.stl
   ```
3. 重新构建项目

### 平台特定问题

#### Windows
- 确保使用Visual Studio而非MinGW
- 检查是否安装了"使用C++的桌面开发"工作负载

#### Linux
- 确保安装了X11开发包
- 检查是否安装了所有必要的开发工具：

```bash
sudo apt install pkg-config automake libtool m4 autoconf python3-distutils
```
