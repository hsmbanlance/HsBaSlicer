## 核心概念
- 多边形输入：填充阶段接收的是当前层轮廓多边形集合，通常已扣除壁厚区域。
- 整数化坐标：内部使用整数坐标进行布尔运算与偏移，避免浮点误差。
- 填充模式：
  - 直线填充：按角度生成平行扫描线，裁剪后得到线段。
  - 简单折线填充：连接相邻扫描段形成连续折线。
  - 高级折线填充：通过连通性分析与桥接逻辑生成更稳健的连续路径。
  - 偏移组合填充：对基础多边形做内外偏移，再对偏移结果应用内部填充。
  - 混合填充：先输出若干偏移边界，再对最内层有效区域填充。
- Lua 自定义填充：通过 `generate_fill` 函数返回多边形或折线数组，胶水负责类型转换与错误处理。

## 详细组件分析

### 直线填充算法
直线填充的核心思想：
- 计算多边形边界框与投影范围。
- 沿指定角度生成等距扫描矩形条。
- 与原始多边形求交，提取每个扫描条内的线段区间。
- 将区间转换为独立线段输出。

```mermaid
flowchart TD
A["输入 Polygons"] --> B["UnIntegerization 转浮点"]
B --> C["计算 min/max 坐标"]
C --> D["计算角度方向 ux, uy 与垂直方向 vx, vy"]
D --> E["遍历扫描位置 t += spacing"]
E --> F["构造扫描矩形并与 poly 求交"]
F --> G["在每个交集中计算 s_min/s_max"]
G --> H["排序并按 u 方向确定端点 a,b"]
H --> I["输出独立线段"]
```

### 简单折线填充算法
简单折线填充在直线扫描基础上，尝试将相邻扫描段的中心连接成连续折线：
- 对每条扫描段进行“向内收缩”以避开边界。
- 使用二分搜索找到段与多边形内部的第一个/最后一个交点。
- 仅允许同一行或相邻行之间连接，避免跨行跳变。
- 将折线点集转换为整数多边形输出。

```mermaid

A["直线扫描 rows"] --> B["按行顺序处理"]
B --> C["对每段收缩 eps 并找内部交点 t0,t1"]
C --> D{"是否有效内部段"}
D --> |否| E["直接输出该段"]
D --> |是| F["尝试连接到上一段"]
F --> G{"同行或相邻行"}
G --> |是| H["追加 aa,bb 到当前折线"]
G --> |否| I["开启新折线"]
H --> J["继续下一段"]
I --> J
J --> K["将所有折线转为整数 Polygon"]
```

### 高级折线填充算法
高级折线填充进一步改进连通性与边界桥接：
- 对相邻行的扫描段进行区间重叠判断，使用并查集构建连通分量。
- 当不同分量且位于相邻行时，尝试沿外环走最短弧进行桥接。
- 若桥接失败，回退到中线点是否在内部作为连接条件。
- 收集额外无法连接的直线段，最后统一输出。

```mermaid

A["rows 排序"] --> B["扁平化为 segList"]
B --> C["并查集 unite 相邻行重叠段"]
C --> D["计算连通分量 compId"]
D --> E["遍历行构建 polylines"]
E --> F{"同分量或同行/相邻行"}
F --> |是| G["直接连接 aa,bb"]
F --> |否| H["尝试 build_bridge 沿外环桥接"]
H --> I{"桥接成功?"}
I --> |是| J["插入桥接路径"]
I --> |否| K["中线点检查或拆分段"]
G --> L["输出折线"]
J --> L
K --> L
```

## 性能与优化
- 内存管理：
  - 内部使用整数坐标减少浮点误差，避免重复分配大对象。
  - 扫描行与线段列表按需增长，避免预分配过大缓冲区。
- 计算复杂度：
  - 直线填充复杂度与扫描行数 × 多边形顶点数相关。
  - 高级折线填充引入并查集与相邻行区间比较，复杂度随扫描段数量增加而上升。
- 并行处理：
  - C++ 填充可并行执行，Lua 填充因共享解释器需串行。
  - 顶层/底层使用实心填充，中间层根据密度调整间距以减少计算量。
- 优化建议：
  - 合理设置间距与角度，避免过密扫描。
  - 对于复杂形状优先使用组合偏移填充，减少内部填充区域。
  - 在 Lua 脚本中尽量复用几何操作，避免重复计算。
