- 填充算法的 C++ 与 Lua 双入口规范；
- `generate_fill` 函数的参数格式与返回值约定；
- `PolygonOperations` 工具函数在脚本中的使用方法；
- 边界框计算、扫描线生成、多边形布尔运算等核心步骤；
- 性能优化建议、调试方法与常见陷阱。

## 核心概念
### 输入与输出类型
- 输入：当前层多边形数组，C++ 侧为 `Polygons`，Lua 侧为 `{ { {x=.., y=..}, ... }, ... }`。
- 输出：填充路径的多边形集合，C++ 侧返回 `Polygons`，Lua 脚本需返回由点表组成的多边形数组。

### 填充模式枚举
`FillMode` 定义三种内置模式：
- `Line`：平行直线填充；
- `SimpleZigzag`：简单锯齿形填充；
- `Zigzag`：改进角点处理的锯齿形填充。

### 关键 C++ 接口
- `OffsetFill`：向内偏移生成同心环；
- `LineFill`：按角度生成独立直线段；
- `SimpleZigzagFill`：连接相邻行线段形成连续折线；
- `ZigzagFill`：更复杂的连通性处理与桥接逻辑；
- `CompositeOffsetFill`：先内部填充，再叠加内外偏移层；
- `HybridFill`：先外扩轮廓，再向内偏移直到最小面积阈值，最后对最内层填充；
- `LuaCustomFill` / `LuaCustomFillString`：通过 Lua 脚本生成填充。

### 内置填充算法流程

#### 直线填充
`LineFill` 的核心是扫描线构造：
1. 将输入多边形转为浮点坐标；
2. 计算包围盒与投影范围；
3. 沿法向步进生成矩形条带；
4. 与原始多边形求交得到每行的有效线段；
5. 输出每个线段作为独立多边形。

```mermaid
flowchart TD
Start(["进入 LineFill"]) --> Unint["UnIntegerization 转浮点坐标"]
Unint --> BBox["计算包围盒 min/max"]
BBox --> Proj["计算投影范围 minProj/maxProj"]
Proj --> Scan["沿法向步进生成矩形条带"]
Scan --> Clip["Intersection 与原始多边形求交"]
Clip --> Segments["提取每行有效线段"]
Segments --> Output["输出独立线段多边形"]
Output --> End(["结束"])
```

#### 简单锯齿形填充
`SimpleZigzagFill` 在扫描线基础上连接相邻行线段：
1. 使用 `LineFilling` 获取行线段；
2. 对偶数行顺序遍历，奇数行逆序遍历；
3. 使用二分查找裁剪线段端点到多边形内部；
4. 仅允许同一行或相邻行连接；
5. 输出连续折线。

#### 高级锯齿形填充
`ZigzagFill` 进一步处理复杂连通性：
1. 排序每行线段；
2. 扁平化所有线段并建立并查集；
3. 根据区间重叠连接相邻行；
4. 构建连通分量；
5. 尝试桥接不同分量的相邻行；
6. 失败时回退到中线检测或额外直线段。

```mermaid

UnionFind --> Components["划分连通分量"]
Components --> Bridge{"需要桥接?"}
Bridge --> |是| BuildBridge["沿外轮廓采样构建桥接路径"]
Bridge --> |否| ConnectSame["直接连接同分量"]
BuildBridge --> CheckMid["检查中点是否在多边形内"]
CheckMid --> |是| ConnectFallback["回退到中线连接"]
CheckMid --> |否| ExtraLines["记录额外直线段"]
ConnectSame --> Convert["转换为整数多边形"]
ConnectFallback --> Convert

Convert --> End(["结束"])
```

## 性能与优化
### 空间分割
- 扫描线算法已按法向步进生成矩形条带，避免全图扫描；
- 对于复杂多边形，可先用 `offsetOperation` 缩小区域，减少后续布尔运算规模。

### 并行处理
- 当前实现以单线程为主，若需并行，可在脚本层对多个不相连区域分别生成填充后合并；
- 注意 Lua 状态与 C++ 对象的生命周期管理。

### 内存管理
- `LineFilling` 会临时存储浮点多边形与行线段，建议在脚本中避免返回过多小多边形；
- `ZigzagFill` 的并查集与连通分量计算可能产生较大中间结构，应控制输入多边形复杂度。

### 布尔运算优化
- 尽量复用 `PolygonOperations.union` / `intersection` / `difference`，避免重复构造相同几何；
- 使用 `offsetOperation` 预裁剪可减少后续交集计算量。
