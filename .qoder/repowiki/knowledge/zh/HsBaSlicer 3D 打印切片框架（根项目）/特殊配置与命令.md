构建入口为顶层 `CMakeLists.txt`，推荐使用 `CMakePresets.json` 中的预设（如 `linux-release`、`windows-release`）；vcpkg 工具链通过 `-DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake` 注入。关键选项：`HSBA_COPL=AUTO|ON|OFF`（控制 CGAL/OpenCASCADE 及许可证切换）、`HSBA_BUILD_REST_API=ON`（需同时启用 vcpkg manifest feature `rest-api` 以安装 cpp-httplib）、`HSBA_SLICER_MODULE=ON`（C++20 module 包装器，需编译器支持且 GMF 可暴露 TU-local 实体）、`HSBA_SLICER_USE_TESTS`、`HSBA_SLICER_RUN_TESTS_AFTER_BUILD`、`HSBA_PROTOBUF_OUT`（导出多语言 proto 文件）。Windows 下通过 `cmake/HsBaWindowsUtf8.cmake` 嵌入 UTF-8 active code page manifest 以正确处理非 ASCII 路径。
