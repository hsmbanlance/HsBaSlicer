根目录通过顶层 `CMakeLists.txt`（cmake_minimum_required 3.28，C++20/C23）统一编排各子模块的依赖、平台开关与安装导出，形成自底向上的分层结构：
- 基础层：`base`（any_object/static_reflect/delegate/thread_pool/coroutine 等模板工具）、`cipher`（加密/哈希/Lua 绑定）、`logger`（Boost.Log 封装）、`utils`（app_config/struct_json/xml/yaml/LuaAnyObject/LuaDllLoader）。
- 数据与几何层：`proto`（Protobuf 定义，经 vcpkg protobuf 生成 .pb.h/.pb.cc，并可选导出 cpp/cs/java/python/php 多语言绑定）、`meshmodel`（CGAL/IGL 后端 + FullTopoModel）、`cadmodel`（OpenCascade B-Rep，HSBA_COPL 开启时启用）、`pointcloud`（OpenVDB）、`2D`（Clipper2 多边形、FloatPolygons/ImageToPolygons/PolygonFill）、`paths`（GCode/Robot/WeldRobot 路径输出）。
- 算法层：`preprocess`（ModelLoader）、`support`（FdmSupport/SlaSupport/OverhangDetector）、`LibHsBaSlicer`（核心切片接口：Slice/mesh_slice.hpp、Preprocess/model_preprocess.hpp、Support/fdm_support.hpp、Fill/polygon_fill.hpp、Path/path_generator.hpp、Floor/sla_floor.hpp、ParamStore/param_store_ops.hpp、Extends/lua_pipeline.hpp）。
- 流水线编排层：`pipelinetypes`（pipeline_types.h 作为 C ABI 类型契约）、`convert`（PipelineConfig ↔ Msg 双向转换）、`DllHsBaSlicer`（C ABI 动态库，按工艺拆分为 fdm/sla/sls/slm/lom/tdp/waam/file_transfer/custom/param_store_pipeline 等实现，并通过 initialize.cpp 统一注册、event_source_register.cpp 暴露进度事件、lua_register.cpp 注入 Lua 脚本能力）。
- 对外出口：`LibHsBaSlicer`（C++ 静态/共享库 API）、`ModuleHsBaSlicer`（可选 C++20 module hsba_slicer.cppm 包装器）、`restapi`（可选 HsBaSlicerRestServer，基于 cpp-httplib 的 HTTP 服务，经 DllHsBaSlicer C ABI 代理完整流水线，职责=端点路由/JSON/XML 协商/异步作业队列/restapi.ini 配置桥接）。
- 示例与测试：`samples/{FDM,SLA,SLS,SLM,LOM,TDP,WAAM,Custom,LibHsBaSlicer}` 演示各工艺调用；`tests/` 按功能域组织 GoogleTest；`static_tests/` 编译期断言。
依赖方向严格自下而上：restapi → DllHsBaSlicer(pipelinetypes C ABI) + fileoperator(ParamStore) + utils(struct_json)，与 samples/Lua 等直接调用 C ABI 的客户端互不依赖；Copyleft 内核（CGAL/OpenCASCADE）由 HSBA_COPL 三态开关控制，影响许可证（MIT vs GPL-3.0-or-later）。
