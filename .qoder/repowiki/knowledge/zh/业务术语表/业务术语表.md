### ParamStore
- 定义：工艺参数的持久化子系统，基于 SQLite 宽表模型（每个 Config 字段一列），提供 Save/Load/Update/List 等 CRUD 能力，并通过 C-ABI、Lib HsBaSlicer、Lua、Module 四层接口暴露给流水线。可选开启 `cryptoKey` 对整个配置做二进制序列化后 AES-256-CBC 加密，密文存入专用 `param_blob` BLOB 列，其余元数据（param_key/schema_version/created_at/updated_at）保持明文以便查询。
- 别名：参数存储、param_store

### 流水線
- 定义：切片处理的核心抽象——从 CAD 模型到 GCode/路径输出的可组合步骤序列。项目内置 FDM/SLA/SLS/SLM/LOM/TDP/WAAM/3D Print 等多种流水线，并支持通过自定义 Lua 脚本注册新流水线；每步流水线均可通过 protobuf 配置和 AnyObject 类型系统扩展。
- 别名：pipeline、流水线

### AnyObject
- 定义：项目内部的动态值容器与反射桥接类型，承载各流水线步骤的配置字段（int64_t/double/string/nullptr 等），并作为 Lua ↔ C++ 的参数传递载体。通过 GetTypeInfo 特化和 caseXXX 注册函数向 Lua 暴露自定义类型，测试侧还提供 Mockit-like 打桩能力（StubThrow、StubReturn 等）。
- 别名：any_object、AnyObject 类型

### 宽表模型
- 定义：ParamStore 的存储形态——每张表对应一个 Config 类，每个字段映射为一列；加密模式下额外增加 `param_blob` BLOB 列存放序列化后的密文，明文字段列被清空。该模型便于按字段查询，但要求建表时列结构完整（`EnsureTable` 不自动补列）。
- 别名：wide table model、宽表

### ParamCodec
- 定义：ParamStore 的自描述二进制编解码器，把 `{列名 → std::any}` 映射序列化为小端格式（magic "HSB1" + 计数字段 + 每项名/类型标签/值），供加密前序列化与解密后反序列化，当前支持 nullptr/int64_t/double/string 四种类型标签。
- 别名：param_codec、参数编解码器

### 核心模块 / Other 模块
- 定义：覆盖率门禁的两个统计桶。Core 模块 = base/2D/utils/cipher/meshmodel/paths/preprocess/support/LibHsBaSlicer，阈值 ≥ 45%；Other 模块 = 其余源码，阈值 ≥ 25%。static_tests 不参与覆盖率统计，仅用于模板编译检查。
- 别名：core coverage、other coverage、覆盖率门控

### HSBA_PROTOBUF_OUT
- 定义：构建开关，启用后除 C++ 生成头外，还会导出 proto 的多语言绑定（C#/Java/Python/PHP），安装到 `<install_prefix>/share/HsBaSlicer/proto/` 下对应目录。
- 别名：protobuf 多语言导出

### 条件双许可
- 定义：项目的许可策略：构建不包含 CGAL/OpenCascade 等 copyleft 内核时采用 MIT；包含任一 GPL/LGPL 组件时采用 GPL-3.0-or-later。具体许可在配置期由 `vcpkg.json` 的 `features.copyleft` 判定，运行时可通过 `GetVersionInfo().license` 查询。
- 别名：conditional dual license、双许可
