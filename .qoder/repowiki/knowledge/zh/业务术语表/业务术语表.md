### 工艺参数保存流水线
- 定义：基于 AnyObject + SQLAdapter 的参数持久化机制，支持注册自定义类型并提供写入/读取两种操作，用于在不同流水线之间复用已保存的工艺参数。
- 别名：param_store_pipeline、ParamStore

### 自定义 Lua 流水线
- 定义：允许用户通过 Lua 脚本完全定义切片/填充/导出流程的流水线形态，提供同步/异步 C ABI 接口及 protobuf 方式调用，并暴露 `HsBa` 算子表供脚本调用模型管理、切片、坐标转换、填充、支撑、路径、打包等能力。
- 别名：CustomLuaPipeline、custom pipeline、lua pipeline

### 3D Print 流水线
- 定义：面向 3D 打印场景的新增流水线类型，参考 base_config.proto 提供对应 proto 定义、C++ 流水线实现及 Lua 自定义版本，与其他工艺（FDM/SLA/SLS/SLM/TDP/WAAM/LOM/FileTransfer）并列。
- 别名：3D print pipeline、3DPrint

### AnyObject Mock
- 定义：AnyObject 体系中的类似 Mockit 的桩功能，可在编译期通过 `HSBA_ANY_OBJECT_ENABLE_MOCK` 宏开启，支持 stub 返回值/异常、实参匹配返回/异常，配合 `MockRegistry` 在测试中拦截方法调用。
- 别名：mock、Mockit-like、any_object mock

### Layer Spiral（层间螺旋）
- 定义：作为配置项内置接入 WAAM/TDP 工艺的层间螺旋路径算法，并通过 Lua API 暴露给自定义流水线使用。
- 别名：spiral path、layer spiral

### Polygon Dump（多边形转 SVG）
- 定义：通过 `HSBA_POLYGON_DUMP` 编译选项（桌面默认 ON）启用的调试输出能力，将 IntPolygon/FloatPolygons 转换为 SVG 矢量图，便于可视化验证几何处理结果。
- 别名：polygon dump、svg dump
