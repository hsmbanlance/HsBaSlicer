根目录是 CMake 顶层工程（CMakeLists.txt），负责依赖探测、平台/特性开关、子目录装配与 install/export。

- 分层边界：
  - 基础层：`base`（概念、委托、线程池、单例、静态反射）、`utils`（配置/序列化/Lua 绑定）、`logger`、`cipher`、`pipelinetypes`（C ABI 类型定义）、`proto`（Protobuf 消息）。这些库被所有上层模块共享。
  - 数据模型层：`meshmodel`（IGL/CGAL 网格）、`cadmodel`（OpenCascade B-Rep，受 HSBA_COPL 控制）、`pointcloud`（OpenVDB）、`2D`（Clipper2 多边形）、`paths`（GCode/Robot/Points 路径输出）。
  - 算法层：`preprocess`（模型加载）、`support`（FDM/SLA 支撑与悬垂检测）。
  - 集成层：`LibHsBaSlicer`（C++ 全流程 API，按 Slice/Preprocess/Fill/Path/Floor/Support/ParamStore/Transfer/Extends 子目录组织）；`DllHsBaSlicer`（导出 C ABI 的动态库，每个工艺一个 `*_pipeline.{h,cpp}` 实现，通过 `pipeline_convert`/`event_source_register`/`lua_register` 统一注册）。
  - 可选服务层：`restapi`（cpp-httplib HTTP 进程，经 DllHsBaSlicer C ABI 代理流水线，独立于核心引擎）。
  - 可执行入口：`HsBaSlicer`（主程序）、`samples/*`（各工艺示例）、`ModuleHsBaSlicer`（C++20 module wrapper，可选）。
- 构建系统：vcpkg 管理依赖（Boost、Clipper2、miniz/bit7z、protobuf、RapidJSON、Eigen3、OpenSSL、libigl、OpenCV、OpenVDB、sqlpp11、Lua、tinyxml2、yaml-cpp、magic_enum），CGAL/OpenCASCADE 通过 `HSBA_COPL=AUTO|ON|OFF` 三态开关启用并切换许可证（MIT ↔ GPL-3.0-or-later）。
- 依赖方向严格自底向上：restapi → DllHsBaSlicer(pipelinetypes C ABI) + fileoperator(ParamStore) + utils(struct_json)，与 samples/Lua 等直接调用 DLL 的客户端互不依赖。
