模块以 `kernel_types.hpp` 定义跨工艺共享的 `Kernel::GeometryCapture`（每层轮廓/填充/支撑快照）和 `Kernel::Hooks`（进度回调 + 原子取消标志），所有工艺管线通过同一对 `(C-ABI config, Hooks)` 接口被调用。

每个工艺一个 `<工艺>_pipeline.{hpp,cpp}` 文件，暴露 `Run<Process>(const HsBa*PipelineConfig_t&, const Hooks&) -> *Output` 函数，统一返回包含 `success/cancelled/error/elapsed_seconds/total_layers` 的结构体；FDM/SLA 等还附带 `GeometryCapture`。

内部将原 Dll 协程 `RunPipelineAsync` 改写为纯同步实现：在 `.cpp` 内构造本地 `Cfg` 视图（拷贝 C 配置 + 注入 hooks），按固定阶段顺序调用 `Slice` → `Support` → `Fill` → `Path` 等子模块，并通过 `base/parallel.hpp` 的 `ParallelForLayers` 进行层并行、`base/error.hpp` 的 `CancelledError` 抛出取消信号，由上层捕获并映射到输出结构体的 `cancelled` 字段。

依赖方向单向向下：本模块仅依赖 `pipelinetypes/pipeline_types.h`（C ABI 配置）、`2D/FloatPolygons.hpp`、`LibHsBaSlicer/{Slice,Support,Floor,Path,Preprocess}/*` 以及 `base/` 工具；不反向依赖 Dll 或 Module 层，从而保证两者行为一致。
