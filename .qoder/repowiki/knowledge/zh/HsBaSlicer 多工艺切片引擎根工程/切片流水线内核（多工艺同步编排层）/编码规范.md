- 每个工艺的公共 API 以 `Run<Process>(const HsBa*PipelineConfig_t& cfg, const Hooks& hooks) -> *Output` 形式声明于独立头文件，并在同名 .cpp 中实现。
- 进程内状态通过局部 `Cfg` 结构体聚合 C 配置与 native hooks，并提供 `CancelRequested()/CheckCancel()` 辅助方法集中处理取消逻辑。
- 进度上报统一经由 `ReportProgress(cfg, percent, stage_name)` 包装，仅在 `cfg.progress` 非空时调用。
- 失败路径不抛异常，而是设置输出结构的 `success=false` 与 `error` 字符串；取消则额外置 `cancelled=true` 并抛出 `CancelledError` 供外层捕获。
- 几何快照通过可选的 `capture_geometry` 开关控制，仅在开启时填充 `GeometryCapture`，避免无谓开销。
