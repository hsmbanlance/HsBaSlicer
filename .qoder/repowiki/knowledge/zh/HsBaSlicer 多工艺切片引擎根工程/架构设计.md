根 CMakeLists.txt 按依赖方向顺序 add_subdirectory：proto → base → cipher → utils → logger → 2D → paths → fileoperator → meshmodel/cadmodel/pointcloud → preprocess → support → pipelinetypes → convert → LibHsBaSlicer → ModuleHsBaSlicer(可选) → DllHsBaSlicer → HsBaSlicer 可执行文件；restapi 仅在启用 HSBA_BUILD_REST_API 且 vcpkg rest-api feature 激活时加入。
- 对外契约分三层：pipelinetypes/pipeline_types.h（C ABI 类型）、DllHsBaSlicer/*.h（C ABI 入口）、LibHsBaSlicer/Pipeline/*_pipeline.hpp（C++20 同步 API），三者由 convert/ 在 proto 消息与 C++ 结构体之间桥接。
- 构建开关集中在根 CMake：HSBA_COPL 控制 CGAL/OpenCASCADE 是否链接并切换 MIT/GPL 许可；HSBA_SLICER_MODULE 控制 C++20 module wrapper；HSBA_USE_DLL_LOADER/HAS_OPENCV/USE_OPENVDB 等宏在各子模块中条件编译平台相关路径。
- 产物统一输出到 bin/$<CONFIG>，logcfg.ini 与 restapi.ini 在配置阶段复制到该目录；install(EXPORT HsBaSlicerTargets) 导出 HsBaSlicer:: 命名空间供外部 CMake 消费。
