本模块以 `DllHsBaSlicer` 为目标构建一个 SHARED（iOS 下退化为 STATIC）的 C ABI 动态库，通过 `dllexport.h` 中的 `HSBA_SLICER_API` 宏统一标记导出符号。

- 顶层入口：`initialize.cpp/.h` 暴露唯一的 `extern "C" void initialize()`，在 DLL 加载时完成 Lua 函数注册、管线注册与一次性运行时初始化；所有对外 API 均使用 `extern "C"` 包裹以保证 ABI 稳定。
- 管线适配层：每个工艺（FDM/SLS/SLM/LOM/TDP/WAAM/SLA）对应一对 `<xxx>_pipeline.{h,cpp}`，将上层配置结构体转换为内部 `HsBaPipelineTypes` 并调用 `LibHsBaSlicer` 执行；`custom_pipeline.*` 提供完全由 Lua 脚本驱动的通用管线接口（同步/异步 + 进度回调）。
- 横切能力：`model_preprocess.*` 负责模型预处理，`file_transfer_pipeline.*` / `param_store_pipeline.*` 处理文件传输与参数存储，`pipeline_convert.*` 做类型转换，`pipeline_parallel.hpp` 是头内联的并行层辅助（基于 `base/thread_pool.hpp`，按块分发层任务并通过 `HSBA_PIPELINE_THREADS` 环境变量控制线程数）。
- 扩展点：`lua_register.*` 暴露 `HsBaAdd2DFunction/HsBaAdd3DFunction/HsBaAddFileFunction/HsBaAddEventCallback`，允许宿主进程向 Lua 环境注入自定义 2D/3D/文件阶段函数及事件回调；`event_source_register.*` 专门注册 zipper 与数据库事件源回调。
- 版本信息：`version_info.*` 暴露二进制版本查询。
- 依赖方向单向向下：本模块仅作为薄包装层，依赖 `LibHsBaSlicer`、`HsBaPipelineTypes`、`HsBaSlicerBase/Utils/Mesh/2D/Preprocess/Support/Paths/FileOperator/Converter/Proto/Version` 等静态库，不反向引用上层宿主代码。
