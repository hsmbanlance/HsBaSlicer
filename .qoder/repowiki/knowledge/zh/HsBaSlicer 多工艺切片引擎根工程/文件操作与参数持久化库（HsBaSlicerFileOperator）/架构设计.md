模块以 CMake 静态库 `HsBaSlicerFileOperator` 形式暴露，按功能划分为四个相对独立的子层：
- 归档 I/O 层：`IZipper.hpp` / `IUnzipper.hpp` 定义抽象接口；`zipper.cpp` + `unzipper.cpp` 基于 miniz 实现默认 ZIP 压缩/解压，`bit7z_zipper.cpp` + `bit7z_unzipper.cpp` 通过 `HSBA_HSBA_USE_BIT7Z` 编译开关提供 7z 扩展实现；`IUnzipper` 采用 CRTP 模式，配合 `UnzipperStream`（封装 `std::ifstream`/`std::istringstream` 的 `std::variant`）统一返回流式读取。
- SQL 适配层：`sql_adapter.hpp` 在 `HsBa::Slicer::SQL` 命名空间下定义 `ISQLAdapter` 抽象及 `SQLiteAdapter`/`MySQLAdapter`/`PostgreSQLAdapter` 三个后端，均使用 PIMPL + `shared_mutex` 保证线程安全；通过 `#ifdef HSBA_USE_MYSQL` / `HSBA_USE_PGSQL` 条件编译接入不同驱动，并对外暴露 `operator|` 管道语法（`SQLSelect`/`SQLInsert`/`SQLUpdate`/`SQLDelete`/`SQLCreateTable`/`SQLRemoveTable`）。
- 参数反射与存储层：`param_reflect.cpp/.hpp` 用宏 `HSBA_PARAM_FIELD` + `HSBA_PARAM_DEFINE_CONFIG_TYPEINFO` 为 FDM/SLA/SLS/SLM/LOM/TDP/WAAM/Custom/FileTransfer 九种 `PipelineConfig_t` 生成 `TypeInfo` 注册表；`param_schema.cpp` 根据 `PipelineConfigTag` 推导默认表名（如 `hsba_param_fdm`），`param_store.cpp` 借助 `AnyObject::ForeachField` 将结构体字段映射到列完成 Save/Load/List/Update/Delete；`param_convert.cpp` 负责类型转换，`param_codec.cpp` 处理 JSON/文本编解码。
- Lua 桥接与远程执行：`LuaAdapter.cpp` 集中导出 Zipper/Unzipper/SQL Adapter/ParamStore 到 Lua 全局表；`RemoteExecutor.cpp` 提供 `RemoteExecutorConnection` 与 `RemoteExecutorConnectionPool`（轮询池，上限 16）用于向远端服务发送文件。
依赖方向单向向外：本模块依赖 `HsBaSlicerBase`、`HsBaCipher`、`HsBaPipelineTypes`、`miniz`、`rapidjson`、`lua`、可选 `bit7z`、可选 `sqlpp11`（sqlite3/mysql/postgresql），不被上层反向依赖。
