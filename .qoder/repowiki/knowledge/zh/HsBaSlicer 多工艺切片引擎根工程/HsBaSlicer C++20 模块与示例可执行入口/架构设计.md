本模块由两层组成：
- `ModuleHsBaSlicer/`：CMake 静态库目标，构建一个单文件 C++20 module（`hsba_slicer.cppm`），对外导出 `export module hsba.slicer;` 及命名空间 `HsBa::Slicer`。该 module 仅做薄封装——将 LibHsBaSlicer 的 free function（如 `LoadModel`、`Slice`、`GenerateAllFdmSupport`、`GenerateGCodePathV2`、`SaveSlsPackageLua` 等）包装为 RAII 的 `Model` 以及按工艺分组的 pipeline 类（`FdmPipeline`、`SlaPipeline`、`SlsPipeline`、`SlmPipeline`、`LomPipeline`、`TdpPipeline`、`WaamPipeline`、`FileTransferPipeline`、`ParamStorePipeline`、`CustomLuaPipeline`），同时 re-export 所有 `HsBaFillMode_t` / `HsBaFdmPipelineConfig_t` 等配置类型供消费者直接使用。
- `HsBaSlicer/`：示例可执行（Android 下为 SHARED 库、iOS 下为 STATIC 库、桌面端为 executable），直接链接底层 `DllHsBaSlicer` 并调用 `HsBaRunFdmPipeline`/`HsBaRunSlaPipeline`/`HsBaRunSlsPipeline` 等 C API 演示用法；通过 `#if defined(ANDROID)/__APPLE__/else` 分支提供 JNI (`Java_com_hsmbanlance_hsbaslicer_example_MainActivity_runPipelineExamples`)、Swift/ObjC 导出 (`HsBaRunPipelineExamples`) 和标准 `main()` 三个入口。
依赖方向单向向下：module → LibHsBaSlicer + HsBaPipelineTypes + Eigen + Clipper2 + Lua；示例程序 → DllHsBaSlicer + HsBaSlicerUtils + HsBaSlicerLog。CMakeLists.txt 显式把 CGAL 传播的 `/fp:strict /fp:except-` 与 `_SCL_SECURE_NO_WARNINGS` 重新 PUBLIC 导出，以保证 BMI 消费方编译期一致。
