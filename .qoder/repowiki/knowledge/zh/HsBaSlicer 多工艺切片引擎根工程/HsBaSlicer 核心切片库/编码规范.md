- 所有对外公开函数在头文件中以 HSBA_SLICER_LIB_API 宏标注导出符号，内部实现仅包含 export.h。
- 每个 .hpp/.cpp 对使用 HSBA_SLICER_LIB_XXX_HPP 形式的 include guard 命名空间保护。
- 公开 API 统一置于 HsBa::Slicer 命名空间下，并通过 Doxygen @brief/@param/@return 注释描述行为与返回值语义。
