本模块是纯示例/演示代码，按打印工艺划分为独立子目录：FDM、SLA、SLS、SLM、LOM、TDP、WAAM 各含一个 `main.cpp` + `CMakeLists.txt` + `scripts/`（可选 Lua 钩子），Custom 子目录则提供一条完整工作流交由 Lua 脚本编排的通用入口；LibHsBaSlicer 单独展示 C++20 module (`import hsba.slicer`) 面向对象 API。

依赖方向单向指向上层构建产物：所有示例通过 `target_link_libraries(... PRIVATE DllHsBaSlicer)` 链接 C ABI 层（`fdm_pipeline.h`、`custom_pipeline.h`、`pipeline_convert.h`、`pipelinetypes/pipeline_types.h`），不直接依赖切片核心源码；Custom 示例还额外链接 `HsBaSlicerLog` 日志库。

API 边界分为三层：
- C ABI：`HsBaCreateDefaultConfig` / `HsBaRun*Pipeline` / `HsBaFreePipelineResult` 等函数族，供 C/C#/Python/Java 调用；
- C++ RAII 类：`Model` / `FdmPipeline` / `CustomLuaPipeline` / `FdmResult` 等，封装在 `hsba.slicer` C++20 module 中；
- Lua 算子表 `HsBa`：`loadModel/slice/fill/toGcode/saveSlaPackage/saveSlsPackage/saveWaamPackage` 等，由 Custom 流水线脚本消费。

Protobuf wire 编解码在 Custom/main.cpp 中以极简手写实现（varint/fixed64/delimited）避免重复注册 protobuf descriptor，仅用于跨语言调用示例。
