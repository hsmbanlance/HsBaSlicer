文档按语言与模块双维度组织：顶层 `en/` 与 `zh/` 下镜像同一套目录结构（`base/`、`utils/`、`cipher/`、`fileoperator/`、`logger/`、`LibHsBaSlicer/`、`DllHsBaSlicer/` 等），每个子目录对应源码中的一个核心模块，每篇 `.md` 对应一个组件或主题；`README.md` 作为双语入口索引。

- 静态 Markdown 文档：由开发者直接维护，不经过构建系统编译。
- API 文档：通过 `Doxyfile`（Doxygen 1.17.0）扫描源码注释，输出到 `doxygen/` 目录；`CMakeLists.txt` 在找到 Doxygen 时注册 `docs` 自定义目标，调用 `${DOXYGEN_EXECUTABLE} ${CMAKE_CURRENT_SOURCE_DIR}/Doxyfile` 执行生成。
- 依赖方向单向：本模块仅消费源码中的头文件注释与仓库内 Markdown，不被源码反向引用。
