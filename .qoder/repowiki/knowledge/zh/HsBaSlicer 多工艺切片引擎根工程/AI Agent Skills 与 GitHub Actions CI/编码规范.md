- SKILL.md 使用 YAML front-matter 声明 `name`、`description`、可选的 `user-invocable` 与 `allowed-tools`，作为 AI agent 的技能注册头。
- `.agents/` 与 `.github/` 下的 skills 目录保持完全镜像结构（`cmake/`、`cpp-modern-features/`），便于本地与 GitHub Copilot 共用同一套技能定义。
- CI workflow 按目标平台拆分为独立文件（linux/macos/windows/android/ios），并通过 `cmake-multi-platform.yml` 抽取公共步骤以减少重复。
