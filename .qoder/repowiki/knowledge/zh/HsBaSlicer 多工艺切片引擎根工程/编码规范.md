- 跨平台特性通过根 CMake 检测后以 HSBA_* 宏（如 HSBA_HAS_CXX_COROUTINES、HSBA_COPL、HSBA_USE_BIT7Z）在子模块中条件编译，而非直接 #ifdef platform。
- 所有子目标统一使用 HsBaSlicer* 前缀命名（HsBaSlicerBase、HsBaSlicerMesh、HsBaSlicerFileOperator 等），并通过 install(EXPORT HsBaSlicerTargets) 以 HsBaSlicer:: 命名空间导出。
- 新增工艺通过同时扩展 LibHsBaSlicer/Pipeline、DllHsBaSlicer、proto、samples 四处实现，保持 C++ 同步 API 与 C ABI 双轨一致。
