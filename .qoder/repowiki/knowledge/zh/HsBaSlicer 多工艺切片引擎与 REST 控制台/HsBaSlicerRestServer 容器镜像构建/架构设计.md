两阶段构建：builder 阶段（ubuntu:24.04）安装 cmake/ninja/vcpkg，通过 `cmake --preset linux-release` 以 `-DHSBA_BUILD_REST_API=ON -DHSBA_SLICER_BUILD_SAMPLES=OFF` 等开关编译 HsBaSlicerRestServer 并 install 到 /opt/hsba-install；runtime 阶段仅拷贝 `/usr/local/` 产物、复制仓库内的 `restapi.ini` 与 `logcfg.ini`（将 host 从 127.0.0.1 改为 0.0.0.0）、创建 hsba 非 root 用户与 /app/data 数据目录，ENTRYPOINT 通过环境变量 HSBA_REST_HOST/HSBA_REST_PORT 注入命令行参数。依赖方向为 docker/Dockerfile → 仓库根 CMakeLists.txt + vcpkg.json + restapi/restapi.ini，镜像本身不耦合 restapi 源码实现。
