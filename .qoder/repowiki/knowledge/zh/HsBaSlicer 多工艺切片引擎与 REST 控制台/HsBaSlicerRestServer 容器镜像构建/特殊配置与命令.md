本地构建命令：`docker build -f docker/Dockerfile -t hsba-rest-api:latest .`（上下文必须是仓库根目录，以便自动应用同目录的 Dockerfile.dockerignore）；运行：`docker run -d -p 8080:8080 -e HSBA_REST_AUTH_TOKEN=<token> hsba-rest-api:latest`；支持 ARG VCPKG_BASELINE 覆盖 vcpkg 基线、ARG HSBA_FEATURES 切换 rest-api/copyleft 特性、ARG JOBS 控制并行度；CI 入口为 `.github/workflows/docker-rest-api.yml`。
