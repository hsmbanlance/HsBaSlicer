模块由两部分组成：
- server.js：无依赖的 HTTP 服务器，仅做两件事——按白名单 ASSETS Map 服务 public/ 下的静态资源（带 CSP、X-Content-Type-Options），并将 /api/* 请求原样转发到 --rest-url 指定的上游 REST 服务；通过 DROPPED_REQUEST_HEADERS/DROPPED_RESPONSE_HEADERS 显式丢弃 hop-by-hop、cookie、origin、referer 等头，并在有 --token 时注入 x-api-key，使浏览器侧无需 CORS。
- public/：纯前端 MVC 应用（index.html + app.css + httphelpers.js + i18n.js + model.js + view.js + app.js），通过 globalThis.HsBaApp.Model/View/Controller 三对象协作，零 DOM 操作库，所有网络调用走 Model.call/callJson，渲染逻辑集中在 View。

依赖方向单向：server.js → node:http/https/fs/path/url；public/*.js 只调 /api/* 端点，不直接访问 REST 服务。测试位于 test/server.test.js 与 test/e2e.test.js，使用 node:test 启动真实 console 实例 + 内嵌 fake REST server 进行集成测试，不引入第三方包。
