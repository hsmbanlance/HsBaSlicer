- HTTP 响应统一通过 sendText/sendJson 两个内部函数构造，附带 Content-Length 与 Cache-Control: no-store，避免手写 res.writeHead。
- 静态资源通过 ASSETS Map 白名单分发，未知路径一律返回 404，禁止对客户端输入做 path.join 目录遍历。
- 请求头转发采用显式黑名单（DROPPED_REQUEST_HEADERS / DROPPED_RESPONSE_HEADERS）而非白名单拷贝，hop-by-hop 与凭据头被明确丢弃。
- CLI 参数解析集中于 parseCliArgs，支持 --flag=value 与环境变量回退，非法值抛出 UsageError（exit code 2），帮助文本由 USAGE 常量生成。
- 前端以 globalThis.HsBaApp 命名空间暴露 Model/View/Controller 三个对象，app.js 作为控制器负责事件绑定与状态驱动，DOM 操作集中在 View。
- 异步 UI 刷新通过 refreshSeq 计数器在 await 后校验是否被新刷新覆盖，防止竞态导致表格闪烁。
