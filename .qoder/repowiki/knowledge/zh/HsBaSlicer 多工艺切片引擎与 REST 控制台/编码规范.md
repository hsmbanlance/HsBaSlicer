- 平台/特性开关通过 CMake option + add_compile_definitions 暴露给源码（如 HSBA_DESKTOP、HSBA_COPL、USE_IGL、USE_OPENVDB、HSBA_HAS_CXX_MODULES），而非硬编码 if(MSVC) 分支。
- 对外稳定接口统一收敛到 DllHsBaSlicer 下的 C ABI 头文件（*_pipeline.h、initialize.h、event_source_register.h 等），内部 C++ 实现不直接暴露给 restapi/samples。
- 配置对象在 C++、protobuf、JSON/XML 三者间通过 convert/* 与 proto/*.proto 双向映射，避免手工编解码散落各处。
- 参数存储走 fileoperator/ParamStore 的反射 Schema 体系（param_reflect.hpp / param_convert.hpp / param_schema.hpp），各工艺 pipeline 复用同一套序列化路径。
