根 CMakeLists.txt 是唯一的装配点：先通过 static_check 探测 C++20 concepts/ranges/source_location/NTTP 等特性，再根据 VCPKG_TARGET_TRIPLET 判定桌面/移动/游戏机平台，依次 add_subdirectory 组装依赖链（proto→base→cipher→utils→logger→2D→paths→fileoperator→meshmodel→[cadmodel|pointcloud]→preprocess→support→pipelinetypes→convert→LibHsBaSlicer→ModuleHsBaSlicer→DllHsBaSlicer→HsBaSlicer），restapi 子目录仅在 HSBA_BUILD_REST_API=ON 且 vcpkg manifest feature rest-api 激活时加入。

跨子模块的耦合契约集中在三处：
- pipelinetypes/pipeline_types.h 作为 DllHsBaSlicer 与 restapi 共享的 C ABI 类型层；
- proto/*.proto + convert/* 在 C++ 与 protobuf JSON/XML 之间做双向转换，供 restapi 端点与 samples/Lua 调用方共用；
- fileoperator/ParamStore 提供参数反射/Schema/持久化，被 LibHsBaSlicer/ParamStore、restapi/config_bridge 以及各工艺 pipeline 共同消费。

可插拔内核由编译期宏开关：HSBA_COPL 控制 CGAL/OpenCASCADE（GPL-3.0-or-later），USE_IGL 启用 libigl 网格内核，USE_OPENVDB 启用点云，USE_OCCT 启用 CAD 内核；HSBA_USE_DLL_LOADER 在桌面平台允许动态加载用户自定义模型/DLL。所有静态库统一以 -fPIC 编译并链接到 DllHsBaSlicer.so，对外仅暴露 dllexport.h 中的 C ABI 头文件，samples/Lua 与 restapi 均通过该 ABI 访问切片能力，互不直接依赖内部实现。
