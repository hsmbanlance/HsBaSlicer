- Lua 绑定采用 CRTP 模式：基类 `LuaAnyObjectNewCastBase` 声明 `GetNewFuncPair`/`GetCastFuncPair`，派生类通过 `LuaAnyObjectNewCastAbstract` 自动拼接 `new_<type>`/`cast_<type>` 函数名。
- Lua 异常通过 `lua_pushstring` + `lua_error` 抛出，错误信息使用 `std::format("Invalid {} object", ...)` 构造。
- 序列化函数对同一类型提供多组重载：`to_json`/`from_json` 针对 `Aggregte`、`Reflectable`、`RapidJsonValueConvertible` 三种概念分别 dispatch，内部实现放在 `detail` 命名空间。
- 对外暴露的公共 API 均位于 `HsBa::Slicer` 或 `HsBa::Slicer::Utils` 命名空间，内部辅助放在匿名或 `detail` 子命名空间。
- 所有头文件使用 `#pragma once` 配合传统 include guard（如 `HSBA_SLICER_GRAPH_HPP`）双重保护。
- 图算法函数通过 `requires` 约束（如 `ArithmeticWeight`、`DirectedGraphTag`、`UndirectedGraphTag`）在编译期限定可用性与参数类型。
