- 对外 C++ API 函数均声明在 `namespace HsBa::Slicer` 中，并以 `HSBA_SLICER_LIB_API` 宏修饰以控制符号导出。
- 每个公开头文件使用 `#ifndef HSBA_SLICER_XXX_HPP` 形式的 include guard，并在注释中以 `@brief` 描述该头职责。
- 可选依赖（CGAL、OCCT）通过 `#ifdef USE_CGAL` / `#ifdef USE_OCCT` 条件编译包裹对应函数声明，保持核心 API 在无这些后端时仍可编译。
- Lua 扩展以 `*Function.*hpp/.cpp` 成对组织（如 `LuaAddFunction`、`EventSourceFunction`），并通过 `lua_pipeline` 统一注册到 `HsBa` 全局表暴露给脚本。
