模块以 `LibHsBaSlicer` 静态/共享库形式构建（CMakeLists.txt），按切片管线阶段划分为子目录：
- `Preprocess/`：模型加载、变换、布尔/厚壳预处理（依赖 HsBaSlicerBase/HsBaSlicerMesh）。
- `Slice/`：沿 Z 轴平面切片，暴露安全/不安全切片及可复用拓扑接口。
- `Fill/`：2D 多边形填充（直线/之字/边框/Lua 自定义）。
- `Path/`：FDM G-code 路径生成、螺旋花瓶模式、SLS/WAAM 导出。
- `Floor/`、`Support/`、`Transfer/`、`ParamStore/`：层底面、支撑、文件传输、参数存储等辅助能力。
- `Extends/`：Lua 扩展层，通过 `lua_pipeline.hpp` 暴露 `SetupLuaPipelineEnvironment` / `RunLuaPipeline`，将上述所有阶段以 `HsBa` 全局表向 Lua 脚本开放，实现完全由 Lua 驱动的自定义流水线。

依赖方向单向向下：本库作为上层编排者，PUBLIC 链接 `HsBaSlicerBase`、`HsBaSlicerMesh`、`HsBaSlicer2D`、`HsBaSupport`、`HsBaPaths`，PRIVATE 链接 `HsBaSlicerUtils`、`HsBaPreprocess`、`HsBaVersion`、`HsBaSlicerFileOperator`；OCCT/CAD 内核仅在启用 `HSBA_COPL` 且非 Android/iOS/游戏主机时可选链接 `HsBaSlicerCADModel`。公共符号统一通过 `export.h` 中的 `HSBA_SLICER_LIB_API` 宏在 Windows 下 dllexport/dllimport，其余平台为空宏。预编译头 `pch_headers.hpp` 聚合 Eigen、Boost、Windows SDK 及内部 base/meshmodel/cadmodel 头以加速编译。
