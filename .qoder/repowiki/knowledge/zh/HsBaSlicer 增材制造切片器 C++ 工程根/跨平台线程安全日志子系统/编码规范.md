- 平台相关实现通过 `#ifdef __ANDROID__` / `#elif defined(TARGET_OS_IOS)` / `#else` 三段式分派，同一逻辑在不同平台下分别调用 `__android_log_print`、`os_log_with_type` 或 `BOOST_LOG_TRIVIAL`。
- 日志级别统一用 0~5 的整型常量表示（trace/debug/info/warning/error/fatal），并通过 `GetLogLevel` / `GetiOSLogType` / `GetAndroidLogPriority` 等内部 helper 映射到各平台原生枚举。
- 对外符号统一加 `HSBA_SLICER_LOG_API` 可见性宏，由 `export.h` 在 Windows 上展开为 `__declspec(dllexport/dllimport)`，其他平台为空宏。
- 日志调用点通过 `std::source_location::current()` 作为默认参数自动携带源码位置信息，并由 `GetSourceLocation` 统一格式化为 `[file:line] function_name:` 前缀。
- 单例实例通过 `std::call_once(instance_flag_, ...)` 配合 `static std::shared_ptr<LoggerSingletone> instance_` 实现线程安全的懒初始化，构造函数接受私有嵌套结构体 `Private` 作为 tag 阻止外部构造。
