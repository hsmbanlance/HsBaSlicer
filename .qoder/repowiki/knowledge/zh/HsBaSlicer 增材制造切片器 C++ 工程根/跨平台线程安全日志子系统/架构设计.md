模块以 `logger.hpp`/`logger.cpp` 暴露单一对外类 `LoggerSingletone`（命名拼写为 Singletone），通过 `base/singleton.hpp` 提供的基类 + `std::shared_mutex` + `std::once_flag` 实现线程安全的懒加载单例；所有公共 API 通过 `export.h` 中的 `HSBA_SLICER_LOG_API` 宏做 Windows DLL 导出控制。

- 平台分支：编译期通过 `__ANDROID__` / `TARGET_OS_IOS` / `_WIN32` 三向分派，桌面端走 Boost.Log（含文件旋转与控制台输出），iOS 走 `os_log_t`，Android 走 `__android_log_print`。
- 配置层：构造时从当前目录下的 `logcfg.ini` 读取 `log.log_level[_debug]`、`log.use_log_file`、`log.log_file`、`log_format.log_datatime_format`，依赖 `fileoperator/rw_ptree.hpp` 解析 INI。
- 调用入口：`Log(message, level, source_location)` 是核心分发函数，`LogDebug/Info/Warning/Error` 及 `inline namespace LogLiterals` 中的 `_log_debug/_log_info/_log_warning/_log_error` 自定义字面量均委托到它，借助 C++20 `std::source_location` 自动捕获文件名、行号与函数名。
- 构建：`CMakeLists.txt` 根据 `BUILD_SHARED_LIBS` 生成 `HsBaSlicerLog` 静态或共享库，并按平台链接 `Boost::log`、系统 `log` 框架或仅基础库。
