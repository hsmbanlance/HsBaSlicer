覆盖率门禁需安装 gcovr（`apt install gcovr` 或 `pip install gcovr`），通过 `cmake -DHSBA_COVERAGE=ON` 或预设 `linux-coverage` 触发，运行测试后执行 `make coverage`；PDB 部署通过 `cmake -DTARGET_BIN=<exe> -DPDB_FILES=<pdb1;pdb2;...> -P cmake/deploy_dlls.cmake` 调用；静态检查通过 `python static_check/cpp_analyzer.py <path>` 与 `python static_check/clang-format-batch.py [-p <repo>] [--style LLVM] [-j N]` 调用。
