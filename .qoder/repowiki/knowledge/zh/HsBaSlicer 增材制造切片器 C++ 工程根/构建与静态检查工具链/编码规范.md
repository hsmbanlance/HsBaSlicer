- CMake 特性探测统一封装为 `check_<lang>_feature_<name>(result)` 函数，内部使用 `check_c[_cxx]_source_compiles` 将布尔结果写回变量名参数。
- Python 工具脚本以 `#!/usr/bin/env python3` 开头，使用 `argparse` 暴露 CLI，并通过 `pathlib.Path` 处理路径，错误时 `sys.exit(1)`。
- 需要忽略文件的 Python 脚本通过解析根目录 `.gitignore` 并结合内置默认模式（build、out、tests、docs 等）来过滤扫描范围。
- 覆盖率门禁采用双通道设计：先一次性将 gcov 数据解析为 JSON tracefile，再分别对 core/other 两组 filter/exclude 列表执行阈值门禁，任一未达标即失败。
