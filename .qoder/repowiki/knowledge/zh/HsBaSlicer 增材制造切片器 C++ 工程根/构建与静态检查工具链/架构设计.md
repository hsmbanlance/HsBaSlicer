模块按职责划分为四个子目录，均被顶层 CMake/CI 消费但不互相依赖：
- `cmake/`：CMake 可复用片段。`HsBaSlicerConfig.cmake.in` 通过 `find_dependency` 声明对外头文件依赖（Eigen3、magic_enum、Clipper2、Lua、Protobuf、OpenSSL）并引入生成的 Targets；`coverage.cmake` 在 GNU/Clang 下注入 `--coverage` 编译/链接选项，基于 gcovr 对 core/other 两组目录分别执行行覆盖率阈值门禁（`HSBA_COVERAGE_THRESHOLD_CORE`/`OTHER`），输出 JSON/XML/HTML 报告；`deploy_dlls.cmake` 作为独立脚本复制 PDB 调试符号到 exe 目录。
- `static_check/`：Python 静态检查工具集。`cpp_analyzer.py` 实现 catch-all 异常、`using namespace`、不安全函数、魔法数字、内存泄漏（new/malloc/free 配对检测）、圈复杂度等规则，跳过 tests/examples 并通过 `.gitignore` 过滤；`clang-format-batch.py` 递归扫描 C/C++ 源文件调用外部 `clang-format` 批量格式化，支持多线程和 dry-run；`feature_check.cmake` 用 `check_cxx_source_compiles` 探测 C11 `_Generic`、C++ Concepts/Ranges/source_location/coroutines/explicit-this/modules 等语言特性，供上层条件启用。
- `scripts/`：仓库文档生成脚本 `repowiki_to_github_wiki.py`。
- `.github/workflows/`：多平台 CI（Android/iOS/Linux/macOS/Windows）及 coverage/publish-wiki 工作流，统一驱动上述 CMake 片段与 Python 脚本。
- `overlay-ports/`：vcpkg overlay 端口目录，README 说明自定义第三方库放置位置。
- `.agents/skills/` 与 `.github/skills/`：AI agent 技能定义占位目录。
