- 第三方库元数据（名称、许可证、主页）集中维护在 Generator_Version.ps1 的 libInfoMap 哈希表中，新增依赖需在此处登记而非直接写死到模板中。
- 平台识别采用基于 vcpkg triplet 的正则匹配策略，并按 GameConsole → Android → iOS → macOS → Linux → Windows 的优先级分支判断目标平台。
- 生成的 C++ 源码使用 UTF-8 无 BOM 编码写入，且所有字符串字面量通过 PowerShell 双引号转义后嵌入模板。
- 对外 API 以 `std::string_view` 暴露静态文本字段，避免在 VersionInfo 中持有动态分配字符串。
