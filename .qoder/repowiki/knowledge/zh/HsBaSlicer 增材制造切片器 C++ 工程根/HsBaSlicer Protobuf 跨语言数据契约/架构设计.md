模块以 protobuf3 为唯一数据契约载体，所有 .proto 文件共享同一 package `HsbaProto`，由 CMakeLists.txt 通过 `find_package(Protobuf)` 驱动：一方面调用 `PROTOBUF_GENERATE_CPP` 生成静态库 `HsBaSlicerProto` 供 C++ 侧直接链接；另一方面在启用 `HSBA_PROTOBUF_OUT` 时，通过自定义命令将每个 .proto 同时编译到 cpp/cs/java/python/php 五个目标目录，实现跨语言多端共享同一份 schema。

内部按职责划分：
- 基础类型层：point.proto、vector.proto、transform.proto 提供 msg_point2/3、msg_vector3、msg_quaternion、msg_transform2/3 等原子几何原语。
- 几何与拓扑层：mesh.proto 基于上述原语定义三角面片（STL 风格与拓扑索引风格）。
- 路径与布尔运算层：path.proto、boolean_operation.proto 描述切片后生成的轮廓与布尔操作结果。
- 工艺基座：base_config.proto 定义全局枚举（msg_technology_type、msg_output_type、msg_profiles_format 等）与根消息 msg_base_config，作为所有工艺配置的入口。
- 工艺管线层：fdm_pipeline.proto、sla_pipeline.proto、slm_pipeline.proto、sls_pipeline.proto、lom_pipeline.proto、waam_pipeline.proto、tdp_pipeline.proto 各自定义对应技术的 pipeline config/result 消息族。
- 通用管道抽象：custom_pipeline.proto、file_transfer_pipeline.proto、slice_config.proto 提供可复用的流水线与切片配置抽象。

依赖方向自底向上：mesh/path/boolean_operation 依赖 point/vector/transform；各 pipeline 文件仅依赖 base_config 与基础几何类型，彼此之间无相互 import，保证各工艺协议可独立演进。
