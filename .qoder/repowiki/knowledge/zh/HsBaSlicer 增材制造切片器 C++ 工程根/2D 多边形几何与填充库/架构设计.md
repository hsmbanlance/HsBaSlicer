模块以 `HsBa::Slicer` 命名空间组织，按数据类型与职责分层：
- 基础类型层：`IntPolygon.hpp/.cpp` 定义 `Point2/Polygon/Polygons`（`Clipper2Lib::Point64/Path64/Paths64`）并提供 MakeSimple、Union/Intersection/Difference/Xor、Offset、Area、PointInPolygons 等核心几何操作；`FloatPolygons.hpp/.cpp` 提供对应的 double 精度别名 `Point2D/PolygonD/PolygonsD`，并额外暴露矩形、圆、椭圆、正多边形构造器以及 `Integerization`/`UnIntegerization` 双整型互转。
- 算法扩展层：`2Dhull.cpp` 实现凸包；`PolygonFill.cpp` 提供 OffsetFill、LineFill、SimpleZigzagFill、ZigzagFill、CompositeOffsetFill、HybridFill 等填充模式，并通过 `LuaCustomFill`/`LuaCustomFillString` 支持用户脚本自定义填充。
- 图像 I/O 层：`ImageToPolygons.cpp` 封装 PNG/JPEG 读取与阈值化（FromImage/FromImageMulti）、多阈值分割，以及将多边形渲染回位图（ToImage），同样提供 Lua 驱动变体。
- 绑定层：`LuaAdapter.cpp` 负责在 Lua 栈与 Polygon/PolygonsD 之间双向转换，并统一注册所有几何与填充函数到 Lua 状态。
依赖方向单向：LuaAdapter → FloatPolygons + IntPolygon；PolygonFill → FloatPolygons + IntPolygon；ImageToPolygons → FloatPolygons；CMakeLists.txt 将上述源编译为静态库 `HsBaSlicer2D`，链接 HsBaSlicerBase、Clipper2、PNG、libjpeg-turbo、OpenCV、Lua，并在非 IOS/GAME_CONSOLE 平台引入 OpenCV。可选宏 `HSBA_HAVE_FREETYPE` 启用字体转轮廓（TextToPolygons），`HSBA_POLYGON_DUMP` 启用 SVG 调试导出。
