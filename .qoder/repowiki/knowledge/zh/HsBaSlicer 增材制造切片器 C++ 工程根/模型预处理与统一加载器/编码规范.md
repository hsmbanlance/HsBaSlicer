- 所有对后端模型的访问都通过 `dynamic_cast` 从 `IModel` 还原为具体类型，失败时抛出 `RuntimeError` 说明来源名称与期望类型。
- 可选后端代码整体用 `#ifdef USE_CGAL` / `#ifdef USE_OPENVDB` / `#ifdef USE_OCCT` 包裹，未启用时抛出 `NotSupportedError` 或 `RuntimeError` 提示缺失后端。
- 模型操作函数统一采用 `(sourceName, resultName, ...)` 参数约定，结果通过 `pool_.insert(resultName, ...)` 写回命名池。
- 错误分类使用 `InvalidArgumentError`（参数非法/重复名称/找不到模型）与 `RuntimeError`（后端不可用/加载失败/类型不匹配）两种异常类型。
- 公共 API 返回 `std::shared_ptr<IModel>`，内部具体实现通过 `std::static_pointer_cast<IModel>` 上溯到抽象接口后再插入池中。
