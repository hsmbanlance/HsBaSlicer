本模块是纯文档产物，不包含可执行代码，按三种形态组织：
- `en/`、`zh/`：双语 Markdown 用户文档，目录结构镜像（base/cipher/fileoperator/logger/utils/DllHsBaSlicer/LibHsBaSlicer），根级提供 README、cpp_cmake_usage.md、lua_pipeline_api.md、vcpkg-dependencies.md 等跨语言一致的引导文件。
- `doxygen/html/`、`doxygen/latex/`：由 Doxygen 从源码注释自动生成的 API 参考，html 子目录包含每个头/源文件的 .html、.js、__incl.map/__incl.png 等关联资源，search/ 子目录存放全文搜索索引。
- 顶层 `Doxyfile` + `CMakeLists.txt`：通过 `find_package(Doxygen COMPONENTS dot)` 发现 doxygen/dot，未找到时仅输出 WARNING；找到后注册 `add_custom_target(docs)`，在 docs 目录下执行 `${DOXYGEN_EXECUTABLE} ${CMAKE_CURRENT_SOURCE_DIR}/Doxyfile` 生成 html/latex 输出。
依赖方向单向：本模块不反向依赖项目源码，仅消费源码中的 Doxygen 注释与 Markdown 文档。
