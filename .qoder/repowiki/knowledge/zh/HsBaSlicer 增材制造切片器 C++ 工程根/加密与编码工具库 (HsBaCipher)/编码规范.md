- 所有对外 API 以 `HsBa::Slicer::Cipher` 命名空间下的无状态静态类组织（`Encoder`、`Hasher`、`Encrypt`），方法签名统一为 `static std::string/std::vector<unsigned char>` 形式的纯函数。
- 针对二进制数据使用 `std::vector<unsigned char>`，针对文本输入使用 `std::string_view`，避免不必要的拷贝。
- 每个公开类在头文件中附带 Doxygen 风格的 `@file`、`@brief`、`@class` 注释块，说明职责与算法参数约束（如 IV 长度）。
- 为常用操作同时提供 `std::string_view` 重载与底层 `std::vector<unsigned char>` 实现，前者通过 inline 转发到后者以减少重复代码。
