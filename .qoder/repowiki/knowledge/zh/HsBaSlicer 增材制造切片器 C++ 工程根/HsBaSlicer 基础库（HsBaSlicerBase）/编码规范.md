- 公共头文件统一使用 `#pragma once` 配合 `HSBA_SLICER_<NAME>__HPP` 形式的 include guard。
- 对外 API 集中在 `HsBa::Slicer` 命名空间，通用工具放在 `HsBa::Slicer::Utils`，ABI 兼容的 POD 结构通过 `extern "C"` 暴露给 C 调用方。
- 自定义错误采用继承 `std::runtime_error` 的扁平异常族（`RuntimeError` → `IOError`/`NotFoundError`/`TimeoutError` 等），并通过 `using std::runtime_error::runtime_error; using std::runtime_error::what;` 复用基类构造与 what()。
- 任意类型的反射元数据通过 `template<> GetTypeInfo<T>()` 特化注入，每个类型返回一个 static `TypeInfo`，并在其中注册字段与方法回调。
- 需要全局状态的单例（如 `MockRegistry`、`Singleton`）采用函数内局部 static 变量实现线程安全的懒初始化。
- 线程安全容器普遍使用 `std::shared_mutex` + `std::lock_guard`/`std::shared_lock` 区分读写路径（见 `Delegate`、`MockRegistry`）。
