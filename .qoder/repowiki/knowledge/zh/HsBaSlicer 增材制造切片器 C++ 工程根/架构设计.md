顶层 CMakeLists.txt 是唯一的构建编排入口：先通过 static_check/feature_check.cmake 探测 C++20 concepts/ranges/source_location/NTTP 等特性并暴露 HSBA_HAS_* 编译宏，再根据 VCPKG_TARGET_TRIPLET 推导平台（HSBA_DESKTOP / HSBA_MOBILE / HSBA_GAME_CONSOLE）与 BUILD_SHARED_LIBS，随后按依赖顺序 add_subdirectory 组装子模块。

- 依赖分层：proto → base/cipher/utils/logger → 2D/paths/fileoperator/meshmodel/(cadmodel|pointcloud) → preprocess/support/pipelinetypes/convert → LibHsBaSlicer → ModuleHsBaSlicer/DllHsBaSlicer/HsBaSlicer(samples) → version/tests/docs。
- 可选内核由 vcpkg.json 的 copyleft feature 驱动：CGAL/OpenCASCADE/libigl[cgal] 仅在 HSBA_COPL=ON 时启用，同时切换项目许可证从 MIT 到 GPL-3.0-or-later；Android/iOS/游戏主机默认禁用 CGAL、OpenCASCADE、OpenVDB、bit7z、DLL loader 等重型依赖。
- 对外契约集中在 DllHsBaSlicer 的 C ABI 头文件与 HsBaSlicerTargets.cmake 包导出，供 C#/Java/Python 宿主通过 FFI 调用；ModuleHsBaSlicer 提供 C++20 module 类式 API 包装同一核心管线。
- 版本信息在 configure 阶段由 PowerShell 解析 vcpkg.json 生成 version.cpp，统一注入所有目标。
- 构建产物统一输出到 out/build/<preset>/bin/<CONFIG>，install 将公共头文件、生成的 proto pb.h、CMake Config 文件安装到标准位置。
