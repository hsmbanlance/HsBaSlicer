模块由三部分组成：
- `hsba_slicer.cppm` 是单一 C++20 interface unit（module; + export module hsba.slicer），同时包含声明与实现，避免 MSVC C2572 隐式 std:: redefinition 错误；对外暴露 `HsBa::Slicer` 命名空间。
- `module_anchor.cpp` 是空源文件，仅用于强制 CMake 对纯 CXX_MODULES 目标调用 archiver 生成 `.lib`。
- `CMakeLists.txt` 将目标建为 STATIC 库，通过 `FILE_SET hsba_slicer_modules TYPE CXX_MODULES` 注册模块接口，并 PUBLIC 链接 `LibHsBaSlicer`、`HsBaPipelineTypes`、Eigen3、Clipper2、Lua。

对外 API 分层：
- 类型重导出层：将 Clipper2 的 Point/Polygon/Polygons 以及 `pipelinetypes/pipeline_types.h` 中的配置/结果结构体重新暴露到 `HsBa::Slicer`。
- RAII 资源层：`Model` 封装 `IModel` 生命周期（构造加载、析构移除）。
- 流水线类层：`FdmPipeline`/`SlaPipeline`/`SlsPipeline`/`SlmPipeline`/`LomPipeline`/`TdpPipeline`/`WaamPipeline`/`FileTransferPipeline`/`ParamStorePipeline`/`CustomLuaPipeline` 各自持有对应 `HsBa*Config_t`，把底层自由函数串成完整流程。
- Lua 扩展点：`add2DFunction`/`add3DFunction`/`addFileFunction`/`addEventCallback` 允许外部注入自定义 Lua 函数与事件回调。
依赖方向单向向下：本模块 → LibHsBaSlicer → 几何/路径/Lua 引擎，不反向引用上层应用。
