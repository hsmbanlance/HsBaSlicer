- 每个流水线（Fdm/Sla/Sls/Slm/Lom/Tdp/Waam/FileTransfer/ParamStore/CustomLua）采用“配置结构体 + Pipeline 类”模式：构造函数接收对应的 `HsBa*Config_t`，`run()` 方法串联底层自由函数完成完整流程。
- Lua 可插拔阶段统一通过 `cfg_.xxx_lua_script` 判分支：若配置了 Lua 脚本则调用 `LuaCustom*ByFile`/`Save*PackageLua`，否则回退到内置算法实现。
- 二维多边形在整数精度（Clipper2 `Path64`）与双精度（`PathD`）之间通过 `Integerization`/`UnIntegerization` 显式转换，避免隐式精度丢失。
- 所有可能失败的公共 API 通过抛出 `SlicerError`（继承 `std::runtime_error`）报告错误，而非返回错误码。
- 默认配置工厂函数（`defaultFdmConfig` 等）在模块内直接转发给 `HsBa*ConfigDefault()`，使消费者无需接触底层 GMF 静态变量。
