模块以 CMake 静态库 `HsBaSlicerMesh` 形式暴露，按后端分为三个并列的 mesh model 实现：
- `IglModel`：继承 `base::IModel` 接口，用 Eigen 矩阵存储顶点/面/法线，封装加载/保存、仿射变换、包围盒/体积、布尔运算及基本几何体工厂。
- `CgalModel`：在启用 `HSBA_COPL` 时编译，作为 CGAL 后端的 mesh model。
- `FullTopoModel`：不继承 IModel，而是从任意 `IModel` 或顶点/三角数组在构造时重建 V/E/F 全拓扑关系，提供 `Slice`/`UnSafeSlice`/`SliceFast` 三种 Z 向切片 API，并通过 `PushFullTopoModelToLua` 把 V/E/F 注入 Lua 状态供脚本自定义切片。
依赖方向单向向上：本模块依赖 `HsBaSlicerBase`（IModel 接口）、`HsBaSlicerProto`、`HsBaSlicer2D`（Polygon/Polygons 类型）和外部库 igl / CGAL / lua；顶层构建通过 `HSBA_COPL` 开关决定是否链接 CGAL 相关目标。
