- 对外 C ABI 统一使用 `#ifdef __cplusplus extern "C" { ... } #endif` 包裹，并以 `HSBA_SLICER_API` 宏修饰每个导出符号。
- 每个工艺流水线遵循相同的三件套命名：`HsBaCreateDefault*Config`、`HsBaRun*Pipeline`（同步）、`HsBaRun*PipelineAsync`（异步）、`HsBaFreePipelineResult`（释放）。
- 所有公共头文件采用 Doxygen 风格的 `@file`/`@brief`/`@author` 注释块，并使用 `#pragma once` 配合 `HSBA_SLICER_*_H` 守卫。
- 异步流水线接口一律接受 `(callback, user_data)` 进度回调与 `(result_callback, result_user_data)` 结果回调，由 C++20 coroutine 在后台执行并在完成时回掉。
- 并行热点路径通过 `ParallelForLayers` 将每层工作提交到 `ThreadPool`，并按块聚合后在调用线程串行触发 `on_progress`，避免从 worker 线程直接回调。
