模块以 `CMakeLists.txt` 构建为一个 SHARED 库（iOS 上退化为 STATIC），对外仅暴露 `extern "C"` + `HSBA_SLICER_API` 标记的符号，形成稳定的跨语言边界。

- 入口与生命周期：`initialize.h/.cpp` 提供唯一 C 入口 `initialize()`，在 DLL 加载时注册 Lua 扩展、事件回调及所有流水线；`version_info.*` 暴露版本信息。
- 流水线族：每个工艺（FDM、SLA、SLS、SLM、Lom、TDP、WAAM）对应一对 `<工艺>_pipeline.{h,cpp}`，统一遵循 `HsBaCreateDefaultConfig` / `HsBaRun*Pipeline` / `HsBaRun*PipelineAsync` / `HsBaFreePipelineResult` 的 API 模式，内部通过 C++20 coroutine 实现非阻塞执行。
- 自定义流水线：`custom_pipeline.*` 暴露基于 Lua 脚本的可编程流水线，Lua 环境通过 `HsBa` 全局表暴露模型加载、切片、支撑、填充、路径输出及 SLA/SLS 打包能力。
- 扩展点：`lua_register.*` 允许宿主注入 2D/3D/File 三类 Lua 函数；`event_source_register.*` 注入 zipper 与数据库事件回调，使 Lua 可监听 zip/db 事件。
- 通用基础设施：`model_preprocess.*` 负责模型预处理；`file_transfer_pipeline.*` 与 `param_store_pipeline.*` 处理文件传输与参数存储；`pipeline_convert.*` 做类型转换；`pipeline_parallel.hpp` 是头文件并行工具，按层分发到 `base/thread_pool.hpp` 的 ThreadPool，并通过 `HSBA_PIPELINE_THREADS` 环境变量控制线程数。
- 依赖方向：本层只调用 `LibHsBaSlicer` 及其下游静态库（`HsBaSlicerBase`、`HsBaSlicerUtils`、`HsBaSlicerMesh`、`HsBaSlicer2D`、`HsBaPreprocess`、`HsBaSupport`、`HsBaPaths`、`HsBaSlicerFileOperator`、`HsBaVersion`、`HsBaSlicerConverter`、`HsBaSlicerProto`），不反向依赖上层应用。
