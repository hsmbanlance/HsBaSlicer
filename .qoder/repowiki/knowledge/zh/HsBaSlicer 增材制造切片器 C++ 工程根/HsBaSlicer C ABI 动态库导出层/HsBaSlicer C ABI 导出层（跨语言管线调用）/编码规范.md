- 所有对外 C ABI 函数均使用 `extern "C"` 包裹并以 `HSBA_SLICER_API` 修饰，头文件通过 `HSBA_SLICER_*_H` 形式的 include guard 保护。
- 每种管线类型（FDM/SLA/SLS/SLM/LOM/TDP/WAAM/文件传输/Lua 自定义）都遵循统一的三件套：`*_pipeline.{h,cpp}` 实现运行逻辑、`pipeline_convert.h` 中提供 `*FromProtoBytes/*ToProtoBytes` 序列化对、以及对应的 `HsBaFree*ConfigStrings` 内存释放函数。
- 序列化函数的返回值约定一致：成功返回 1、失败返回 0；输出缓冲区由函数内部 `malloc` 分配并由调用方负责释放。
- Lua 扩展通过 `HsBaLuaRegFn` 函数指针类型注册，按 2D/3D/File/Event 四类分类注入，而非直接修改核心代码。
