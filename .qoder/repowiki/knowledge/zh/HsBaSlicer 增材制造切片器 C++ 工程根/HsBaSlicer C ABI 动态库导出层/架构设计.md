本模块作为 LibHsBaSlicer 之上的薄包装层：每个工艺（fdm/sla/sls/slm/lom/tdp/waam）对应一对 *_pipeline.{h,cpp}，统一实现配置、执行、结果序列化与错误码转换；custom_pipeline 提供 Lua 脚本扩展入口，file_transfer_pipeline 与 param_store_pipeline 负责外部数据通道，model_preprocess 与 pipeline_convert 处理模型预处理与格式转换，event_source_register 与 lua_register 完成事件源与 Lua API 注册，initialize/version_info 提供库生命周期与版本信息。

跨子模块的编排由 CMakeLists.txt 统一驱动：在非 iOS 平台构建为 SHARED 库，iOS 平台降级为 STATIC（因 iOS 无法动态加载任意 dylib），并通过 HSBA_SLICER_EXPORTS 宏控制 dllexport.h 中的导出符号。所有导出函数仅调用 LibHsBaSlicer 已暴露的接口，不直接依赖底层实现细节，从而在 DLL 边界上形成单向依赖：DllHsBaSlicer → LibHsBaSlicer + HsBaPipelineTypes + 若干静态库。
