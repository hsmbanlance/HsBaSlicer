- 跨平台分支通过顶层 CMake 定义的 HSBA_DESKTOP / HSBA_MOBILE / HSBA_GAME_CONSOLE / HSBA_COPL / HSBA_USE_BIT7Z / HSBA_NO_DLL_LOADER 等宏控制，而非直接判断 CMAKE_SYSTEM_NAME。
- 可选功能通过 HSBA_HAS_* 编译宏（如 HSBA_HAS_CXX_MODULES、HSBA_HAS_CXX_COROUTINES、HSBA_HAS_NTTP_FP、HSBA_HAS_C_GENERIC）进行条件编译。
- 第三方依赖统一通过 vcpkg.json 声明并由 find_package/pkg_check_modules 引入，禁止在子模块内直接 git clone 或手动链接。
- 对外 API 通过 DllHsBaSlicer 暴露 C ABI，LibHsBaSlicer 提供 C++ 自由函数接口，ModuleHsBaSlicer 提供 C++20 module 类式封装，三者共享同一内部管线。
- 新增子模块需在顶层 CMakeLists.txt 中按依赖顺序 add_subdirectory，并在 _HSBA_INSTALL_TARGETS 与 install(FILES ...) 块中同步注册安装规则。
