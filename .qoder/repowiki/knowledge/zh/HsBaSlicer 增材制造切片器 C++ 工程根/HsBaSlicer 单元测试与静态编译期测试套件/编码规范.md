- 每个测试文件以 `#define BOOST_TEST_MODULE <name>` 开头并包含 `<boost/test/included/unit_test.hpp>`，用例组织在 `BOOST_AUTO_TEST_SUITE(<suite>)` / `BOOST_AUTO_TEST_CASE(<case>)` 中。
- CMake 中对每个测试目标统一声明 `target_compile_definitions(... PRIVATE BOOST_TEST_DYN_LINK)` 并调用 `enable_testing()` + `add_test(NAME ... COMMAND $<TARGET_FILE:...>)` 注册到 CTest。
- 需要动态链接 Boost.Test 的可执行目标均通过 `target_link_libraries(... Boost::unit_test_framework)` 显式链接框架。
- 对第三方/外部 DLL 的依赖通过同目录下的 `mock_<lib>_dll.cpp` 桩文件解耦，测试只链接桩而非真实 DLL。
- 可选功能测试通过 CMake 变量（`HSBA_COPL`、`HSBA_POLYGON_DUMP`、`HSBA_ANY_OBJECT_ENABLE_MOCK`）包裹 `if(...)` 块，未启用时该测试目标不会被构建。
- 静态测试位于 `static_tests/` 下，使用 `static_assert` 与 `constexpr` 断言模板/元编程结果，不定义任何 `main` 函数，作为静态库被上层链接。
