samples/ 是纯示例集合，每个子目录对应一种可独立编译的 target：
- Custom/：核心示例，通过 HsBaRunCustomPipeline / HsBaRunCustomPipelineAsync 调用 `scripts/my_*_pipeline.lua`，把整条工作流（模型加载、切片、支撑、填充、导出）交给 Lua；同时演示内联源码、异步回调以及基于 proto/custom_pipeline.proto 的 wire 字节流编解码（示例 5 自实现 varint/fixed64/delimited 解析，刻意不链接 HsBaSlicerProto 以避免描述符重复注册）。
- FDM/、SLA/、SLM/、SLS/、TDP/、WAAM/、LOM/：各工艺固定流水线示例，分别包含 main.cpp + CMakeLists.txt + scripts/my_*_export.lua（或 my_support.lua / my_infill.lua / my_floor.lua），通过 DllHsBaSlicer 暴露的 C API（如 HsBaRunFdmPipeline、HsBaRunSlaPipeline 等）运行。
- LibHsBaSlicer/：展示 C++20 module (`import hsba.slicer;`) 面向对象封装（Model/FdmPipeline/FdmResult、CustomLuaPipeline）的用法，与 C API 示例互补。
依赖方向单向：所有示例仅依赖上层构建产物 DllHsBaSlicer（及其公开头文件），不反向引用 samples 内部代码；资源（stanford_bunny.stl、scripts/）在 POST_BUILD 阶段复制到输出目录。
