- 每个转换主题采用成对的 `.hpp`/`.cpp` 文件，文件名遵循 `<Src>2<Dst>` 语义（如 Eigen2Msg、Msg2Eigen、FullTopoModel2Msg、Msg2FullTopoModel）。
- 所有公共 API 声明在头文件中，实现放在同名 `.cpp`，并通过 `HSBA_SLICER_<NAME>__HPP` 形式的 include guard 保护。
- API 统一置于 `HsBa::Slicer` 命名空间下，并以 `void Xxx2Yyy(...)` 或返回值形式的函数名表达源→目标的转换方向。
- 涉及 C 结构体的 PipelineConfig 转换函数在 Doxygen `@note` 中明确标注字符串字段由 `malloc` 分配及对应的释放函数（如 `HsBaFreePipelineResult`）。
