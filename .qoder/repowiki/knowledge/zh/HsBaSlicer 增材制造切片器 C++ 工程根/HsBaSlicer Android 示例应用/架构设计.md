模块采用标准 Android Gradle 单工程结构：根目录 `settings.gradle` 仅 include `:app` 子模块；`app/build.gradle` 声明 `com.android.application` 插件、namespace `com.hsmbanlance.hsbaslicer.example`、minSdk 21/targetSdk 34，并通过 `jniLibs.srcDirs = ['src/main/jniLibs']` 与 `abiFilters "arm64-v8a"` 将预编译的 `.so` 打入 APK。
- 入口类 `MainActivity.java` 通过 `System.loadLibrary("HsBaSlicer")` 加载主库（依赖同目录下的 `libDllHsBaSlicer.so`），并以 native 方法 `runPipelineExamples()` 暴露给上层运行 FDM/SLA/SLS 流水线示例。
- 原生二进制由外部 CMake 构建后手工拷贝至 `app/src/main/jniLibs/arm64-v8a/`，本模块不参与 C++ 编译，仅承担打包与运行时发现职责。
- 依赖方向单向：Java 层 → NDK ABI → 预编译 C++ 共享库，无 Java/Kotlin 业务代码。
