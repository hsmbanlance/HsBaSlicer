根 CMakeLists.txt 按依赖层次 add_subdirectory：先构建基础层（base/cipher/utils/logger/proto），再构建算法层（2D/paths/fileoperator/meshmodel/cadmodel/pointcloud/preprocess/support），然后组装 DllHsBaSlicer（C ABI）和 LibHsBaSlicer（C++ ABI），最后才把 restapi 子目录纳入构建。
- 跨模块契约：restapi 不直接调用 LibHsBaSlicer/C++ 层，而是通过 DllHsBaSlicer 暴露的 C ABI（pipeline_convert.h + pipelinetypes/pipeline_types.h）访问完整切片流水线；同时复用 fileoperator 的 ParamStore 做参数持久化、utils 的 struct_json 做 JSON/XML 序列化。
- 可选性门控：HSBA_BUILD_REST_API 默认 OFF，仅在桌面平台生效，且要求 vcpkg manifest feature `rest-api` 安装 cpp-httplib，否则 configure 阶段 FATAL_ERROR；启用后顶层还会把 restapi.ini 复制到 bin/$<CONFIG> 并 install 到 /etc/HsBaSlicer。
- 统一产物布局：所有可执行/库输出到 ${CMAKE_BINARY_DIR}/bin/$<CONFIG>，install 导出 HsBaSlicerTargets.cmake 供外部 find_package(HsBaSlicer) 消费。
- 多 ABI 共存：samples/Lua 与 restapi 都通过 DllHsBaSlicer C ABI 解耦，避免与 LibHsBaSlicer 内部实现耦合。
