模块以独立可执行 `HsBaSlicerRestServer` 为边界：`main.cpp` 解析 `--config/--host/--port` 并调用 `RunServer`；`restapi.hpp` 仅暴露该入口。

内部按职责分层：
- 配置层：`server_config.{hpp,cpp}` 加载 `restapi.ini`（INI → `ServerConfig`），`config_bridge.{hpp,cpp}` 通过反射 TypeInfo 在 JSON/XML/protobuf 与 C ABI 配置结构之间双向转换。
- 序列化层：`serialize_value.hpp` + `content_negotiate.{hpp,cpp}` 提供 `SerializeValue` 与 `DataFormat` 协商（Accept / ?format= / default_format）。
- 运行时桥接层：`pipeline_executor.{hpp,cpp}` 封装 DllHsBaSlicer C ABI（`CreateDefaultConfig`/`DestroyConfig`/`RunPipeline`/`KindName`/`ParseKind`），将各 kind 的结果归一化为 `SliceOutcome`，避免跨 DLL 共享反射对象。
- 并发层：`job_manager.{hpp,cpp}` 维护固定大小 worker 线程池 + 有界队列，支持提交、状态轮询、结果下载、删除与 TTL 回收；`Runner` 函数指针可被测试注入 mock。
- 路由层：`routes.cpp` 使用 `httplib::Server` 注册 `/api/health|version|pipelines|kinds|jobs|params|config/*` 等端点，统一经 `ReplyValue`/`ReplyError` 输出。

依赖方向单向向外：restapi → DllHsBaSlicer(pipelinetypes C ABI) + fileoperator(ParamStore) + utils(struct_json/struct_xml) + httplib；samples/Lua 等 C ABI 调用方不反向依赖本模块。构建由顶层 `HSBA_BUILD_REST_API` 门控（默认 OFF，仅桌面平台），CMake 中 `find_package(httplib CONFIG REQUIRED)` 并通过 vcpkg feature 激活。
