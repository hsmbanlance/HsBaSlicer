以 CMake 静态库 HsBaSlicerConverter 暴露，依赖方向单向：仅消费上层库（Eigen3::Eigen、HsBaSlicerProto、HsBaSlicerMesh、HsBaPipelineTypes），不反向依赖。
- 几何层：Eigen2Msg.hpp/.cpp 与 Msg2Eigen.hpp/.cpp 成对实现 Eigen::Vector/Matrix/Transform/Isometry/Quaternion 与 msg_vector/msg_point/msg_transform/msg_path 等 protobuf 消息的双向转换。
- 领域层：FullTopoModel2Msg 与 Msg2FullTopoModel 在 FullTopoModel（来自 HsBaSlicerMesh）与 msg_topo_trimeshes 之间做序列化/反序列化；PipelineConfig2Msg 与 Msg2PipelineConfig 覆盖 FDM/SLA/SLS/SLM/LOM/WAAM/TDP 全部主流水线，将 C 结构体 HsBa*PipelineConfig_t / HsBa*PipelineResult_t 与对应 .pb.h 消息互转。
- 所有公共 API 统一置于 HsBa::Slicer 命名空间，头文件通过 #pragma once + HSBA_SLICER_<NAME>_HPP include guard 双重防护。
