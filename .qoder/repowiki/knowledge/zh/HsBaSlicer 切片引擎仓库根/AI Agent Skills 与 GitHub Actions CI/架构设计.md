模块由两个并列的 .agents/ 与 .github/ 两部分组成：
- `.agents/skills/` 与 `.github/skills/` 各自包含 `cmake/SKILL.md`（含 `references/templates.md`）和 `cpp-modern-features/SKILL.md`，两份目录结构镜像对称，分别供本地 Copilot 与 GitHub Copilot 消费；每个 SKILL.md 以 YAML front-matter（`name`、`description`、`user-invocable`、`allowed-tools`）声明技能元数据。
- `.github/workflows/` 下按平台拆分 workflow：`build-linux.yml`、`build-macos.yml`、`build-windows.yml`、`build-android.yml`、`build-ios.yml` 以及共享模板 `cmake-multi-platform.yml`，另含 `publish-wiki.yml` 与 `test-coverage.yml`；workflow 通过 vcpkg toolchain 与 Android NDK 完成交叉编译。
- `.github/copilot-instructions.md` 作为仓库级 Copilot 提示，汇总项目架构、Lua/Protobuf/CMake 约定与搜索关键词，是 AI agent 进入本仓库的入口文档。
依赖方向单向：SKILL.md 仅描述现有代码风格，workflow 仅调用外部 CI 服务，二者均不依赖业务源码。
