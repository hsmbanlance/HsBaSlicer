- 每个工艺在 `proto/` 下拥有独立的 `.proto` 文件，并在 `base_config.proto` 中集中声明跨工艺共享的枚举（technology_type、output_type、profiles_format 等）。
- `pipeline_types.h` 中以 `typedef enum HsBaXxx_t` + `typedef struct HsBaXxxPipelineConfig_t` + `typedef struct HsBaXxxPipelineResult_t` + `ProgressCallback` / `ResultCallback` 四件套的形式组织每种工艺的 C ABI。
- 所有对外结构体字段使用 `const char*` 字符串指针且注释标注 caller must free，配合对应的 `HsBaFreeXxxPipelineResult` 释放约定。
- 每个 Config 结构体后紧跟一个 `static inline HsBaXxxConfigDefault(void)` 初始化函数，将字符串字段置 0、数值字段赋默认值，保证 ABI 可零初始化。
- C ABI 整体被 `#ifdef __cplusplus extern "C" { ... } #endif` 包裹，确保 C/C++ 调用方均可直接 include。
