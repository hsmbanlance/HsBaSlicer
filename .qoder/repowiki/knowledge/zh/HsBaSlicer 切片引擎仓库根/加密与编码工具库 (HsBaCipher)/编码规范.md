- 所有工具类（Encoder、Hasher、Encrypt）均为无状态类，对外仅暴露 static 成员函数，不维护实例字段。
- API 同时提供接受 `std::vector<unsigned char>` 与 `std::string_view` 的重载，后者在 inline 中转换为字节向量后委托主实现。
- 公开符号统一置于 `HsBa::Slicer::Cipher` 命名空间下，并以 `@file` Doxygen 注释描述职责。
- 加解密算法以「算法_模式_encrypt / decrypt」成对命名（如 aes256_cbc_encrypt/decrypt、des3_ecb_encrypt/decrypt），IV 版本额外带 `_with_iv` 后缀。
