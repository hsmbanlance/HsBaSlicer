- 公共头文件统一使用 `#pragma once` 配合 `HSBA_SLICER_<NAME>__HPP` 形式的 include guard 双重防护。
- 对外 API 集中在 `HsBa::Slicer` 命名空间，内部工具放在 `HsBa::Slicer::Utils`，反射相关再下沉到 `Utils::StaticReflect`。
- 运行时反射通过继承 `TypeInfo` 并特化 `GetTypeInfo<T>()` 注册类型元信息，销毁/拷贝/移动由函数指针表驱动。
- 可选功能通过宏开关裁剪：如 `HSBA_ANY_OBJECT_ENABLE_MOCK` 控制 Mockit-like 桩代码是否编译，默认检测常见测试框架宏自动开启。
- 跨语言边界使用 `extern "C" typedef struct ..._t` 形式导出 POD 结构体，避免 C++ ABI 泄漏。
- 线程安全容器（Delegate、MockRegistry）统一采用 `std::shared_mutex` + `std::lock_guard`/`std::shared_lock` 保护读写。
