- 每个工艺的示例遵循统一结构：`main.cpp` 定义多个 `RunXxxPipeline()` 静态函数（基本用法、自定义参数、Lua 钩子、异步、特殊模式），并在 `main()` 中顺序调用。
- 配置对象一律通过 `HsBaCreateDefaultConfig()` / `defaultFdmConfig()` / `defaultCustomConfig()` 获取默认值后再覆写字段，而非手动构造。
- 结果对象使用配对释放：`HsBaRun*Pipeline` 返回的结果必须调用对应的 `HsBaFreePipelineResult` / `HsBaFreeCustomPipelineResult` 释放 C 侧分配的字符串字段。
- 进度回调统一采用 `(int percent, const char* stage, void* user_data)` 签名，并通过 `HSBA_GAME_CONSOLE` 宏在控制台/游戏主机平台下禁用日志输出。
- Lua 扩展点通过 `*_lua_script` + `*_lua_func` 字段注入（如 `support_lua_script`/`infill_lua_script`），脚本内暴露固定函数名（如 `generate_support`、`generate_fill`、`run_pipeline`）。
- 资源路径使用相对路径（`models/stanford_bunny.stl`、`scripts/*.lua`、`output/...`），由 CMake POST_BUILD 命令复制到可执行文件所在目录。
