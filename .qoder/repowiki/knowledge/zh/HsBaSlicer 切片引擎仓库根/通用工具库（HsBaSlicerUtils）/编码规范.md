- Lua 可调用接口通过 CRTP 基类派生具体适配器，并由统一的 `Register*` 函数集中注册到 `lua_State*`。
- 新增 Lua 原生类型时，通过特化 `LuaAnyObjectNewCastImpl<T, "typename">` 并提供 `new_func_impl` / `cast_func_impl` 静态方法完成绑定。
- 从 Lua 栈取值后统一使用 `lua_error` + `std::format` 的错误消息模式抛出异常，避免静默失败。
- 对外暴露的类型名采用字符串字面量模板参数（`Utils::TemplateString`）而非运行期字符串，用于生成 Lua 可见的 type name 与函数名前缀。
- 结构体序列化通过 C++20 concept（`Aggregte` / `Reflectable`）约束模板参数，再交由对应格式的 `to_json` / `from_json` 等重载实现。
