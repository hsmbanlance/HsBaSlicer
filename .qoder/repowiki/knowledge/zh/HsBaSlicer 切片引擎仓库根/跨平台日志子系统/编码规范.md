- 日志级别统一使用 0~5 的 int 常量，各平台通过独立的 GetLogLevel/GetiOSLogType/GetAndroidLogPriority 辅助函数映射到后端枚举。
- 所有公开 API 均用 HSBA_SLICER_LOG_API 宏标注，Windows 下由 CMake 在构建目标上定义 HSBA_SLICER_LOG_EXPORTS 切换 dllimport/dllexport。
- 对 LoggerSingletone 的每次调用入口先检查 instance_ 为空则通过 std::call_once(instance_flag_, ...) 惰性创建，避免重复构造。
- 平台相关代码通过 #ifdef __ANDROID__ / #if defined(TARGET_OS_IOS) && TARGET_OS_IOS / 非 Android+iOS 三段守卫隔离，公共接口保持单一 switch(log_lv) 分发。
- 用户自定义字面量返回临时 LogState 对象，析构时触发实际日志输出，从而支持 "msg"_log_info() 这种延迟求值的流式写法。
