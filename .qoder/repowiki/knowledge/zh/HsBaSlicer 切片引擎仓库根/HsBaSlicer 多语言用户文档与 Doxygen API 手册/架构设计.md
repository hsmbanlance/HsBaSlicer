本模块由两类内容组成：
- 静态 Markdown 文档：顶层 `en/` 与 `zh/` 下镜像同一套目录结构（`base/`、`utils/`、`cipher/`、`fileoperator/`、`logger/`、`LibHsBaSlicer/`、`DllHsBaSlicer/`），每个子目录对应源码中的一个核心模块，每篇 `.md` 对应一个组件或主题；`README.md` 作为双语入口索引，汇总基础层、文件数据层、几何模型层、切片核心层的模块概览。
- 动态 API 文档：通过 `Doxyfile`（Doxygen 1.17.0）扫描仓库头文件注释，输出到 `doxygen/` 目录；`CMakeLists.txt` 使用 `find_package(Doxygen COMPONENTS dot)` 探测工具链，找到时注册 `docs` 自定义目标执行 `${DOXYGEN_EXECUTABLE} ${CMAKE_CURRENT_SOURCE_DIR}/Doxyfile`，未找到时打印警告并跳过该目标。
依赖方向单向：本模块仅消费源码中的头文件注释与仓库内 Markdown，不被源码反向引用。
