模块以 `CMakeLists.txt` 定义目标 `DllHsBaSlicer`：iOS 下退化为 STATIC（iOS 应用无法动态加载任意 dylib），其余平台构建 SHARED；通过 `target_compile_definitions` 注入 `HSBA_SLICER_EXPORTS`，由 `dllexport.h` 中的 `HSBA_SLICER_API` 宏在 Windows 上展开为 `__declspec(dllexport/dllimport)`，非 Windows 为空宏。

- 顶层入口：`initialize.cpp/.h` 暴露唯一的 `extern "C" void initialize()`，作为 DLL 加载时宿主调用的唯一初始化点，用于 Lua/pipeline 的一次性注册。
- 工艺管线适配层：每个主流工艺（FDM/SLA/SLS/SLM/LOM/TDP/WAAM）对应一对 `<xxx>_pipeline.{h,cpp}`，头文件仅声明 C ABI 函数族（`HsBaCreateDefaultConfig` / `HsBaRunXxxPipeline` / `HsBaRunXxxPipelineAsync` / `HsBaFreePipelineResult`），实现中负责将外部配置结构体映射到内部 `HsBaPipelineTypes` 并调用 `LibHsBaSlicer`。
- 通用脚本管线：`custom_pipeline.*` 提供完全由 Lua 驱动的管线接口，同步/异步双入口共享同一 config/result 结构体，并通过 `HsBa.progress()` 驱动进度回调。
- 横切能力：`model_preprocess.*` 负责模型预处理，`file_transfer_pipeline.*` / `param_store_pipeline.*` 处理文件传输与参数存储，`pipeline_convert.*` 做类型转换，`pipeline_parallel.hpp` 是转发至 `base/parallel.hpp` 的兼容 shim，按块分发层任务并通过 `HSBA_PIPELINE_THREADS` 环境变量控制线程数。
- 扩展点：`lua_register.*` 暴露 `HsBaAdd2DFunction/HsBaAdd3DFunction/HsBaAddFileFunction/HsBaAddEventCallback`，允许宿主进程向 Lua 环境注入自定义 2D/3D/File 阶段函数及事件回调；`event_source_register.*` 专门注册 zipper 与数据库事件源回调。
- 版本信息：`version_info.*` 暴露二进制版本查询。
- 依赖方向单向向下：本模块仅作为薄包装层，依赖 `LibHsBaSlicer`、`HsBaPipelineTypes` 以及 `HsBaSlicerBase/HsBaSlicerUtils/HsBaSlicerMesh/HsBaSlicer2D/HsBaPreprocess/HsBaSupport/HsBaPaths/HsBaSlicerFileOperator/HsBaVersion/HsBaSlicerConverter/HsBaSlicerProto` 等静态库，不反向引用上层宿主代码。
