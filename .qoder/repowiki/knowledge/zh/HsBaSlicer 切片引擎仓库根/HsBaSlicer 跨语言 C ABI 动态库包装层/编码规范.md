- 所有对外 C ABI 函数均使用 `extern "C"` 包裹并以 `HSBA_SLICER_API` 宏标注导出符号，确保跨语言调用稳定。
- 每个工艺管线以成对的 `<工艺>_pipeline.{h,cpp}` 文件组织，头文件只声明 C ABI 函数，实现中负责将外部配置映射到内部 pipeline types。
- 可选的异步管线接口采用「同步函数 + 同名 Async 函数」配对模式（如 `HsBaRunFdmPipeline` / `HsBaRunFdmPipelineAsync`），共享同一 config/result 结构体。
- 宿主扩展通过统一的 `HsBaLuaRegFn` 函数指针类型注册到 2D/3D/File 三类阶段，避免为每种扩展定义新回调签名。
- 头文件统一使用 `#pragma once` 配合 `HSBA_SLICER_<NAME>_H` 形式的 include guard 双重保护。
