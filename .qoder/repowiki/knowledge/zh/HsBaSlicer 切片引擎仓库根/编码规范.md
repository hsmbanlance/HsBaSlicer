- 编译器能力通过 `check_cxx_feature_*` 探测后以 `HSBA_HAS_*` / `HSBA_NO_*` 宏控制条件编译，而非直接检测编译器版本。
- 平台分支统一通过 `HSBA_DESKTOP` / `HSBA_MOBILE` / `HSBA_GAME_CONSOLE` / `ANDROID` / `IOS` 宏判断，避免在各子模块重复写 `if(WIN32|ANDROID|IOS)`。
- 可选功能（Copyleft 内核、DLL 加载器、bit7z、OpenGL dump、协程线程池、测试、文档、samples）均以 `HSBA_*` CMake option 暴露并在顶层集中决策。
- 对外 ABI 严格限定为 protobuf 生成的 `pipeline_types.h` 与 `DllHsBaSlicer/*.h` 中的 C 函数，C++ 类仅存在于内部库与 ModuleHsBaSlicer。
- 所有可安装目标通过统一的 `_HSBA_INSTALL_TARGETS` 列表注册，并使用 `HsBaSlicer::` 命名空间导出 CMake target。
