- 覆盖率门控：需安装 gcovr（`apt install gcovr` 或 `pip install gcovr`），运行前先 build 并执行测试，再执行 `cmake --build ... --target coverage`；可通过 `-DHSBA_COVERAGE_THRESHOLD_CORE=... -DHSBA_COVERAGE_THRESHOLD_OTHER=... -DHSBA_COVERAGE_JOBS=N` 调整阈值与并发。
- Windows UTF-8 清单：对目标调用 `hsba_apply_utf8_codepage(<target>)` 后由 MSVC 链接器自动嵌入 `hsba_utf8.manifest`。
- 静态检查：`python static_check/cpp_analyzer.py <path_or_file> [-c threshold] [-o report]`；`python static_check/clang-format-batch.py [-p path] [--style LLVM] [-j N] [--dry-run]`。
- Wiki 发布：`python scripts/repowiki_to_github_wiki.py [--lang en|zh|both] [--src .qoder/repowiki] [--out wiki-output]`。
