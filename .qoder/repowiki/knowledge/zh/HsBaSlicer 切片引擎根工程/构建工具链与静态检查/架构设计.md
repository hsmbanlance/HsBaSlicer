本模块按职责划分为四个子目录：
- `cmake/`：CMake 可复用片段。`HsBaSlicerConfig.cmake.in` 是对外发布的 find_package 入口，通过 `find_dependency` 声明 Eigen3/magic_enum/Clipper2/Lua/Protobuf/OpenSSL 等公共依赖并引入 `HsBaSlicerTargets.cmake`；`coverage.cmake` 在 GNU/Clang 下注入 `--coverage` 编译/链接选项，基于 gcovr 生成 JSON tracefile 后分 core/other 两路阈值门禁（`HSBA_COVERAGE_THRESHOLD_CORE`/`OTHER`），输出 HTML/XML 报告；`deploy_dlls.cmake` 作为独立 `-P` 脚本复制 PDB 到 exe 目录。
- `static_check/`：Python + CMake 混合的静态质量门禁。`cpp_analyzer.py` 实现 Gitignore 匹配、内存泄漏检测（new/malloc/calloc/realloc 配对）、catch-all 异常、`using namespace`、不安全函数、魔法数字、圈复杂度等规则；`clang-format-batch.py` 并行调用 clang-format 批量格式化；`feature_check.cmake` 用 `check_cxx_source_compiles` 探测 C11 `_Generic`、C++ concepts/ranges/source_location/NTTP/coroutines/explicit this/modules` 等编译器特性。
- `.github/workflows/`：多平台 CI（Linux/macOS/Windows/iOS/Android）+ `test-coverage.yml` + `publish-wiki.yml`，统一走 CMake + vcpkg + Ninja 流程。
- `overlay-ports/`、`triplets/`：vcpkg 扩展点，分别放置自定义 port 与自定义 triplet 定义。
依赖方向单向向外：CI → CMake 片段 → 外部依赖；Python 脚本仅读取源码树，不反向依赖项目目标。
