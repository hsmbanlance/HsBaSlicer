覆盖率门禁需安装 gcovr（`apt install gcovr` 或 `pip install gcovr`），并通过 `cmake -DHSBA_COVERAGE=ON` 或预设 `linux-coverage` 启用；`coverage` 目标会先解析 gcov 数据再分别对 core/other 模块执行 `--fail-under-line` 阈值检查。PDB 部署使用 `cmake -DTARGET_BIN=<exe_path> -DPDB_FILES=<pdb1;pdb2;...> -P cmake/deploy_dlls.cmake`。静态检查与格式化分别通过 `python static_check/cpp_analyzer.py <path>` 与 `python static_check/clang-format-batch.py [-p <repo>] [--style LLVM] [-j N]` 运行。
