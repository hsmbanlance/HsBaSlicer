- 公共头文件统一使用 `#pragma once` 配合 `HSBA_SLICER_<NAME>__HPP` 形式的 include guard。
- 对外 API 通过 `HSBA_SLICER_LOG_API` / `HSBA_SLICER_CIPHER_API` 等宏标记导出符号，便于动态库链接。
- 跨语言边界的数据结构（如 `HsBaVector2f_t`、`HsBaMatrix4f_t`）以 `extern "C" typedef struct` 形式暴露 POD 类型。
- 单例实现采用 `static shared_ptr` + `std::shared_mutex` + `std::once_flag` 的懒初始化模式（见 `LoggerSingletone`）。
- AnyObject 的类型注册通过特化 `GetTypeInfo<T>()` 并在其中填充 `TypeInfo::methods` 映射完成，新增类型遵循此扩展点。
- Mockit 风格的测试桩通过 `HSBA_ANY_OBJECT_ENABLE_MOCK` 宏开关，按 (TypeInfo*, method_name) 键注册规则与 stub，并以 `ScopedEnable`/`ScopedStubs` RAII 控制生命周期。
