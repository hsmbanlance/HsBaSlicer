- 每个流水线（FDM/SLA/SLS/SLM/LOM/TDP/WAAM/FileTransfer/Custom）在 `pipeline_types.h` 中成对定义 Config 与 Result 结构体，并配套 ProgressCallback 与 ResultCallback 函数指针类型。
- 所有 C ABI 类型使用 `HsBa` 前缀（如 `HsBaFdmPipelineConfig_t`、`HsBaProgressCallback`），并以 `_t` 后缀标记 typedef，统一置于 `extern "C"` 块内。
- 每个 Config 结构体均提供对应的 `HsBa*ConfigDefault()` 内联函数，将字符串字段初始化为 NULL、数值字段赋默认值，供调用方零初始化后按需覆盖。
- Result 结构体中包含 UTF-8 字符串指针（如 `gcode_content`/`error_message`/`export_path`），并在注释中标明由调用方负责释放（对应 `HsBaFree*PipelineResult`）。
- protobuf 消息命名采用 `msg_` 前缀（如 `msg_point3`、`msg_stltrimesh`、`msg_path3`），并按几何基元、网格、流水线三类分别组织到独立 `.proto` 文件中。
- convert 子模块以对称的 `<X>2Msg.<hpp|cpp>` 与 `Msg2<X>.<hpp|cpp>` 成对文件实现双向转换，命名空间统一为 `HsBa::Slicer`。
