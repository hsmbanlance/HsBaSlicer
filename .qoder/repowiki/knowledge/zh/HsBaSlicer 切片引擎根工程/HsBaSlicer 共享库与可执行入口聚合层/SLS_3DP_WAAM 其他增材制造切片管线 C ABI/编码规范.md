- 每个工艺在匿名命名空间内成对定义 `InternalXxxConfig` / `InternalXxxResult`，并由 `BuildXxxConfig` 从 C 结构体拷贝字段、`ToCResult` 反向转换，C 字符串所有权通过局部 `OwnedCString` RAII 包装后 `release()` 移交调用方。
- 流水线主体以 `RunXxxPipelineAsync` 协程实现，分 Stage 1/2/3 注释块组织，每步通过 `ReportProgress(cfg, percent, stage)` 上报进度，异常统一捕获 `RuntimeError` 并写入 `error_message`。
- 切片阶段先 `BuildSliceTopology` 一次，再 `ParallelForLayers` 并行 `SliceLayer`，层 Z 坐标由本地 `GetLayerZ(first_layer_height, layer_height)` 计算，避免重复算术。
- 对外 C API 同时提供同步 `HsBaRunXxxPipeline`（阻塞取 `task.get_result()`）与异步 `HsBaRunXxxPipelineAsync`（`task.then` 回调），后者用 `std::make_shared<InternalXxxConfig>` 持有配置供协程跨线程访问。
