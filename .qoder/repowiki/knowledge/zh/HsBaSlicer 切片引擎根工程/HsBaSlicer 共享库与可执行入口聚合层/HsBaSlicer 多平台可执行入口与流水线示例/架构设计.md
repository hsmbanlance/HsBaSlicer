本模块是 HsBaSlicer 的顶层应用层（dll_export_layer），仅包含一个 C++ 源文件 `HsBaSlicer.cpp` 与头文件 `HsBaSlicer.h`，作为跨平台可执行/库的单一入口。

- 依赖方向：本模块只向上依赖 `DllHsBaSlicer`（FDM/SLA/SLS 流水线 API）、`HsBaSlicerUtils`、`HsBaSlicerLog`，不引入任何内部算法实现，属于纯编排层。
- 构建产物由 `CMakeLists.txt` 按平台分支决定：Android 下为 SHARED 库并自动复制 `DllHsBaSlicer/*.so`；iOS 下为 STATIC 库；其余平台为可执行文件；Windows 下通过 `deploy_dlls.cmake` 在 POST_BUILD 阶段部署 PDB。
- 运行时入口通过 `#if defined(ANDROID) / #elif defined(__APPLE__) / else` 三向分发：Android 导出 JNI 函数 `Java_com_hsmbanlance_hsbaslicer_example_MainActivity_runPipelineExamples`，iOS 导出 C 函数 `HsBaRunPipelineExamples`，macOS/Desktop 使用标准 `main()`。
- 所有入口统一先初始化日志单例与 `initialize()`，再顺序调用 `RunFdmExample` / `RunSlaExample` / `RunSlsExample` 三个示例函数，每个示例遵循“创建默认配置 → 设置模型与参数 → 同步运行流水线 → 处理结果 → 释放内存”的固定流程。
