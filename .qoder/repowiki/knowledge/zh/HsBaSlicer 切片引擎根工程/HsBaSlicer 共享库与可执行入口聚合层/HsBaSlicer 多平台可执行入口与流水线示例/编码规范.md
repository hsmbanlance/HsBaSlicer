- 每条流水线示例遵循相同的七步模板：获取默认配置 → 设置 model_name/model_path → 可选参数覆盖 → 设置 output_path → 同步调用 `HsBaRun*Pipeline` → 根据 result.success 写日志 → 调用对应的 `HsBaFree*PipelineResult` 释放内存。
- 进度回调统一通过局部匿名命名空间中的 `OnProgress(int percent, const char* stage, void*)` 实现，并以字符串格式化 `[X%] <stage>` 格式写入日志。
- 日志输出统一走 `HsBa::Slicer::Log::LoggerSingletone`，桌面/macOS 路径还额外使用 `LogLiterals` 的 `_log_info` / `_log_warning` 字面量语法。
