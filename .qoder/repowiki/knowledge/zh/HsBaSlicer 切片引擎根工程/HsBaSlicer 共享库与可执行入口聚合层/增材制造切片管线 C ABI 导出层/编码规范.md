- 每个管线文件采用相同的四段式布局：匿名命名空间内的 InternalConfig/Result、OwnedCString、BuildConfig/ToCResult、RunXxxPipelineAsync 协程，以及末尾的 HSBA_SLICER_API C 导出函数。
- 跨 C ABI 边界传递的可变字符串一律通过本地 OwnedCString 持有，再通过 release() 移交所有权给调用方，并由对应的 HsBaFree*PipelineResult 负责 free。
- 协程参数使用引用而非值拷贝，并在注释中标注 NOLINT(cppcoreguidelines-avoid-reference-coroutine-parameters) 说明 caller 保证生命周期。
- 进度上报统一通过 ReportProgress(cfg, percent, stage) 完成，百分比在各阶段间线性插值（如 0→10→15→…→100）。
- Lua 扩展点遵循「可选脚本 + 默认函数名」模式：若提供 script 则读取文件内容后调用 func（缺省为 generate_support/generate_fill/export_sla 等），否则回退到内置 C++ 实现。
- 错误处理统一 catch RuntimeError 并将消息前缀 "Pipeline error: " 写入 result.error_message，成功路径设置 success=true 并返回 elapsed_seconds。
