- 每个管道文件采用匿名命名空间承载内部 `InternalXxxConfig` / `InternalXxxResult` 结构体与 `BuildXxxConfig` / `RunXxxAsync` / `ToCResult` 辅助函数，仅在文件末尾以 `// ========== C API ==========` 分隔后暴露 `HSBA_SLICER_API` 符号。
- C 字符串跨边界传递时统一使用 `OwnedCString`（或等价的 `DupToHeap`）通过 `std::malloc` 分配并由调用方通过对应的 `HsBaFreeXxxResult` 释放，避免 C/C++ 堆混用。
- 协程任务统一捕获 `RuntimeError` 并将其转换为 `InternalXxxResult.success=false` + `error_message`，同时用 `steady_clock` 包裹 try 块计算 `elapsed_seconds`。
- 同步 C API 内部构造 `Task` 后调用 `.get_result()` 阻塞等待，异步 C API 则 `std::make_shared` 持有配置并通过 `task.then` 回调返回结果，二者共享同一份 `RunXxxAsync` 实现。
- C 枚举到库内枚举的转换采用显式 `switch`（如 `ToLibKind`、`ToLibBackend`），而非依赖底层整型顺序，保证 ABI 稳定。
