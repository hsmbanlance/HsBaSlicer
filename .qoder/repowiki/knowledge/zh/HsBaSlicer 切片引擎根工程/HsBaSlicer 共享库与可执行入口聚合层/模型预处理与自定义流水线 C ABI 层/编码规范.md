- 所有 C ABI 函数统一以 `HSBA_SLICER_API` 标注并以 `extern "C"` 包裹，向非 C++ 调用方暴露稳定符号。
- C 函数入口对 `const char*` 参数进行空指针守卫并返回 0/NULL，避免将空指针传入内部 API。
- 内部 `HsBa::Slicer::RuntimeError` 在 C 边界被 catch 后转为返回值（1/0 或 NULL），绝不让 C++ 异常跨 ABI 传播。
- 需要返回对象生命周期的函数（如 Load/Get/Boolean）通过局部 `ToHandle` 将 `shared_ptr<IModel>` 包装为堆上指针，由 `HsBaReleaseModelHandle` 配对释放。
- CGAL 相关的高级操作（ThickSolid、BooleanUnion/Difference/Intersection/Xor）统一用 `#ifdef USE_CGAL` 包裹，未启用时返回 NULL 而非报错。
- C/C++ 字符串边界传递采用 `OwnedCString` 值语义包装 `malloc` 分配的空终止字符串，配合 `release()` 完成一次性所有权移交。
