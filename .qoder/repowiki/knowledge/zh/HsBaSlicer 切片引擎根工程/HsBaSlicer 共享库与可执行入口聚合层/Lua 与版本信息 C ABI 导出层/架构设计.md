本模块是 DllHsBaSlicer 动态库中面向外部调用方的薄包装层，仅包含两个职责清晰的源文件：
- `lua_register.cpp`：通过 `extern "C"` 暴露 `HsBaAdd2DFunction` / `HsBaAdd3DFunction` / `HsBaAddFileFunction` / `HsBaAddEventCallback` 四个导出函数，内部转发到 `HsBa::Slicer::Add*Functions` 与 `AddEventCallback`，由 `LibHsBaSlicer/Extends/LuaAddFunction.hpp` 完成实际注册。
- `version_info.cpp`：提供 `HsBaGetVersionJson` / `HsBaGetVersionXml` / `HsBaFreeVersionString` 三个 C ABI，内部调用 `LibHsBaSlicer/version_info.hpp` 获取 JSON/XML 字符串，并通过本地 `DuplicateString` 用 `malloc` 复制后交由调用方 `free`。
依赖方向单向指向 `LibHsBaSlicer`（核心实现）与 `HsBaVersion`（版本数据），不反向依赖任何上层管线；`CMakeLists.txt` 根据 iOS 平台在 STATIC/SHARED 之间切换构建目标，并将这两个文件纳入统一库源列表。
