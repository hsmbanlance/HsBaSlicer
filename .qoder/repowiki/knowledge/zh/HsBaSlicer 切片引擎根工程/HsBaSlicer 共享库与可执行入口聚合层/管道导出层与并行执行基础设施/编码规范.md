- 每个管线类型（FDM/SLA/SLS/…）都成对提供 `*FromProtoBytes` 与 `*ToProtoBytes` 两个 `HSBA_SLICER_API int` 函数，失败返回 0、成功返回 1，并在入口统一校验空指针与 size。
- 序列化流程固定为：构造对应 `HsbaProto::xxx_pipe_config/result` 消息 → 调用 `HsBa::Slicer::MsgToXxx` / `XxxToMsg` → `ByteSizeLong()` 分配 buffer → `SerializeToArray` 写入 → 通过 out 参数返回裸指针与长度。
- 配置结构体的 C 字符串字段通过同名的 `HsBaFreeXxxConfigStrings` 释放，内部复用匿名命名空间内的 `FreeIfNotNull` 辅助函数，避免重复 free。
- 并行循环使用 `ParallelForLayers` 包裹，work 仅写自身 layer_index 对应的输出槽，进度回调 `on_progress` 在块结束后由调用线程串行触发。
