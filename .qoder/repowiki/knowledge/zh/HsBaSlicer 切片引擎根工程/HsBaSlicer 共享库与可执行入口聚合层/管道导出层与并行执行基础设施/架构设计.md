本模块处于 DLL 边界，承担三类职责：
- `pipeline_convert.cpp`：以 `HsBaFdm/Sla/Sls/FileTransfer/Custom/Slm/Lom/Tdp/Waam` 各管线类型为单位，成对暴露 `*FromProtoBytes` / `*ToProtoBytes` / `*ConfigStrings` 清理函数，内部委托 `convert/Msg2PipelineConfig.hpp` 与 `convert/PipelineConfig2Msg.hpp` 中的 `MsgToXxx` / `XxxToMsg` 完成 protobuf ↔ C struct 转换，并通过 `std::malloc` + `FreeIfNotNull` 管理跨 ABI 的字符串内存。
- `pipeline_parallel.hpp`：头文件内联的 `ParallelForLayers`，基于 `base/thread_pool.hpp` 的 `ThreadPool` 将互不依赖的层分发到线程池，按 block 聚合进度回调；通过环境变量 `HSBA_PIPELINE_THREADS` 在运行时切换串行/并行路径，用于性能对比验证。
- `event_source_register.cpp`：把 C 风格的函数指针包装为 `HsBa::Slicer::AddZipperEventCallback` / `AddDBEventCallback` 所需的 lambda，并做 `string_view` → `const char*` 的生命期拷贝。
依赖方向单向向外：本模块依赖上层 `convert/*` 转换器与 `LibHsBaSlicer/Extends/EventSourceFunction.hpp`，不被核心切片逻辑反向引用，是纯对外适配层。
