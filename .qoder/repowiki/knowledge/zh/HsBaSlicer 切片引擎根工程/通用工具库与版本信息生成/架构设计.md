模块由两个并列的 CMake 子目标组成：
- `utils/` 构建为 `HsBaSlicerUtils` 静态库，按职责划分为若干独立头文件：`LuaNewObject.hpp` 提供 Lua userdata 生命周期管理（`NewLuaObject` / `LuaGC` / `UniqueLua`），`LuaAnyObject.hpp` 基于 CRTP（`LuaAnyObjectNewCastBase` → `LuaAnyObjectNewCastAbstract` → `LuaAnyObjectNewCastImpl<T, TypeName>`）为基本类型和自定义类型生成 `new_<type>` / `cast_<type>` 注册函数，并通过 `RegisterAnyObject` 统一注入；`struct_concepts.hpp` 定义 `Aggregte` / `Reflectable` C++20 concepts，驱动 `struct_json.hpp` / `struct_xml.hpp` / `struct_yaml.hpp` 对聚合类型进行反射式序列化；`app_config.cpp` 暴露线程安全的 `AppConfigSingletone` 单例；`Graph.hpp` / `AreaGraph.hpp` 提供基础图算法；`LuaDllLoader.*` 负责动态加载 Lua 脚本。
- `version/` 构建为 `HsBaVersion` 静态库，CMake 在 configure 阶段调用 `Generator_Version.ps1` 从 `vcpkg.json`、`HSBA_COPL`、构建类型等变量生成 `version.cpp`，再编译进库，对外暴露 `GetVersionInfo()`。
依赖方向单向向外：本模块依赖 `HsBaSlicerBase`、`HsBaSlicerFileOperator`、Boost.Date_Time、rapidjson、tinyxml2、yaml-cpp、Lua，不被上层业务逻辑反向依赖。
