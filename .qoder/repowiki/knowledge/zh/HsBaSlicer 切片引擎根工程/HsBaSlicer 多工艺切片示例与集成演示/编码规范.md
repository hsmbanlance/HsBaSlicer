- 每个工艺示例遵循统一四段式：获取默认配置 → 设置 model_name/model_path/output_path → 调用 `HsBaRun*Pipeline` 同步或 `HsBaRun*PipelineAsync` 异步 → 检查 result.success 并调用对应的 `HsBaFree*Result` 释放内存。
- 日志输出通过本地 `LogMsg` 辅助函数封装，使用 `#ifndef HSBA_GAME_CONSOLE` 在控制台平台回退到空实现，保证游戏主机也能编译。
- Lua 扩展点通过配置项中的 `<stage>_lua_script` + `<stage>_lua_func` 成对指定脚本路径与函数名，由 C++ 侧在对应流水线阶段动态加载执行。
- 资源文件通过 CMake `add_custom_command(TARGET ... POST_BUILD)` 复制到 `$<TARGET_FILE_DIR:target>/models` 与 `scripts`，避免在 configure 期展开生成器表达式。
