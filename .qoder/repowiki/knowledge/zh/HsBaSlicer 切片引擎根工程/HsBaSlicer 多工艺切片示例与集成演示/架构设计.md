samples 是纯示例集合，按工艺划分目录，每个子目录是一个独立的 CMake target：
- FDM / SLA / SLS / SLM / TDP / WAAM / LOM：各自提供 main.cpp + scripts/*.lua，通过 DllHsBaSlicer 的 C ABI（`HsBaCreateDefault*Config`、`HsBaRun*Pipeline`、`HsBaFree*Result`）调用对应流水线，Lua 脚本仅替换支撑/填充/地板/导出等阶段。
- Custom：完全由 Lua 接管整条工作流，C++ 侧只暴露 `HsBaCustomPipelineConfig_t` 与 `HsBaRunCustomPipeline`，并通过内嵌的极简 Protobuf wire 编解码器演示跨语言调用（不链接 protobuf 运行库，避免描述符重复注册）。
- LibHsBaSlicer：展示绕过 DllHsBaSlicer 直接链接 LibHsBaSlicer 的方式，同时提供传统头文件版（`main_header.cpp`）和 C++20 module 版（`import hsba.slicer;`），后者依赖 `HSBA_SLICER_MODULE=ON`。
依赖方向单向指向核心库（DllHsBaSlicer / LibHsBaSlicer / ModuleHsBaSlicer），示例之间互不依赖，但共享 FDM/models/stanford_bunny.stl 作为测试模型；Android/iOS 下所有 sample 均编译为静态库而非可执行文件以保留编译校验。
