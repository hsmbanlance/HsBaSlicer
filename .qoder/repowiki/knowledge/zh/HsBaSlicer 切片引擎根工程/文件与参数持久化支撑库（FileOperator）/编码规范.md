- 归档后端通过继承 `IZipper` 或 CRTP 基类 `IUnzipper<Derived>` 实现，具体实现类使用私有 `struct Private` 配合友元 `friend class I...` 限制构造。
- 可插拔后端统一通过 `#ifdef HSBA_USE_*` / `#ifdef HSBA_HSBA_USE_*` 宏进行条件编译，Lua 注册函数也随宏成对出现。
- SQL 适配器采用 PIMPL 模式（内部 `class Impl; std::unique_ptr<Impl> impl_;`）+ `std::shared_mutex` 保证线程安全，对外暴露 `ISQLAdapter` 接口。
- SQL 操作通过 `operator|` 管道语法与 `SQLSelect`/`SQLInsert`/`SQLUpdate`/`SQLDelete`/`SQLCreateTable`/`SQLRemoveTable` 结构体组合，rvalue 重载一律删除以防止误用。
- 面向 Lua 的导出集中在 `LuaAdapter.*`，通过 `RegisterLua*` 系列函数将 C++ 对象包装为 userdata 后 push 到 lua_State。
- ParamStore 的错误处理策略是记录 `last_error_` 的同时抛出异常，不吞掉错误，由上层（含 Lua）决定处理方式。
