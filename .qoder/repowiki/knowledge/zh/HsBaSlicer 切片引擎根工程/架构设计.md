根目录通过顶层 CMakeLists.txt 与 CMakePresets.json 统一调度各子模块：
- 依赖分层：base_library → utils_library → geometry_and_model_layers → geometry_core/support_system/preprocess → data_types_and_proto/dll_export_layer/module_interface → android_app/samples/tests。
- ABI 契约：dll_export_layer 暴露的 HSBA_SLICER_API C ABI 与 data_types_and_proto 中的 protobuf/C++ 转换器是跨模块边界；module_interface 在其上封装 C++20 module `hsba.slicer`。
- 插件扩展点：geometry_and_model_layers 的 IModel 抽象、support_system 的 ISupport 接口、file_operator 的 AnyObject 反射参数持久化共同构成可插拔管线。
- 构建产物：samples/android_app/tests 作为消费者链接 LibHsBaSlicer（dll_export_layer 产出），build_tooling 提供覆盖门禁与 CI。
- 版本信息由 utils_library 在配置阶段通过 PowerShell 生成静态常量供全仓消费。
