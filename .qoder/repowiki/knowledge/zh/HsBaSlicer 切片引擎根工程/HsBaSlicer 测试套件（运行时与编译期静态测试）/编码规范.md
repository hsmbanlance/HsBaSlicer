- 每个测试用例文件顶部使用 `#define BOOST_TEST_MODULE <name>` 并包含 `<boost/test/included/unit_test.hpp>` 以启用内置模式。
- CMake 中每个测试目标统一遵循 `add_executable` → `target_link_libraries(... Boost::unit_test_framework)` → `target_compile_definitions(... BOOST_TEST_DYN_LINK)` → `enable_testing()` → `add_test(NAME ... COMMAND $<TARGET_FILE:...>)` 的固定顺序。
- 可选功能测试通过 CMake 条件块（`if(HSBA_COPL)`、`if(TARGET HsBaSlicerCADModel)`、`if(HSBA_POLYGON_DUMP)`、`if(MSVC)`）包裹，未启用时不参与构建。
- 需要模拟外部 DLL 的场景（CAD Model、DLL Loader、PointCloud）采用同目录下的 `mock_<xxx>_dll.cpp` 单独编译为共享库供测试可执行程序链接。
- 针对平台差异的代码路径使用编译器宏（`_MSC_VER`、`__GNUC__`、`__clang__`）进行条件编译，而非运行时分支。
