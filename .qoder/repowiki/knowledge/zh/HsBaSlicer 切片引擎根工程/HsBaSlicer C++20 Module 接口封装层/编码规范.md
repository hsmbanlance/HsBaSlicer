- 每个流水线类型（FDM/SLA/SLS/SLM/LOM/TDP/WAAM/FileTransfer/ParamStore/CustomLua）都暴露为一个独立的 class，构造函数接受对应的 `HsBa*Config_t` 并保存为私有成员，对外只暴露 `run()` 及若干可选子步骤方法。
- 所有可能失败的公共方法统一通过抛出 `SlicerError : public std::runtime_error` 表达错误，而非返回 bool 或 error code。
- Lua 可扩展的流水线在运行时检查 `cfg_.xxx_lua_script`，若存在则走 Lua 路径（如 `GenerateAllLuaSupport`、`SaveSlsPackageLua`、`LuaCustomFillByFile`），否则回退到内置算法实现。
- 默认配置工厂函数（`defaultFdmConfig` 等）在本模块内直接转发到 `LibHsBaSlicer` 的 `HsBa*ConfigDefault()`，避免消费者依赖 GMF 静态变量。
- 二维多边形在整数精度（`Polygons`/`Path64`）与浮点精度（`PolygonsD`/`PathD`）之间通过 `Integerization` / `UnIntegerization` 显式转换，slice 输出先用整型再按需转双精度。
- 模块采用单文件 .cppm 模式（声明与实现同在 `hsba_slicer.cppm`），以避免 MSVC 在分离 impl unit 时出现 implicit-import std:: 重定义的 C2572 错误。
