模块由三个文件组成：
- `hsba_slicer.cppm` 是单一 C++20 module interface unit（声明与实现同在一个 `.cppm`），对外 `export module hsba.slicer;`，内部以 `namespace HsBa::Slicer` 组织。
- `module_anchor.cpp` 仅含一个空符号，用于强制 CMake 的 archiver 生成静态库归档（避免纯 CXX_MODULES FILE_SET 在某些 CMake 版本下不触发 lib.exe）。
- `CMakeLists.txt` 将该目录构建为 STATIC 库 `ModuleHsBaSlicer`，并通过 `target_sources ... FILE_SET hsba_slicer_modules` 注册 module interface，同时 PUBLIC link 到 `LibHsBaSlicer`、`HsBaPipelineTypes`、Eigen3、Clipper2、Lua。

内部分层清晰：顶层提供 RAII 的 `Model` 包装器与一组 Pipeline 类（FdmPipeline/SlaPipeline/SlsPipeline/SlmPipeline/LomPipeline/TdpPipeline/WaamPipeline/FileTransferPipeline/ParamStorePipeline/CustomLuaPipeline），每个 Pipeline 持有对应 `HsBa*Config_t` 配置并在 `run()` 中按固定顺序调用底层自由函数（Slice → Support → Fill → Path / Floor → Render → Package）。Lua 扩展点通过 `add2DFunction/add3DFunction/addFileFunction/addEventCallback` 注入，使脚本可参与 Slice/Support/Fill/Output 各阶段。依赖方向单向向下：本模块仅消费 `LibHsBaSlicer/*` 与项目内 `pipelinetypes`、`2D`、`meshmodel`、`paths`、`support` 等头，不被其反向依赖。
