Build via CMake presets defined in `CMakePresets.json` (e.g. `cmake . --preset linux-release` → `out/build/linux-release`). Dependencies resolved through vcpkg (`vcpkg.json` + `vcpkg-configuration.json`); enable optional features via `VCPKG_MANIFEST_FEATURES` (e.g. `rest-api` for cpp-httplib, `copyleft` for CGAL/OpenCASCADE). Desktop UTF-8 active code page is auto-applied via `cmake/HsBaWindowsUtf8.cmake`. Coverage build uses `HSBA_COVERAGE=ON` (gcov/gcovr, Core ≥45% / Other ≥25% gate). Tests disabled on Android/iOS/game consoles; run with `ctest` after `enable_testing()` from the top-level build dir.
