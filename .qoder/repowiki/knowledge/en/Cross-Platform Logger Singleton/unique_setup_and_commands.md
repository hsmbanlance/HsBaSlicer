Build as either static or shared library via the parent CMake configuration; when building the SHARED target, define `HSBA_SLICER_LOG_EXPORTS` so `export.h` emits `__declspec(dllexport)` on Windows. At runtime, place a `logcfg.ini` next to the executable with sections `log.log_level[_debug]`, `log.use_log_file`, `log.log_file`, and `log_format.log_datatime_format` to override defaults (default log path is `<cwd>/log/log.txt`).
