Build configuration is driven by CMake options at the top level: `-DHSBA_BUILD_REST_API=ON -DVCPKG_MANIFEST_FEATURES=rest-api` to enable the optional REST server; `-DHSBA_COPL=ON` to link CGAL/OpenCascade (switches license to GPL-3.0-or-later); `-DHSBA_SLICER_MODULE=ON` for the C++20 module wrapper; `-DHSBA_SLICER_USE_TESTS=ON/OFF`; `-DHSBA_SLICER_RUN_TESTS_AFTER_BUILD=ON/OFF`. Tests are registered via `enable_testing()` at the root so `ctest` works from the build directory. Windows builds automatically embed an active-code-page UTF-8 manifest for all executables.
