Built as a single static library `HsBaSlicerBase` (CMakeLists.txt) with no internal sub-packages; files are grouped by responsibility:
- Model abstraction: `IModel.hpp` defines the `IModel` abstract base plus the `ModelFormat` enum (mesh/BRep/CSG/point-cloud groups) and a flat `extern "C"` struct block (`HsBaVector2f`, `HsBaMatrix4f`, `HsBaPolys2D_t`, …) that forms the C ABI boundary for FFI consumers.
- Format dispatch: `ModelFormat.{hpp,cpp}` centralizes `ToString`, extension parsing (`GetExtName`, `ModelTypeFromExtName`) and category predicates (`IsMeshFormat`, `IsBrepFormat`, `IsCSGFormat`, `IsPointCloudFormat`).
- Reflection / scripting bridge: `any_object.{hpp,cpp}` + `any_visit.hpp` implement a type-erased `AnyObject` backed by per-type `TypeInfo` (destroy/copy/move + field/method maps); `member_fn_traits` + `type_ensure` auto-register free functions as methods. A `MockRegistry` (gated by `HSBA_ANY_OBJECT_ENABLE_MOCK`) provides test-time stubbing of `Invoke`.
- Error system: `error.{hpp,cpp}` defines a `RuntimeError` hierarchy (`OutOfRangeError`, `IOError`, `NotFoundError`, …) used throughout the library.
- Concurrency: `thread_pool.hpp` (`ThreadPool` + optional `ThreadPoolExecutor` implementing `IExecutor` from `coroutine.hpp`), `parallel.hpp`, `delegate.hpp`, `singleton.hpp`, `memory_pool.hpp`, `object_pool.hpp`.
- Geometry math: `eigen_translator.{hpp,cpp}` bridges Eigen types to/from the C ABI structs in `IModel.hpp`; `units.hpp`, `string_helper.hpp`, `template_helper.hpp`, `concepts.hpp`, `contracts.hpp`, `tuple_each.hpp` are small generic utilities.
- Encoding / filename: `encoding_convert.{hpp,cpp}` uses Boost.Locale/Nowide on desktop platforms (see CMake conditional linking); `filename_check.{hpp,cpp}` validates paths.
Dependency direction is one-way outward: this module depends on Eigen3, magic_enum, and optionally Boost.Locale/Boost.Nowide; it is consumed by every higher-level slicer module but exposes no public headers beyond those listed in CMakeLists.txt.
