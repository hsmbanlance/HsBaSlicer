Build requires CMake ≥ 3.28, a C++20-capable compiler, and vcpkg. Typical flow: `mkdir -p build && cd build && cmake .. -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake && cmake --build . --config Release`. Desktop presets are available via `cmake --preset <linux-release|windows-release|...>` from the repo root. To enable the REST server, configure with `-DVCPKG_MANIFEST_FEATURES=rest-api` (or set env var) and `-DHSBA_BUILD_REST_API=ON`; to include GPL copyleft kernels add `-DVCPKG_MANIFEST_FEATURES=copyleft` (or `-DHSBA_COPL=ON`). Coverage builds use `-DHSBA_COVERAGE=ON` and run `ctest` against Core ≥ 45% / Other ≥ 25% thresholds.
