The module builds the static library `HsBaVersion` (CMakeLists.txt) which exposes a single public API in `version.hpp`: the `HsBa::Slicer::Version` namespace with `ThirdLibraries` / `VersionInfo` structs and the `GetVersionInfo()` accessor. The implementation is not hand-written: CMake's `execute_process` invokes `Generator_Version.ps1` at configure time to render `version.cpp.in` into a concrete `version.cpp` under the build tree. The PowerShell generator parses `vcpkg.json`, resolves platform-scoped `default-features` via a small expression evaluator (`Test-VcpkgPlatform` supporting `|`, `&`, `!`), merges explicit features passed through `VCPKG_MANIFEST_FEATURES`, walks all top-level and feature-scoped dependencies, emits a `push_back` for each known library from its internal `libInfoMap`, and flips the project license between MIT and GPL-3.0-or-later based on whether any copyleft (GPL/LGPL without an OR clause) dependency is present. The generated source embeds `@CMAKE_BUILD_TYPE@`, `@CONFIGURE_TIME@`, `@VCPKG_TARGET_TRIPLET@`, and the resolved target platform string (Windows/Linux/macOS/Android/iOS/GameConsole/Unknown). Dependency direction: `HsBaVersion` depends only on `HsBaSlicerBase` (for `Utils::InplaceVector`) and is consumed by higher layers that need runtime version/license introspection.
