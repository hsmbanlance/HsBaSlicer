The root `CMakeLists.txt` is the single entry point that detects compiler capabilities (C++20 concepts/ranges/source_location/NTTP), enforces `-fPIC`, selects platform/toolchain via vcpkg triplets, and conditionally enables copyleft kernels (CGAL + OpenCASCADE) which flips the project license from MIT to GPL-3.0-or-later. It then `add_subdirectory()` in a strict dependency order: `proto` → `base` → `cipher` → `utils` → `logger` → `2D` → `paths` → `fileoperator` → `meshmodel` → (`cadmodel` if copyleft) → (`pointcloud`) → `preprocess` → `support` → `pipelinetypes` → `convert` → `LibHsBaSlicer` → (`ModuleHsBaSlicer` C++20 module) → `DllHsBaSlicer` → `HsBaSlicer` (version). The public surface is layered: `LibHsBaSlicer` exposes the C++ pipeline API, `DllHsBaSlicer` wraps it behind a stable C ABI for host languages, and `ModuleHsBaSlicer` provides a C++20 module wrapper over those free functions. All internal static libraries are exported under the `HsBaSlicer::` CMake namespace via `install(EXPORT ...)` and `find_package(HsBaSlicer CONFIG)` is supported. Optional features (copyleft kernels, bit7z, OpenCV, coroutine thread pool, polygon dump, tests, docs, samples) are toggled through `HSBA_*` options that propagate compile definitions across children.
