Two-layer generator pipeline driven by CMake at configure time:
- `CMakeLists.txt` locates `pwsh`/`powershell`, invokes `Generator_Version.ps1` with `-OutputPath`, `-BuildType`, `-VcpkgTriplet`, `-VcpkgJsonPath`, and `-Copyleft`, then compiles the produced `version.cpp` into the static library `HsBaVersion` (publicly linking `HsBaSlicerBase`).
- `Generator_Version.ps1` parses `vcpkg.json`, maps the vcpkg triplet to a target platform (Windows/Linux/macOS/iOS/Android/GameConsole), walks the dependency list (including optional `features.copyleft` deps when enabled), looks up each dep in an inline license/homepage map, emits `ThirdLibraries` entries, and decides the project license (`GPL-3.0-or-later` if any GPL/LGPL without an OR clause is present, otherwise MIT). The generated file defines `HsBa::Slicer::Version::GetVersionInfo()` returning a `VersionInfo` struct.
- `version.hpp` declares the public API (`VersionInfo`, `ThirdLibraries`, `GetVersionInfo`) using `std::string_view` fields and `Utils::InplaceVector` for the dependency list; `version.cpp.in` is a CMake-configured fallback template (uses `@VAR@` placeholders) kept in sync with the PowerShell generator's output shape.
Dependency direction: this module depends only on `base/InplaceVector.hpp` from `HsBaSlicerBase`; nothing in the rest of the tree depends on it except via the public header.
