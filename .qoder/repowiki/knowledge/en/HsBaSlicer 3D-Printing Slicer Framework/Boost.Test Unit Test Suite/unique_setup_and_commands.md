Build/test flow is controlled by CMake variables: `-DHSBA_SLICER_RUN_TESTS_AFTER_BUILD=ON` (default ON) auto-runs ctest after each test binary builds; `-DHSBA_COPL=ON` enables CGAL-related tests; `-DHSBA_POLYGON_DUMP=ON` enables Lua polygon dump tests; on MSVC the Graph test requires `/bigobj` due to Boost.Graph template instantiation limits. Tests are invoked via `ctest` from the build tree.
