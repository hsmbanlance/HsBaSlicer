Two sibling sub-trees under `base/` and `logger/` that together form the runtime foundation of the project.

- `base/` is a header-heavy utility library. Core abstractions: `IModel.hpp` defines the `HsBa::Slicer::IModel` interface plus the `ModelFormat` enum and a flat `extern "C"` ABI struct set (`HsBaVector2f_t`, `HsBaMatrix4f_t`, `HsBaPolys2D_t`, …) for interop with other layers; `base_interface.hpp` exposes the generic `ITranslator<T>` string-conversion interface. Type system helpers live in `any_object.hpp` (`AnyObject` + `TypeInfo` registry with per-type method maps, `GetTypeInfo<T>()` template, `member_fn_traits`) and are gated behind `HSBA_ANY_OBJECT_ENABLE_MOCK`, which auto-detects Boost.Test / GoogleTest / Catch2 / Doctest macros to compile an in-process `MockRegistry` supporting `StubMethod`/`WhenCalled`/`ScopedStubs`. Error taxonomy (`error.hpp`) derives every exception from `RuntimeError` (e.g. `IOError`, `NotFoundError`, `TimeoutError`). Supporting utilities include `singleton.hpp` (thread-safe `Utils::Singleton<T>` via `std::call_once`), `memory_pool.hpp`, `object_pool.hpp`, `thread_pool.hpp`, `coroutine.hpp`, `delegate.hpp`, `concepts.hpp`, `template_helper.hpp`, `tuple_each.hpp`, `string_helper.hpp`, `filename_check.hpp`, `units.hpp`, `static_reflect.hpp`, `boost_std_convert.hpp`, `encoding_convert.*`, `eigen_translator.*`, `ModelFormat.*`, and `InplaceVector.hpp`. Dependency direction inside `base/` is one-way: higher-level headers (e.g. `any_object.hpp`) depend on lower-level ones (`error.hpp`, `concepts.hpp`); nothing in `base/` depends on `logger/`.
- `logger/` is a separate CMake-built shared library exposing `HsBa::Slicer::Log::LoggerSingletone` (a `Utils::Singleton` subclass) with leveled static entry points (`LogDebug`/`LogInfo`/`LogWarning`/`LogError`) and user-defined literals `_log_debug`/`_log_info`/`_log_warning`/`_log_error` returning a `LogState` RAII object whose destructor flushes. Backend selection is conditional: Boost.Log when available, Apple `os_log` on iOS, otherwise a minimal fallback. The `export.h` header provides `HSBA_SLICER_LOG_API` visibility macros for Windows DLL import/export.

The two trees are independent build targets (`base/CMakeLists.txt`, `logger/CMakeLists.txt`); consumers link whichever they need.
