Single-module Android application (`:app`) built with the Gradle `com.android.application` plugin (AGP 8.3.2, compileSdk/targetSdk 34, minSdk 21). The only Java source is `MainActivity.java`, which statically loads `libHsBaSlicer.so` via `System.loadLibrary("HsBaSlicer")` and calls the JNI entry `runPipelineExamples()` to exercise the native FDM/SLA/SLS pipelines shipped as prebuilt `.so` files under `src/main/jniLibs/arm64-v8a/` (both `libHsBaSlicer.so` and its dependency `libDllHsBaSlicer.so`). ABI is restricted to `arm64-v8a` through `android.defaultConfig.ndk.abiFilters`. There are no Kotlin sources, no third-party dependencies, and no UI beyond a single `TextView` — the app exists purely as a JNI bridge and smoke test for the native library.
