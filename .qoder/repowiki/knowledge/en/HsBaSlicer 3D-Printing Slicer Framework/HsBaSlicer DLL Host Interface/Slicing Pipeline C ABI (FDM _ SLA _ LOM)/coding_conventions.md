- Each pipeline file defines a private `Internal*Config` struct mirroring the public C config, plus a `Build*Config` translator and a `ToCResult` converter that uses an anonymous-namespace `OwnedCString` RAII guard to transfer `malloc`-owned C strings across the boundary.
- The coroutine entry point installs common Lua types via `HsBa::Slicer::InstallCommonAnyObjectTypes()`, wraps all work in a single try/catch that converts `RuntimeError` into a failure result, and measures elapsed time with `std::chrono::steady_clock`.
- Progress reporting goes through a local `ReportProgress(cfg, percent, stage)` helper that invokes `cfg.progress_cb(percent, stage.c_str(), cfg.progress_user_data)` only when the callback is non-null.
- Per-layer work is parallelized with `ParallelForLayers(total_layers, lambda, progress_callback)` after building a shared slice topology once via `BuildSliceTopology`, since `SliceLayer` only const-reads it.
- Lua customization is opt-in: if a `<stage>_lua_script` field is empty the built-in C++ implementation is used; otherwise the script file is read into memory and passed to the corresponding `Lua*ByFile`/`Save*SlaPackageLua`/`Save*SlsPackageLua` function, with a default function name derived from the `<stage>_lua_func` field.
- The C API exposes paired sync/async functions (`HsBaRun*Pipeline` blocking on `task.get_result()`, `HsBaRun*PipelineAsync` wrapping the config in `std::make_shared` and chaining `task.then(...)`) plus a matching `HsBaFree*PipelineResult` that frees the owned C strings.
