- Each pipeline file mirrors the same shape: anonymous-namespace helpers (`OwnedCString`, `CalculateLayerCount`, `GetLayerZ`, `ReportProgress`, `Build*ConfigJson`), an `Internal*Config`/`Internal*Result` pair, `Build*Config` + `ToCResult` converters, a coroutine `Run*PipelineAsync`, and a block of `HSBA_SLICER_API` C functions.
- C-owned heap strings are bridged across the ABI boundary via a local `OwnedCString` RAII wrapper that allocates with `std::malloc`, moves ownership out through `release()`, and frees in its destructor — paired with a matching `HsBaFree*PipelineResult` caller-side free.
- The three-stage pipeline flow (Preprocess → Slice → Lua Export) is identical across SLS/SLM/3DP, differing only in the process name injected into the generated JSON (`"SLS"`, `"SLM"`, `"3DP"`) and the enum-to-string helpers (`SlmMaterialName`/`SlmLightName`/`MetalGasName` vs. `BinderModeName`).
- Progress callbacks are invoked at fixed percentage milestones (0/10/15/50/60/100%) with human-readable stage labels, and layer-slice progress is interpolated as `15 + (done * 35) / total_layers`.
- Export requires a non-empty `export_lua_script`; when missing the pipeline short-circuits with an error message naming the missing field, and the default Lua function name is derived from the process (`export_sls` / `export_slm` / `export_tdp`) unless overridden by `export_lua_func`.
- Errors propagate by setting `result.success = false` and populating `error_message`, with top-level exceptions caught as `RuntimeError` and wrapped in a `"Pipeline error: "` prefix.
