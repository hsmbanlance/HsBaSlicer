Coverage: enable via `-DHSBA_COVERAGE=ON` or the `linux-coverage` CMake preset; run tests then `cmake --build . --target coverage` — fails if core/non-core buckets miss their thresholds. Coverage tuning via cache vars `HSBA_COVERAGE_THRESHOLD_CORE`, `HSBA_COVERAGE_THRESHOLD_OTHER`, `HSBA_COVERAGE_JOBS`. Static checks: `python static_check/cpp_analyzer.py <path>` (exit 1 on fatal issues) and `python static_check/clang-format-batch.py [-j N] [--dry-run]`. Documentation publishing: `python scripts/repowiki_to_github_wiki.py [--lang en|zh|both] [--src .qoder/repowiki] [--out wiki-output]`. Windows symbol deployment: `cmake -DTARGET_BIN=<exe> -DPDB_FILES=<pdb...> -P cmake/deploy_dlls.cmake`.
