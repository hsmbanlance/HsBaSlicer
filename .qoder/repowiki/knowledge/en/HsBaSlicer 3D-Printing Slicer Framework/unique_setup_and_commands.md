Configure with `cmake .. -DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake`; presets in `CMakePresets.json` provide `linux-release`/`windows-release`/etc.; enable copyleft kernels via `VCPKG_MANIFEST_FEATURES=copyleft` or set `HSBA_COPL=ON`; toggle coverage with `-DHSBA_COVERAGE=ON` (adds a `coverage` target gating core ≥45% / other ≥25% line coverage); install via `cmake --install <build_dir> --prefix <prefix> --config Release` and consume downstream with `find_package(HsBaSlicer CONFIG REQUIRED)` linking `HsBaSlicer::DllHsBaSlicer` or `HsBaSlicer::LibHsBaSlicer`.
