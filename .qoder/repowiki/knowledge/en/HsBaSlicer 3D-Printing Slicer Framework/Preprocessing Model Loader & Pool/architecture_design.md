Single-class leaf module (`HsBa::Slicer::ModelLoader`) in `ModelLoader.hpp`/`.cpp`, built as the `HsBaPreprocess` static library via `CMakeLists.txt`. It owns a `NamedObjectPool<IModel, HSBA_MODEL_POOL_SIZE>` (from `base/object_pool.hpp`) and exposes a uniform `IModel`-based API. `LoadModel` routes by extension through `ModelTypeFromExtName` / `IsPointCloudFormat` / `IsMeshFormat` / `IsBrepFormat` into three concrete backends: mesh formats → `IglModel`, BRep formats → `OcctModel`, point-cloud formats → `OpenVdbModel`. Optional features are gated by compile-time macros: CGAL boolean/thick-solid operations under `#ifdef USE_CGAL`, OpenVDB point-cloud operations under `#ifdef USE_OPENVDB`, OCCT CAD kernel only when `HSBA_COPL` is set and not on Android/iOS/game-console targets (see `CMakeLists.txt`). Dependency direction is inward-only: this module depends on `HsBaSlicerBase` (IModel, error types, format helpers) and `HsBaSlicerMesh` (IglModel), with conditional links to `HsBaSlicerPointCloud` and `HsBaSlicerCADModel`; it does not depend on higher-level slicer layers.
