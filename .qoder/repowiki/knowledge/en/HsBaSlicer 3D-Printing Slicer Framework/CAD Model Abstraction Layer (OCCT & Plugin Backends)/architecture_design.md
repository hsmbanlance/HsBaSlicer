Two sibling implementations of `HsBa::Slicer::IModel` coexist in this static library:
- `OcctModel` wraps an OCCT `TopoDS_Shape`, providing STEP/IGES/VRML/BRep load/save, affine transforms, bounding-box/volume/tessellation queries, boolean operations (`Union`/`Intersection`/`Difference`/`Xor` as friend free functions), thick-solid/shell creation, and primitive factories (`CreateBox`, `CreateSphere`, `CreateCylinder`, `CreateCone`, `CreateTorus`, `CreatePrime`).
- `UserCustomCADModel` is a thin adapter over a dynamically loaded DLL/SO; it delegates all `IModel` calls through function pointers resolved from a user library conforming to the `IUserCustomCAD` ABI (create/destroy model, boolean ops, primitives, thickness setter, extrude). The actual symbol loading/unloading is hidden behind the PIMPL class `UserCustomCADDll`.

Dependency direction: this module depends on `base/IModel.hpp` (the abstract contract), `2D/FloatPolygons.hpp` (polygon types), `HsBaSlicerMesh` (mesh utilities), and OpenCASCADE headers; it does not depend on any UI or slicer frontend. Build-time selection: the whole `UserCustomCAD*` translation unit is excluded when `HSBA_NO_DLL_LOADER` is defined, and `Boost::dll` is linked only on desktop targets per `CMakeLists.txt`.
