- Each `IModel` implementation exposes the same transform surface — separate overloads for `Eigen::Vector3f`, `Eigen::Quaternionf`, scalar `float`, `Eigen::Isometry3f`, `Eigen::Matrix4f`, and `Eigen::Transform<float,3,Eigen::Affine>` — so callers can pass whichever type they have without conversion.
- Boolean operations are exposed as free friend functions (`Union`, `Intersection`, `Difference`, `Xor`) taking two models by const reference rather than mutating members, keeping the core shape immutable at the call site.
- Primitive constructors are provided as `static` factory methods (`CreateBox`, `CreateSphere`, `CreateCylinder`, `CreateCone`, `CreateTorus`, `CreatePrime`) instead of constructors, separating construction from the default empty-model constructor.
- Plugin ABI boundaries are expressed as typedef'd function-pointer aliases (`CreateModelFunc`, `DestroyModelFunc`, `BooleanOperationFunc`, etc.) inside `IUserCustomCAD`, with each getter returning one such pointer.
