Two parallel content trees under `docs/en` and `docs/zh` mirror each other, covering Foundation Layer (base/utils/logger), File & Data (cipher/fileoperator), Geometry Models, and Slicing Core (LibHsBaSlicer, DllHsBaSlicer) with per-module subfolders. The top-level `Doxyfile` plus `CMakeLists.txt` drive a `make docs` target that invokes Doxygen to regenerate the static site under `docs/doxygen/html` (and LaTeX output). The `html/search/` directory holds ~558 search index files produced by Doxygen's full-text search; the rest of `doxygen/html` is one page per source file (`*_source.html`, `*_incl.png`, `*_cgraph.*`). There is no runtime code — this module is purely documentation assets consumed by consumers of the HsBaSlicer libraries.
