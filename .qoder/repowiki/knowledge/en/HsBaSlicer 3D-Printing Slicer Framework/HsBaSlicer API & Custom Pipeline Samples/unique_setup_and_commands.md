Each sample builds independently via CMake; the `LibHsBaSlicer` sample additionally requires the `HSBA_SLICER_MODULE` CMake option to enable the C++20 module variant (`lib_sample_module`). On non-Android/non-iOS hosts the post-build step copies `samples/FDM/models/stanford_bunny.stl` and `samples/Custom/scripts/` next to the produced executable so relative paths resolve at runtime.
