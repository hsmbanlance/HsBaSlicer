Three sibling classes live in this leaf module, all under namespace `HsBa::Slicer`:
- `IglModel` implements the abstract `base/IModel.hpp` interface backed by Eigen matrices (`vertices_`, `faces_`, `normals_`) and libigl IO/geometry; it exposes affine transforms, bounding-box/volume queries, STL/OBJ/PLY/OFF load/save, primitive factories (`CreateBox`/`Sphere`/`Cylinder`/`Cone`/`Torus`), extrusion from `PolygonD`/`PolygonsD`, and free functions `Union`/`Intersection`/`Difference`/`Xor` declared as friends.
- `CgalModel` is an alternative `IModel` implementation wrapping a `CGAL::Polyhedron_3<EpicKernel>` plus `Nef_polyhedron_3` for exact boolean operations; it adds surface geodesic/helix/spiral APIs. It is compiled only when the CMake flag `HSBA_COPL` is set (CGAL is copyleft).
- `FullTopoModel` does not implement `IModel`; instead it consumes one via its constructor and rebuilds full vertex/edge/face adjacency (`Vertex`, `Edge`, `Face` structs) to support robust Z-slicing (`Slice`, `UnSafeSlice`, `SliceFast`), Euler characteristic checks, and Lua-scriptable slicing through embedded Lua (`lua.hpp`).

Dependency direction is one-way outward: this module depends on `base/IModel.hpp`, `2D/FloatPolygons.hpp`, `HsBaSlicerBase`, `HsBaSlicerProto`, `HsBaSlicer2D`, and optionally CGAL/libigl-copyleft; nothing inside the module depends on the others except `FullTopoModel` taking an `IModel&` reference. The CMakeLists.txt builds a single static library `HsBaSlicerMesh` whose source list toggles `CgalModel.*` on/off based on `HSBA_COPL`.
