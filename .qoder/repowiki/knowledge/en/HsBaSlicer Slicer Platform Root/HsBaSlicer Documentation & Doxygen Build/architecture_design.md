Two parallel content trees under `docs/en` and `docs/zh` mirror each other, with per-module subdirectories (`base`, `cipher`, `fileoperator`, `logger`, `utils`, `DllHsBaSlicer`, `LibHsBaSlicer`) each containing one Markdown page per component. A top-level `README.md` indexes both language versions and the module overview. The `doxygen/` directory is the generated output root (empty in source). `Doxyfile` configures Doxygen 1.17.0 to scan the C++ sources and emit HTML/latex/RTF under `doxygen/`. `CMakeLists.txt` finds Doxygen via `find_package(Doxygen COMPONENTS dot)` and exposes an optional `docs` custom target that runs `doxygen Doxyfile`; if Doxygen is absent the target is silently skipped with a warning. There is no runtime code — this module is purely documentation assets plus the build glue.
