This module is the thin C export layer sitting on top of `LibHsBaSlicer` (see `CMakeLists.txt`). It defines three stable C ABI entry points:
- `initialize()` in `initialize.{h,cpp}` — single-call DLL bootstrap that registers Lua functions, pipelines, and performs one-time runtime setup; idempotent across repeated calls.
- Event-source callbacks in `event_source_register.{h,cpp}` — `HsBaAddZipperEventCallback` / `HsBaAddDBEventCallback` let host languages plug in zipper and database event handlers via function pointers.
- Version introspection in `version_info.{h,cpp}` — `HsBaGetVersionJson`, `HsBaGetVersionXml`, and paired `HsBaFreeVersionString` return UTF-8 strings allocated by the DLL.
All public symbols are annotated with the `HSBA_SLICER_API` macro from `dllexport.h`, which resolves to `__declspec(dllexport)` on Windows when `HSBA_SLICER_EXPORTS` is defined and to nothing on other platforms. The build target switches between SHARED and STATIC (`add_library`) depending on iOS vs. non-iOS, because iOS apps cannot load arbitrary dylibs. Dependency direction is strictly outward: this layer calls into `LibHsBaSlicer` and its transitive dependencies but exposes only C-compatible `extern "C"` symbols.
