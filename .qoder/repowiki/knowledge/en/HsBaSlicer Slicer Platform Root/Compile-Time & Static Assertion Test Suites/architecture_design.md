Two sibling CMake subprojects under a thin `CMakeLists.txt` aggregator: `base_static_tests/` exercises `base/template_helper.hpp`, `base/any_visit.hpp`, `base/tuple_each.hpp`, `base/coroutine.hpp`, and `base/any_object.hpp` (including the `TypeInfo` registration pattern for `AnyObject`); `utils_static_tests/` exercises `utils/struct_json.hpp`, `utils/struct_xml.hpp`, `utils/struct_yaml.hpp`, `utils/LuaNewObject.hpp`, and `utils/LuaAnyObject.hpp`. Each subproject has its own `CMakeLists.txt` producing a standalone executable whose only purpose is to fail compilation when a facility breaks — there are no runtime assertions or test frameworks. Tests depend outward on `base/` and `utils/` headers but have no reverse dependency from production code.
