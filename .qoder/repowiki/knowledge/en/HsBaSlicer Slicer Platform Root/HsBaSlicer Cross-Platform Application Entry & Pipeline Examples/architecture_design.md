Single-file entry module (`HsBaSlicer.cpp`) that compiles into three different artifacts via `CMakeLists.txt`: an executable on Windows/Linux/macOS, a SHARED library for Android (output to `android_libs/<ABI>`), and a STATIC library for iOS. The source is platform-gated with `#if defined(ANDROID)`, `#elif defined(__APPLE__)` (with `TARGET_OS_IPHONE` branch), and a fallback `main()` for desktop. It depends only on the C API surface of `DllHsBaSlicer` (`fdm_pipeline.h`, `sla_pipeline.h`, `sls_pipeline.h`, `initialize.h`) and the `logger/logger.hpp` singleton; it does not link against any higher-level UI or engine code directly. Each of the three pipelines (FDM, SLA, SLS) is demonstrated by a `Run*Example()` function following the same config → run → free-result pattern, all orchestrated by `RunAllPipelineExamples()`. The header `HsBaSlicer.h` is intentionally minimal — just an umbrella include.
