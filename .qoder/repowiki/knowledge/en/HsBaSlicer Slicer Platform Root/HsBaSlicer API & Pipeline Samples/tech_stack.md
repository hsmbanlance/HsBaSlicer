C++17/20 samples targeting Windows/Linux/macOS/Android/iOS; the module sample requires a C++20 module-capable compiler (MSVC 19.34+, GCC 14+, Clang 16+) and the `HSBA_SLICER_MODULE=ON` CMake option; the Custom sample deliberately avoids linking `HsBaSlicerProto` and implements a minimal varint/fixed64/delimited Protobuf wire encoder/decoder by hand to demonstrate cross-language serialization.
