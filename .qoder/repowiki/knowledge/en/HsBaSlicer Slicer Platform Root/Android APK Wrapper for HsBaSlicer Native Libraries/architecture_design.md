Single-activity Android app under `android/app/` using Gradle (`com.android.application` plugin, compileSdk 34, minSdk 21) with no Java/Kotlin dependencies. The only source file is `MainActivity.java`, which statically loads the native library via `System.loadLibrary("HsBaSlicer")` in a `static {}` block and declares one native method `runPipelineExamples()` whose C/C++ counterpart follows the standard JNI naming convention (`Java_com_hsmbanlance_hsbaslicer_example_MainActivity_runPipelineExamples`). Prebuilt `.so` artifacts (`libHsBaSlicer.so`, `libDllHsBaSlicer.so`) are shipped as binary assets under `app/src/main/jniLibs/arm64-v8a/` and consumed through the `jniLibs.srcDirs` Gradle source set; ABI is restricted to `arm64-v8a`. Dependency direction is strictly one-way: this module depends on the native CMake-produced libraries but has no reverse dependency — it exists purely as an APK packaging shell around the core engine.
