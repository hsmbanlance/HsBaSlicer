Single-class facade `HsBa::Slicer::ModelLoader` (ModelLoader.hpp/.cpp) built as the `HsBaPreprocess` static library. It owns a `NamedObjectPool<IModel, HSBA_MODEL_POOL_SIZE>` (`base/object_pool.hpp`) keyed by user-assigned names; `LoadModel` inspects the extension via `base/ModelFormat.hpp` helpers (`IsPointCloudFormat`, `IsMeshFormat`, `IsBrepFormat`) and instantiates `IglModel`, `OcctModel`, or `OpenVdbModel` accordingly. Optional kernel APIs are gated by compile-time macros: CGAL-boolean/thick-solid ops under `#ifdef USE_CGAL`, OpenVDB point-cloud ops under `#ifdef USE_OPENVDB`, and OCCT CAD support is additionally excluded on Android/iOS/game-console per CMakeLists.txt. The public API returns `std::shared_ptr<IModel>` so callers stay decoupled from concrete kernels; internal helpers (`ToIglModel`, `AsOpenVdbModel`) perform `dynamic_cast` to route between backends. Dependency direction is one-way outward: this module depends on `HsBaSlicerBase`, `HsBaSlicerMesh`, optionally `HsBaSlicerPointCloud` and `HsBaSlicerCADModel`, but exposes no further sub-interfaces.
