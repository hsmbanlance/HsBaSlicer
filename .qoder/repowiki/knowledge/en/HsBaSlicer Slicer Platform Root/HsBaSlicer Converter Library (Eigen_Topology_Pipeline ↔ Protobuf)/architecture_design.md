Built as the `HsBaSlicerConverter` static library (`CMakeLists.txt`) with a flat file-per-converter layout. Each conversion direction is split into a paired `.hpp`/`.cpp` pair: geometry primitives (`Eigen2Msg.*`, `Msg2Eigen.*`), mesh topology (`FullTopoModel2Msg.*`, `Msg2FullTopoModel.*`), and per-pipeline C-struct serialization (`PipelineConfig2Msg.*`, `Msg2PipelineConfig.*`). All public APIs live in namespace `HsBa::Slicer` and take native objects by const reference while writing into pre-allocated protobuf message pointers — there are no constructors or RAII wrappers around the converters themselves. Dependencies flow one-way outward: this module depends on `Eigen3::Eigen`, `HsBaSlicerProto` (generated `*.pb.h` headers such as `path.pb.h`, `mesh.pb.h`, `custom_pipeline.pb.h`, etc.), `HsBaSlicerMesh` (`meshmodel/FullTopoModel.hpp`), and `HsBaPipelineTypes` (`pipelinetypes/pipeline_types.h`); it exposes only pure conversion functions so consumers can call them from any layer without pulling in protobuf internals.
