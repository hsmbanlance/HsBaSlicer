Single C++ module (`logger.hpp` + `logger.cpp`) exposing the `HsBa::Slicer::Log` namespace. `LoggerSingletone` is a shared-ptr singleton built on `std::shared_mutex` + `std::once_flag`, with construction gated by a private `Private` tag so only `CreateInstance` can construct it. Platform-specific sinks are selected at compile time via `__ANDROID__` / `TARGET_OS_IOS` / `_WIN32` guards: desktop uses Boost.Log (console + optional rotating file), Android uses `__android_log_print`, iOS uses `os_log`. Configuration is read from `<cwd>/logcfg.ini` via `fileoperator/rw_ptree.hpp` (ptree-based INI parser). The public API also includes an inline `LogLiterals` namespace with user-defined literals (`"msg"_log_debug/_info/_warning/_error`) that return a `LogState` object whose destructor invokes the logger, enabling fluent syntax like `"hello"_log_info()`. Symbol visibility is controlled by `export.h`'s `HSBA_SLICER_LOG_API` macro, toggled by `HSBA_SLICER_LOG_EXPORTS` on Windows. Build is driven by `CMakeLists.txt`, which switches between static/shared library targets and links platform libraries (`Boost::log_setup`, `log` on Android, none on iOS).
