Four sibling sub-trees with distinct roles:
- `cmake/`: CMake helper modules consumed by the top-level build. `HsBaSlicerConfig.cmake.in` is the installed-package finder that declares public dependencies (Eigen3, magic_enum, Clipper2, Lua, Protobuf, OpenSSL) and includes `HsBaSlicerTargets.cmake`. `coverage.cmake` instruments all targets with `--coverage`, defines core-vs-other filter buckets (`base`, `2D`, `utils`, …), and exposes a `coverage` custom target that runs gcovr twice with `--fail-under-line` thresholds to gate CI. `deploy_dlls.cmake` is a standalone script invoked via `cmake -P` to copy PDB symbols next to an executable.
- `version/`: A small CMake subproject that invokes `Generator_Version.ps1` at configure time to emit `version.cpp` from `vcpkg.json` (platform triplet, copyleft feature, dependency license map). The generated source is compiled into the `HsBaVersion` static library, which links publicly against `HsBaSlicerBase` and exposes `version.hpp`.
- `static_check/`: Three independent tools. `feature_check.cmake` provides `check_cxx_feature_*` / `check_c_feature_*` functions wrapping `CheckCXXSourceCompiles` for C++20/23 features (concepts, ranges, coroutines, explicit this, NTP class/fp, template-template matching, C++ modules support detection). `cpp_analyzer.py` is a self-contained Python linter (catch-all exceptions, `using namespace`, unsafe functions, magic numbers, memory leaks, cyclomatic complexity) driven by argparse. `clang-format-batch.py` recursively formats C/C++ files in parallel via `ThreadPoolExecutor`, parsing `.gitignore` manually and skipping generated files like `version.cpp`.
- `scripts/repowiki_to_github_wiki.py`: Standalone converter that reads `.qoder/repowiki/{en,zh}/content/*.md`, flattens directory names to wiki page names, strips repowiki-specific `<cite>`/section-source blocks, and emits GitHub Wiki pages plus `Home.md` / `_Sidebar.md` / `_Footer.md`.

Dependency direction: nothing here depends on project source code; everything is either consumed by the top-level CMake configuration or invoked as a standalone CLI.
