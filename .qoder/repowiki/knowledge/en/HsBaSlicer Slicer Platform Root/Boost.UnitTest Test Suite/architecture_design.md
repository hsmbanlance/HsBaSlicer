Flat directory layout mirroring the production source tree: each subdirectory under tests/ corresponds to a feature (AnyObject, AnyVisit, ConfigMap, PolygonFill, PathsOut, Models, Support, etc.) and contains one or more `*_test.cpp` files plus optional fixtures (mock DLLs in CADModel/, PointCloud/, DllLoader/; Lua scripts in PolygonFill/). All targets are declared centrally in `tests/CMakeLists.txt`, which links each executable against the relevant HsBaSlicer libraries (`HsBaSlicerBase`, `HsBaSlicer2D`, `HsBaPaths`, `HsBaCipher`, `LibHsBaSlicer`, …) and `Boost::unit_test_framework`. Conditional compilation gates (`HSBA_COPL`, `HSBA_POLYGON_DUMP`, `TARGET HsBaSlicerCADModel`) control whether OCCT/CGAL/Lua-polygon tests are built. A shared `ALL_TEST_TARGETS` list feeds a `RunAllTests` custom target that runs `ctest -V`. Tests use Boost.Test's included mode (`#define BOOST_TEST_MODULE ...` + `<boost/test/included/unit_test.hpp>`), so each file is an independent executable rather than a shared test library.
