Build and run via CTest: `cmake --build <build-dir> --target RunAllTests` (or `ctest -V`). Individual suites can be re-run post-build through the generated `POST_BUILD` commands when `HSBA_SLICER_RUN_TESTS_AFTER_BUILD=ON`. The `graph_test` target adds `/bigobj` on MSVC due to Boost.Graph template instantiation exceeding the 65535 section limit. CGAL tests only build when `HSBA_COPL` is enabled; OCCT tests only when `HsBaSlicerCADModel` is present.
