Build via `cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake` then `cmake --build build --config Release`; presets are available through `CMakePresets.json` (e.g. `--preset linux-release`). Enable optional features via `VCPKG_MANIFEST_FEATURES`: set `rest-api` for the REST server, `copyleft` to link CGAL/OpenCascade (switches license to GPL-3.0-or-later). Coverage builds use `-DHSBA_COVERAGE=ON` and enforce Core ≥ 45% / Other ≥ 25% line coverage. Android/iOS builds require NDK and set `ANDROID_NDK_HOME`.
