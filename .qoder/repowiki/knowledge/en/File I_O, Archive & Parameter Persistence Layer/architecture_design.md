The module is organized into four internal layers around two orthogonal concerns:

- Archive layer: `IZipper.hpp` defines a pure-virtual `IZipper` interface; `zipper.cpp`/`bit7z_zipper.cpp` provide miniz-based and optional bit7z-based implementations. Extraction uses a CRTP design in `IUnzipper.hpp` (`template <typename Derived> class IUnzipper`) so both `Unzipper` (miniz) and `Bit7zUnzipper` share `ReadFromFile`/`GetStream` via `ReadFromFileImpl`/`GetStreamImpl`, returning an `UnzipperStream` that abstracts over in-memory buffers or temp files.
- SQL layer: `sql_adapter.hpp` declares `ISQLAdapter` plus `SQLiteAdapter` (always built), `MySQLAdapter` and `PostgreSQLAdapter` (gated by `HSBA_USE_MYSQL` / `HSBA_USE_PGSQL`). Each concrete adapter uses PIMPL (`class Impl; std::unique_ptr<Impl> impl_`) and a `shared_mutex` for thread safety, and exposes a fluent pipe operator API (`db | SQLSelect{...}` etc.).
- Parameter persistence pipeline: `param_reflect` + `param_convert` + `param_schema` + `param_codec` + `param_store` form a staged Save flow (Validate → Reflect → Coerce → Upsert). `ParamStore` owns one `ISQLAdapter&`, auto-detects backend via `ParamSchema::DetectBackend`, generates wide tables per `PipelineConfig` tag, and optionally encrypts the reflected column map with AES-256-CBC before storing it in a `param_blob` column.
- Integration surface: `LuaAdapter.{hpp,cpp}` registers zipper/unzipper classes, all three SQL adapters, and `ParamStore` as Lua userdata; `RemoteExecutor.{hpp,cpp}` provides a connection pool to a remote executor service for bulk file transfer.

Dependency direction is inward-only: LuaAdapter depends on every other sub-component; ParamStore depends on sql_adapter/reflect/convert/schema/codec; archive backends depend only on interfaces and `base/delegate.hpp`. The CMake target `HsBaSlicerFileOperator` is a static library linking `HsBaSlicerBase`, `rapidjson`, `HsBaCipher`, `HsBaPipelineTypes`, `miniz::miniz`, `HsBaSlicerUtils`, Lua, and conditionally `bit7z`, Boost.Log, and sqlpp11 backends.
