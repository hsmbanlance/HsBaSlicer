- Concrete archive backends expose a public virtual interface (`IZipper`) or a CRTP base (`IUnzipper<Derived>`) while keeping constructors private behind a nested `struct Private` friend tag, forcing creation through a `static Create()` factory returning `std::shared_ptr`.
- Database adapter implementations hide platform-specific state via PIMPL (`class Impl; std::unique_ptr<Impl> impl_`) and protect concurrent access with a `std::shared_mutex` member.
- Optional third-party backends are gated by preprocessor macros (`#ifdef HSBA_USE_MYSQL`, `#ifdef HSBA_USE_PGSQL`, `#ifdef HSBA_USE_BIT7Z`) on both the class declarations and their corresponding Lua registration functions.
- Parameter persistence operations go through a staged pipeline (Validate → Reflect → Coerce → Upsert) orchestrated by `ParamStore`, with progress reported via a `ProgressFn` callback and errors recorded in `last_error_` before being rethrown.
- Fluent query composition is exposed through free `operator|` overloads taking `ISQLAdapter&` and typed structs (`SQLSelect`, `SQLInsert`, `SQLUpdate`, `SQLDelete`, `SQLCreateTable`, `SQLRemoveTable`), with rvalue-reference overloads explicitly deleted to prevent misuse.
