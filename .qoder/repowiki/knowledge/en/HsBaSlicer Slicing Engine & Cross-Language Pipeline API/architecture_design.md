Three-layer build with clear dependency direction: `base` (thread pool, coroutines, concepts) → `LibHsBaSlicer` (pure C++ stage implementations: Slice/Preprocess/Support/Fill/Path/ParamStore/Transfer/Extends) → `DllHsBaSlicer` (C ABI wrappers for each process type). The root `CMakeLists.txt` is the single configuration point that detects compiler features (concepts, ranges, source_location, NTTP, coroutines), toggles copyleft kernels (CGAL/OpenCASCADE via `HSBA_COPL`), and wires vcpkg dependencies (Boost, Clipper2, miniz, bit7z, protobuf, RapidJSON, Eigen3, OpenSSL, OpenCV, libigl, OpenVDB, sqlpp11, Lua, tinyxml2, yaml-cpp, magic_enum). `ModuleHsBaSlicer` provides an optional C++20 module wrapper (`hsba_slicer.cppm`) when the toolchain supports modules. `DllHsBaSlicer` builds as SHARED on desktop and STATIC on iOS; it only calls exported symbols from `LibHsBaSlicer`, keeping the C ABI boundary clean. Each pipeline (`fdm_pipeline.*`, `sla_pipeline.*`, `sls_pipeline.*`, `slm_pipeline.*`, `lom_pipeline.*`, `waam_pipeline.*`, `tdp_pipeline.*`) follows the same shape: C struct config/result + `BuildConfig`/`ToCResult` helpers + a coroutine `RunPipelineAsync` that chains Preprocess → Slice → Support → Fill → Path Generation, plus sync/async entry points and `HsBaFreePipelineResult`. Parallelism is centralized in `base/parallel.hpp`: a process-wide `PipelinePool()` singleton built once with `ResolvePipelineThreads()` (reads `HSBA_PIPELINE_THREADS`, falls back to `hardware_concurrency()`) and `ParallelForLayers` / `ParallelMapLayers` using an atomic cursor for dynamic load balancing across workers; `pipeline_parallel.hpp` is a compatibility shim so existing Dll sources keep their include. Coroutine integration goes through `Utils::Task<T>` and `ThreadPoolExecutor` (in `base/thread_pool.hpp`), which dispatches onto the same pool. Lua extension points live under `LibHsBaSlicer/Extends` (`LuaAddFunction`, `EventSourceFunction`, `LuaCommonTypes`, `lua_pipeline`) and are registered per-stage via `InstallCommonAnyObjectTypes()` before any user script runs. Samples under `samples/{FDM,SLA,SLS,SLM,LOM,TDP,WAAM,Custom,LibHsBaSlicer}` exercise every pipeline independently.
