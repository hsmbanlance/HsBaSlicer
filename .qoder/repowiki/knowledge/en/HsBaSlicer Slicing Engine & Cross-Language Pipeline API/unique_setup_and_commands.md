Configure with CMake 3.28+ and a vcpkg triplet (e.g. `x64-windows`, `x64-linux`, `arm64-ios`). Set `HSBA_COPL=AUTO|ON|OFF` to enable/disable CGAL/OpenCASCADE (switches project license to GPL-3.0-or-later when ON). Control parallelism at runtime via the `HSBA_PIPELINE_THREADS` environment variable; set it to `1` to force serial execution for regression comparison against the original ordering. Coverage builds use the top-level `coverage` target enabled by `-DHSBA_COVERAGE=ON`.
