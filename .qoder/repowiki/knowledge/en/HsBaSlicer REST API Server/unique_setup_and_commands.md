Executable `HsBaSlicerRestServer` takes `--config <ini>` (default `restapi.ini`), `--host`, `--port`, `--auth-token`, `--tls-cert`, `--tls-key`, `--require-tls`, `--help`. Credentials can be injected at runtime via env vars `HSBA_REST_AUTH_TOKEN`, `HSBA_REST_TLS_CERT`, `HSBA_REST_TLS_KEY` when the ini leaves them empty. HTTPS requires cpp-httplib built with its openssl port feature.
