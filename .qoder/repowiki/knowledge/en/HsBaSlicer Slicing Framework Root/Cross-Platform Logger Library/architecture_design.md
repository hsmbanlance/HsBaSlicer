Single C++ module under `logger/` exposing the `HsBa::Slicer::Log` namespace. The public API lives in `logger.hpp` (`LoggerSingletone` class plus a `LogLiterals` inline namespace with `_log_debug/_log_info/_log_warning/_log_error` user-defined literals returning a `LogState` RAII object). `logger.cpp` implements platform-specific dispatch: non-mobile builds use Boost.Log (console + optional rotating file sink configured from `logcfg.ini` via `fileoperator/rw_ptree.hpp`), Android uses `__android_log_print`, iOS uses `os_log`. Thread safety is achieved through a static `std::shared_mutex` plus `std::once_flag` guarding lazy singleton construction via `GetInstance()` / `CreateInstance()`. Configuration defaults to level 1 (debug) in `_DEBUG` and level 3 (warning) otherwise; file logging is disabled by default unless `log.use_log_file` is set in the INI. `export.h` provides the `HSBA_SLICER_LOG_API` visibility macro for Windows DLL import/export, and `CMakeLists.txt` builds either a static or shared library (`HsBaSlicerLog`) linking `HsBaSlicerBase`, `HsBaSlicerFileOperator`, and platform libraries (`Boost::log`, Android `log`, or none for iOS).
