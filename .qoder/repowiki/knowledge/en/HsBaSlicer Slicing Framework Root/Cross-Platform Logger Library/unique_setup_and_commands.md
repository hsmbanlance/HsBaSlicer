Build produces `HsBaSlicerLog` as either STATIC or SHARED depending on `BUILD_SHARED_LIBS`; when shared, the `HSBA_SLICER_LOG_EXPORTS` compile definition must be present so `export.h` emits `__declspec(dllexport)` instead of `dllimport`. Runtime configuration is read from `<cwd>/logcfg.ini` with keys `log.log_level_debug`, `log.log_level`, `log.use_log_file`, `log.log_file`, and `log_format.log_datatime_format`.
