The module is a thin CMake + PowerShell code generator that produces `version.cpp` at configure time. `CMakeLists.txt` locates `pwsh`/`powershell`, invokes `Generator_Version.ps1` with `-OutputPath`, `-BuildType`, `-VcpkgTriplet`, `-VcpkgJsonPath`, and `-Copyleft`, then compiles the generated file into the static library target `HsBaVersion`. The public API lives in `version.hpp` under namespace `HsBa::Slicer::Version`, defining `ThirdLibraries` (name/license/homepage) and `VersionInfo` (product name, license, version, build type/platform/timestamp, vcpkg triplet, plus an `InplaceVector<ThirdLibraries, 100>`). The generator parses `vcpkg.json`, maps the triplet to a platform (`Windows`/`Linux`/`macOS`/`Android`/`iOS`/`GameConsole`), filters dependencies by platform constraints, looks up each dependency in an internal `libInfoMap` of known licenses and homepages, and emits C++ source that populates `GetVersionInfo()`. If any dependency carries a GPL/LGPL license (excluding dual-licensed variants), the emitted project license switches from MIT to GPL-3.0-or-later. The only runtime dependency inside this module is `Utils::InplaceVector` from `base/InplaceVector.hpp`; the generated `version.cpp` includes only `version.hpp`.
