Build via CMake presets defined in `CMakePresets.json` (e.g. `cmake . --preset linux-release` → `out/build/linux-release`). Cross-compilation uses `VCPKG_TARGET_TRIPLET` to auto-select Windows dynamic vs Linux/Android static linkage. Coverage build toggled with `-DHSBA_COVERAGE=ON`. Install with `cmake --install <build_dir> --prefix <prefix> --config Release` and consume via `find_package(HsBaSlicer CONFIG REQUIRED)` linking `HsBaSlicer::DllHsBaSlicer` or any `HsBaSlicer::*` target.
