Two independent concerns sit side by side under this module:
- `cmake/` provides CMake scripts consumed by the top-level build. `HsBaSlicerConfig.cmake.in` is the package-config template (via `@PACKAGE_INIT@`) that declares public dependencies (`Eigen3`, `magic_enum`, `Clipper2`, `Lua`, `Protobuf`, `OpenSSL`) through `find_dependency` and includes the generated `HsBaSlicerTargets.cmake`. `coverage.cmake` injects `--coverage` compile/link options and defines a `coverage` custom target that runs gcovr in two gated passes — core vs. other — against configurable thresholds (`HSBA_COVERAGE_THRESHOLD_CORE`, `HSBA_COVERAGE_THRESHOLD_OTHER`) with parallel worker control via `HSBA_COVERAGE_JOBS`. `deploy_dlls.cmake` is a standalone `-P` script invoked with `TARGET_BIN` and `PDB_FILES` to copy debug symbols next to executables. `HsBaWindowsUtf8.cmake` and `hsba_utf8.manifest` provide Windows UTF-8 support.
- `scripts/repowiki_to_github_wiki.py` is a self-contained Python 3 tool that reads `.qoder/repowiki/{en,zh}/content/*.md`, flattens nested directories into hyphenated wiki page names, strips repowiki-specific `<cite>` / section-source blocks, and emits `Home.md`, `_Sidebar.md`, `_Footer.md` (plus language variants `Home-zh` / `_Sidebar-zh`) ready for push to the GitHub Wiki repo.
Dependency direction is one-way: these files are consumed by the project root's CMakeLists.txt and CI; nothing in this module depends on the rest of HsBaSlicer source.
