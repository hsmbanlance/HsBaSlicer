On MSVC the file `OpenVdbModel_mesh.cpp` is compiled with `/bigobj` because the OpenVDB level-set reconstruction templates exceed the 65535 section limit. OpenVDB linkage additionally requires explicit linking of blosc (target name varies between `blosc_shared`/`blosc_static`/`blosc`) and ZLIB due to vcpkg's FindOpenVDB not propagating IMPORTED_LINK_DEPENDENT_LIBRARIES for static archives.
