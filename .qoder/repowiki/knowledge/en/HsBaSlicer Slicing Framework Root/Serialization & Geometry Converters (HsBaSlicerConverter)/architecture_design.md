Built as the `HsBaSlicerConverter` static library (`CMakeLists.txt`). The module is organized into three converter pairs around a single boundary: protobuf ↔ Eigen geometry (`Eigen2Msg.*`, `Msg2Eigen.*`) covering vectors, points, quaternions, affine/isometry transforms, matrices, and point paths; protobuf ↔ mesh topology (`FullTopoModel2Msg.*`, `Msg2FullTopoModel.*`) bridging `meshmodel/FullTopoModel` with `msg_topo_trimeshes`; and protobuf ↔ C pipeline config/result structs (`PipelineConfig2Msg.*`, `Msg2PipelineConfig.*`) for every supported process (FDM, SLA, SLS, SLM, LOM, 3DP/TDP, WAAM, custom Lua, file transfer). Dependency direction is one-way outward: this module depends on `HsBaSlicerProto` (generated `.pb.h` headers), `Eigen3::Eigen`, `HsBaSlicerMesh`, and `HsBaPipelineTypes`, but no other HsBaSlicer subsystems depend back on it. Each conversion pair is split across a `.hpp` declaration and a `.cpp` implementation under the `HsBa::Slicer` namespace.
