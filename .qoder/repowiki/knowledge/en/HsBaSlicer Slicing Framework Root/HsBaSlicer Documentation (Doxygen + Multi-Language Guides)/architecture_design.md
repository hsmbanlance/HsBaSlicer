The docs tree is organized as a parallel bilingual mirror: `en/` and `zh/` each contain identical subdirectories (`base`, `cipher`, `fileoperator`, `logger`, `utils`, `DllHsBaSlicer`, `LibHsBaSlicer`) mirroring the C++ source layout, plus top-level guides (`README.md`, `cpp_cmake_usage.md`, `lua_pipeline_api.md`, `vcpkg-dependencies.md`, `wiki_maintenance_guide.md`). `doxygen/` is the output directory for generated API docs. `CMakeLists.txt` wires Doxygen via `find_package(Doxygen COMPONENTS dot)` and exposes an `add_custom_target(docs ...)` that runs `${DOXYGEN_EXECUTABLE} ${CMAKE_CURRENT_SOURCE_DIR}/Doxyfile`; if Doxygen is absent the target is silently skipped with a warning. Dependency direction is one-way: this module consumes the source tree only through Doxygen's header scanning — it contains no buildable code.
