Single-class facade `HsBa::Slicer::ModelLoader` (ModelLoader.hpp/.cpp) built as the `HsBaPreprocess` static library. It owns a `NamedObjectPool<IModel, HSBA_MODEL_POOL_SIZE>` (`base/object_pool.hpp`) keyed by user-supplied names; `LoadModel` inspects the file extension via `base/ModelFormat.hpp` (`IsPointCloudFormat` / `IsMeshFormat` / `IsBrepFormat`) and instantiates `OpenVdbModel`, `IglModel`, or `OcctModel` accordingly. Optional feature sets are gated by CMake-defined macros: `USE_CGAL` exposes ThickSolid and BooleanUnion/Intersection/Difference/Xor (with an OCCT fast path falling back to CGAL-backed `IglModel` via helpers `ToIglModel`/`ToOcctModel`), while `USE_OPENVDB` adds point-cloud ops (PointCloudToMesh, MergePointClouds, DownsamplePointCloud, RemovePointCloudOutliers, PointCloudCentroid/Normals/Count). The module depends downward on `base/*`, `meshmodel/IglModel`, optionally `cadmodel/OcctModel` and `pointcloud/OpenVdbModel`; it has no upward dependency on slicer engines, keeping it a pure input/preprocessing layer.
