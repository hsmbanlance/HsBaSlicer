Each sample builds its own executable/library via CMake; on desktop platforms the `POST_BUILD` step copies `models/stanford_bunny.stl` and the local `scripts/` tree next to the binary so relative paths resolve at runtime. The LibHsBaSlicer module sample requires a C++20-capable compiler (MSVC 19.34+, GCC 14+, Clang 16+) and `HSBA_SLICER_MODULE=ON`. On Android/iOS targets the same sources are compiled as static libraries instead of console executables.
