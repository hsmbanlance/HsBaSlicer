Two sibling IModel implementations share one abstraction:
- `OcctModel` (`OcctModel.{hpp,cpp}`) wraps an OCCT `TopoDS_Shape`, implementing `IModel` with STEP/IGES/VRML/BRep load/save dispatchers (`ReadStep`/`ReadIGES`/`ReadVRML`/`ReadBRep`), affine/isometry/homogeneous transforms via OCCT geometry, AABB/volume/tessellation queries, and free-function boolean operators (`Union`/`Intersection`/`Difference`/`Xor`) plus `ThickSolid`. Primitive factories (`CreateBox`/`CreateSphere`/`CreateCylinder`/`CreateCone`/`CreateTorus`/`CreatePrime`) build shapes from libigl-style polygons.
- `UserCustomCADModel` (`UserCustomCADModel.{hpp,cpp}`) is an `IModel` adapter that delegates to a user-provided shared library loaded at runtime through `UserCustomCADDll`, which resolves function pointers exposed by an `IUserCustomCAD` ABI (`CreateModelFunc`, `DestroyModelFunc`, `BooleanOperationFunc`, primitive creators, thickness setter, extrude functions). The whole block is gated by `HSBA_NO_DLL_LOADER` so it can be compiled out on embedded/console targets.
- `OcctTypeAliases.hpp` centralises type aliases used across both implementations. Dependency direction: this module depends on `base/IModel.hpp`, `HsBaSlicerMesh` (for polygon types), and OpenCASCADE; nothing in the rest of the slicer depends on OCCT internals — only on the `IModel` interface.
- Build manifest `CMakeLists.txt` compiles the two sources into the static library `HsBaSlicerCADModel`, links `OpenCASCADE` and `Boost::dll` (desktop-only), and exposes `HsBaSlicerBase` + `HsBaSlicerMesh` as public dependencies.
