The module exposes three classes under `HsBa::Slicer` that implement the common `base/IModel.hpp` interface:
- `IglModel` — lightweight Eigen/libigl-backed mesh storing vertices/faces/normals; supports load/save, affine transforms, bounding box, volume, normals, boolean ops (Union/Intersection/Difference/Xor as free friends), and primitive/extrusion factories (`CreateBox`, `CreateSphere`, `CreateCylinder`, `CreateCone`, `CreateTorus`, `CreatePrime`).
- `CgalModel` — CGAL `Polyhedron_3` wrapper with exact-predicates kernel; adds Nef-based boolean operations and surface geodesic/curve/helix utilities (`GeodesicPath`, `GeodesicDistance`, `ProjectPointOnSurface`, `SurfaceSpiral`, `SurfaceHelix`).
- `FullTopoModel` — read-only topology rebuild over an `IModel`; constructs explicit `Vertex`/`Edge`/`Face` adjacency lists from triangles, offers `CheckTopo`, `EulerCharacteristic`, and multiple Z-slice APIs (`Slice`, `UnSafeSlice`, `SliceFast`, plus Lua-driven `SliceLua` variants).

Dependency direction is one-way: `IglModel` and `CgalModel` depend on `IModel`; `FullTopoModel` consumes any `IModel` but does not expose it. The build manifest `CMakeLists.txt` compiles `IglModel`+`FullTopoModel` into the static library `HsBaSlicerMesh` unconditionally, while `CgalModel` is gated behind the `HSBA_COPL` CMake flag (CGAL is copyleft). External deps are `igl::igl_core`, `HsBaSlicerBase`, `HsBaSlicerProto`, `HsBaSlicer2D`, and Lua (`lua.hpp`).
