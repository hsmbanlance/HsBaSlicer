Flat collection of `.proto` files under the `HsbaProto` package, split into two conceptual layers: shared primitives (`point.proto`, `vector.proto`, `mesh.proto`, `path.proto`, `transform.proto`, `boolean_operation.proto`) imported by higher-level schemas, and per-technology pipeline configs (`fdm_pipeline.proto`, `sla_pipeline.proto`, `slm_pipeline.proto`, `sls_pipeline.proto`, `tdp_pipeline.proto`, `waam_pipeline.proto`, `lom_pipeline.proto`, `file_transfer_pipeline.proto`, `custom_pipeline.proto`, `base_config.proto`, `slice_config.proto`). The CMake build has two modes: when `HSBA_PROTOBUF_OUT` is set it runs `protoc` to emit C++, C#, Java, Python, and PHP sources into a configurable output directory; otherwise it uses `PROTOBUF_GENERATE_CPP` to compile the generated code directly into the static library `HsBaSlicerProto` linked against `protobuf::libprotobuf`.
